# 📗 くらしノート

暮らしのことを一冊に。**やること（Todo）** と **買うもの**、そして
**「この洗剤はどのお店が一番安いか」** の記録が、同じアプリの中にあります。

> もとの名前は「かいものノート」でした。買い物だけのアプリではなくなったので、
> 名前とアイコンを変えています。データの保存先（`kaimono-note-v2`）はそのままなので、
> 入れてある中身は何も失われません。

ビルド不要・サーバー不要のPWA。スマホのブラウザから「ホーム画面に追加」すると、
ふつうのアプリと同じように起動でき、電波がなくても使えます。

---

## できること

### やること（Todo）

いちばん左のタブで、**アプリを開くとここから始まります**。手に取ったときの
問いは「何を買うんだっけ」より「今日なにをするんだっけ」のほうが多いので。
買うものタブは、お店に着いてから一押しで開けます。

- 下の**＋**から追加。やること・**いつまでに**・**時刻**・**くりかえし**・★・メモを
  一枚で。**シートの中の選択肢は折り返して全部見えます**——横に流れる並びだと、
  390pxの画面では「1か月後」と「なし」が右の外に隠れていました
- 日付は**今日 / 明日 / 明後日 / 明々後日 / 1週間後 / 1か月後 / なし**から一押し。
  ほかの日はカレンダーから
- **カレンダーが縦に並んでいる形**です——期限切れ / **今日（朝・午後・夜）** /
  明日 / 明後日 / この先1週間は**1日ずつ**（「8月14日 金」）/ **◯月 第△週** /
  **◯月** / **いつか**（日付を決めていないもの）
- **中身のない棚も細い一行で残ります。** そこへ運べるようにするためです——
  空っぽの棚は「置き場所」であって、無い日ではありません
- **棚と棚のあいだには線が入り、見出しにはその棚の色がうっすら乗ります。**
  日付の見出しが15行も続くと、どこで明日が終わって明後日が始まるのかが
  読めませんでした——項目を持ち上げて運んでいるときにこそ効いてきます
- **今日のぶんは囲みの中**にまとまります（買うものタブの「今回買うもの」と同じ形）。
  中は「今日（時間はいつでも）」「朝」「午後」「夜」に分かれます
- **時刻も決められます**（任意）。「朝・午後・夜」のすぐ下の欄に書くと、行に
  **19:30** と出て、同じ棚の中では**時計の順**に並びます。棚は時刻から決まるので、
  9:00は朝、14:30は午後、19:30は夜へ自動で入ります（朝＝0時台〜11時台、
  午後＝12〜17時、夜＝18時以降）。
  **時刻と「朝・午後・夜」は片方だけ**です——「19:30」と「朝」の両方を持つと
  どちらが本当か分からなくなるので、あとから決めたほうが残ります。
  なお**アラームは鳴りません**（並び順と目印です）。シートにもそう書いてあります
- **行の左端の色が、その日までの近さ**です。今日が赤、離れるにつれて
  オレンジ→黄→緑→青。いつかは灰色。見出しの丸も同じ色です
- **★**を付けると、同じ日のなかで先に出てきます
- **長押しして動かせます。** 同じ棚の中では並べ替え、**別の棚へ運べば日付が変わります**
  ——「朝」から「夜」へ、「今日」から「8月16日 日」へ、「9月」へ、「いつか」へ。
  運んでいる先の棚が光るので、どこに落ちるか見ながら決められます。
  日付の棚は時間帯も時刻もそのままにし（変わったのは日だけなので）、
  「朝・午後・夜」の棚に落としたときは時刻のほうが降ります（21:00のまま
  「朝」には置けないので）。「いつか」は日付ごと外します
- **くりかえし**（毎日・毎週・毎月）は、済ませても終わりません。**次の日に動きます**
  ——「ゴミ出し」を毎週にしておけば、押すたびに来週の日付になります。
  何日か遅れて押しても、次はちゃんと未来の日になります
- **毎週は曜日で決められます**（複数可）。「燃えるゴミ＝火・金」なら、
  火曜に済ませた次は金曜、金曜に済ませた次は来週の火曜。
  日付を決めてあっても、選んだ曜日に自動でそろえます
- **毎月は「◯日」と「第◯◯曜日」から選べます**。「第2火曜日」「最終金曜日」は
  月ごとに日付が変わるので、そのように数えます（第5週の無い月は飛ばします）。
  「◯日」のほうは、その日の無い月は月末になります
- くりかえしの決まりは行にも小さく出ます（「毎週 火・金」）。ただし**控えめな色**で
  ——ずっと変わらない性質であって、今日の知らせではないので、探せば読めて、
  探していなければ目に入らない濃さにしてあります
- 行を**右にスワイプ**で「今日にする」、**左にスワイプ**で**アーカイブ**
  （削除ではありません。取り消せます）。行をタップすれば直せます。
  ほんとうに消したいものは、その行のシートの「削除」から
- 済ませたものも、しまったものも**アーカイブ**に、片付けた**日付と時刻**つきで
  残ります。買うもの・価格のアーカイブと**同じ見た目**——薄くなって、名前に線が
  引かれ、期限の色も抜けて灰色になります。終わった用事に「今日」の赤を
  着せたままにしておく意味はないので
- **行 / タイル**を切り替えられます（買うもの・価格と同じボタン、同じ設定）
- **日付を決めたものは、その日が来るとアプリのアイコンに数が出ます**
  （期限切れも数えます。来週のぶんは、来週になるまで数えません）。
  タブにも同じ数が出ます。**設定がまだオフのときは、日付を決めた画面から
  そのままオンにできます**
- **時刻を決めたものは、その時刻が来るまで数に入りません。** 「19:30に薬」を
  朝から1と表示しても、まだ手のつけようがありません——ずっと置きっぱなしの数字は、
  読まなくなる数字です。**昨日ぶんは時刻に関係なく数えます**（遅れているものは
  待ちません）
- **時刻が来たら知らせます**（設定 →「やることの時刻を知らせる」）。同じ時刻に
  何件あっても通知は一本にまとめます。
  ただし——**アプリを閉じているあいだは鳴りません。** 決まった時刻に閉じたアプリを
  起こすには、送り手になるサーバーが要ります（iOS 16.4以降のWeb Pushでも、
  誰かが押してやらないと届きません）。このアプリはGitHub Pagesに置いた
  ファイルの集まりで、データもお使いの端末の中だけにあります。iOSには
  ローカルで時刻を予約する仕組み（Notification Triggers）もありません。
  **できるのは「開いているあいだに鳴ること」と「次に開いたときにまとめて出ること」**
  です。設定の文言もそう書いてあります——鳴ると思っていたものが鳴らないのは、
  いちばん困るのが「当てにしていた時刻」だからです
- 日付が変わると、並びも色もバッジも自動で言い直します。時刻が来たときも同じです

### 買うもの（買い物リスト）
- 画面の下に浮いている**＋**から追加（帯ではなくボタンだけなので、
  そのぶんリストが広く使えます）。商品名・**今回買う（★）**・カテゴリ・メモを
  一枚で入れられます。個数はここでは聞きません（あとから行をタップして直せます）。
  **カテゴリは名前から自動で振り分け**（「牛乳」→ 冷蔵・冷凍、「シャンプー」→ 日用品）。
  自分で選び直せば、その振り分けを覚えます
- 打っている間に**登録済みの商品を候補表示**（最安値つき）。タップすればその商品として
  追加され、同じ名前の商品が二つできることはありません。
  **かなの違いは気にしません**——「え」で「エマール」、「きゅうり」で「ｷｭｳﾘ」が出ます
- 追加すると**シートは閉じます**。増えた行がその場で見えて、次の一件は
  ＋をもう一度押すだけです
- カテゴリごとにまとめて表示。**カテゴリは行の左端の色**で分かります
  （見出しの行は置きません）。チップをタップすれば絞り込みも
- 数量・メモ・買ったかどうかのチェック
- **買ったものは「アーカイブ」へ**、買った**日付と時刻**つきで（新しいものが上）。
  一日に何度も買い物に出れば同じ日付が並ぶので、どちらが先だったかを言えるのは
  時計のほうです。まとめて削除するボタンはありません——買ったことは消す理由に
  なりませんし、買い物中に押したくなる場面もないので。やること・価格の
  アーカイブも同じ名前・同じ書き方です
- **メモは普段そのまま読めます。** 記入欄ではなく本文が折り返して全部出て、
  **鉛筆マーク**（かメモ自体）をタップすると書けるようになります。
  一行の入力欄では、二行のメモは横に切れて読めませんでした。
  リストの行にも2行ぶんまで出ます
- 行を**右にスワイプ**で★（今回買うもの）の出し入れ、**左にスワイプ**で
  **アーカイブ**（その行はリストから外れ、価格タブの一覧からも下がります）。
  どちらも指を離すと元の位置に戻り、取り消しはトーストから。
  スワイプで出てくる面は**その行のカテゴリの色**です
- 入力中のキーボードは、**画面を下にスワイプ**すればしまえます
- 右上の**虫めがね**で検索。商品名・メモ・カテゴリのどれでも引っかかります
  （価格タブとやることタブにも同じ虫めがねがあります。使うときだけ開くので、
  ふだんは一行ぶん画面が広く使えます）
- **★で「今回買うもの」を選ぶ**と、その品だけが**ひとつの囲みの中**にまとまります。
  タブのバッジもその買い物ぶんだけを数えます。
  選ばなかった品は囲みの下に「そのほか」として残るので、
  買うものリストと買い置きメモを一枚で持ち歩けます
- **買い物リストに合計は出しません。** 値段が分かっている品だけを足した数は
  カゴの合計ではないのに、リストの下に置かれた数字はその合計に見えてしまいます。
  行ごとの値段（事実）は出しますが、足し算はしません
- ★が一つも付いていないうちは、リストが並ぶだけです。「気づいたこと」も
  出しません。買い物の予定が決まっていないのに助言をしても、
  何についての助言なのか言えないからです

### 価格の記録
- 商品ごとに、お店ごとの値段を登録 → **いちばん安いお店に🏆バッジ**
- 行に書くのは**商品名・内容量・1個あたり・値段・最安の店**だけ。
  「3店舗で比較中」のような、アプリ自身の記録の件数は出しません
- **右にスワイプ**すると、その商品が買い物リストに出入りします
  （入っていなければ入れる、入っていれば外す）。出てくる面は**その商品の
  カテゴリの色**——入っているものを外すときだけ、灰色になります。
  **左端が塗られている**商品が、いま買うものです（色は同じくカテゴリの色）。
  リストで「買った」を押すと、**その塗りつぶしは消えます**——カゴに入ったものは
  もう買うものではないので。そのままもう一度右にスワイプすればチェックが外れて、
  また買うものに戻ります（リストから消えるわけではありません）
- 商品の追加も、リストと同じ**画面の下に浮いた＋**から（右上ではありません。
  どちらの画面も、足す動きは同じ場所・同じボタンです）
- **左にスワイプ**すると**アーカイブ**。めったに買わない物は、いちばん下の
  「アーカイブ」にたたまれて一覧から消えます（**しまった日付と時刻**が付きます）。
  しまった商品は、買うものタブの「買った」行と**同じ見た目**——薄くなって、
  名前に線が引かれます。値段の記録は消えません。
  もう一度左にスワイプすれば戻ります。商品名で探したときは、アーカイブも
  開いて一緒に出てきます
- アーカイブは**買い物リストとひとつながり**です。しまえば買い物リストからも
  外れ（左端の色も消えます）、リストに入れれば自動で戻ってきます。
  買い物リストの行を左にスワイプしても同じアーカイブに入ります
- 比べるのは**値段そのもの**。同じ物を同じ大きさで買うので、
  100mlあたりのような割り算はしません
- **入数のあるものだけ1個あたり**：「10個」「12ロール」と入れておくと
  「1個あたり ¥26.8」も添えます（「500ml」は目印として表示するだけ）
- 同じ店の値段を何度も記録すると、**値段の推移がグラフ**で見えます
  （最新の値段が「今の価格」として比較に使われます）
- 「値段を追加」は、**まだ値段の無いお店**から始まります。直前に入れたお店が
  そのまま選ばれていると、次の一件が同じお店に入って前の行が消えたように
  見えるので。値段のあるお店を選ぶとボタンが**「更新」**に変わり、
  今いくら入っているかも出ます（前の値段は履歴に残ります）
- 値段の欄は**電卓**になっています。＋−×÷ のほか、「税+8%」「税+10%」と
  「割引−%」（398に12と入れれば350）。式を打つと「確定」が「＝」に変わり、
  答えを見てから確定できます
- **電卓を出したまま「追加」を押しても大丈夫**です。電卓は指が離れるまで
  引っ込みません——先に引っ込むと画面が三分の一ぶん下にずれて、押したはずの
  ボタンではなく、そこへ滑り込んできた行の🗑が押されていました
  （「確定」を押さずに足した値段も、そのまま記録されます）

### お店くらべ

タブではなく、**リストと価格の右上のお店ボタン**（くらべる印の付いたお店の絵）から開きます。
毎日開くものではないので、タブ1つぶんの場所は「やること」に譲りました。
- 買い物リスト全体で、**どのお店を中心に買うと総額いくらか**を自動計算
- 同じ買い物カゴで比較するので、取扱商品数が違うお店同士でも公平に並びます
  （その店にない物は「最安の店で買う」前提で計算）
- **最安の組み合わせ**（各商品を最安店で買った場合）との差額も表示
- 商品ごとの最安店を一覧表示

### 気づいたこと

登録した値段を読んで、そのとき言えることだけを出します。

- 「今回は業務スーパーだけで足ります」／「店を分けると ¥320 安くなります」
- 「牛乳がイオンで ¥218 → ¥248 に上がりました」（同じ店の前回の値段と比べます）
- 「お米の値段が古くなっています」（3ヶ月以上前の記録）

すべて端末の中の計算です。外部に問い合わせないので、通信も費用も要らず、
機内モードでも出ます。出てくる数字はあなたが入れた値段そのものなので、
それらしいだけの推測が混ざることはありません。言える材料が無いときは
黙っています。

### 商品の絵
- 商品の絵は**全部このアプリの中で描いています**（約555種）。名前から自動で選びますが、
  商品の詳細から**自分で選び直せます**
- 食べものと消耗品だけではありません。**家具・寝具**（椅子・机・ソファ・ベッド・布団・
  カーテン・本棚…）、**文房具**（鉛筆・シャーペン・蛍光ペン・修正テープ・印鑑…）、
  **キッチングッズ**（片手鍋・おたま・泡立て器・おろし金・急須・弁当箱…）、
  **カトラリー**（スプーン・フォーク・ナイフ・れんげ・箸）、
  **家電**（電子レンジ・冷蔵庫・洗濯機・扇風機・ドライヤー・ノートパソコン…）も
  それぞれの絵です。これらは**日用品**に振り分けられます（もちろん選び直せます）
- **一枚が何役も兼ねない**ようにしてあります。大根とごぼうは別、そばとうどんも別、
  かまぼことちくわも別です。以前は「キャベツ」一枚が白菜もレタスもほうれん草も
  引き受けていて、絵で見分ける意味がありませんでした
- 選ぶ画面では、名前から**「もしかして」**の候補を上に出します。
  「食器用洗剤」なら食器用洗剤と洗濯洗剤——取り違えやすい相手こそ隣に並べます
- 名前で絵をさがすこともできます。自分で選んだ絵は、名前を変えても動きません

### 並べ方（行 / タイル）

やること・買うもの・価格の3画面とも、**行**と**タイル**を切り替えられます。
どの画面の右上のボタンからでも切り替わり、全部に効きます。

- **行**：商品名・値段・最安の店が一行に並びます
- **タイル**：一行に3つの正方形。絵が大きく、商品名は折り返して全部出ます。
  一画面に3倍入るので、探すときはこちらが速いです。
  価格タブのタイルには、値段の下に**いちばん安いお店**も出ます

**スワイプはどちらでも同じです**——右がそのタブの「する」（やることでは今日に、
買うものでは★、価格ではリストへの出し入れ）、左がアーカイブ。タイルでは幅がないので
文字は出さず、絵だけが出ます。並べ替え（長押しして動かす）は行だけです。

### そのほか
- ライト / ダークテーマ（自動切り替え対応）
- **ホーム画面のアイコンに残り数**を出せます（設定 → 表示、または
  やることに日付を決めるときにその場で）。数えるのは
  **「今回買うもの」の残り＋今日までのやること**です。
  iPhoneでは**設定をオンにしていないと出ません**（タブのバッジは設定なしで出ます）。
  iOS 16.4 以降のホーム画面アプリで使えます。iPhone ではバッジが通知の許可に
  ぶら下がっているので、オンにするとき通知の許可を聞かれます（通知は送りません）。
  数はアプリに戻るたびに言い直します——iOSは再起動や強制終了でバッジを
  勝手に消し、ページには何も言わないので。許可が外れているときは、
  設定のスイッチが「許可が必要」と出ます
- お店・カテゴリの追加、名前や色の変更、並び替え
- JSONでバックアップ・復元
- **自動バックアップ**：1日1回と、削除・復元などの危ない操作の直前に、
  アプリが自動で控えを残します（最新7件）。うっかり消しても設定から戻せます
- データは**この端末の中だけ**に保存されます（サーバーに送信しません）

> 自動バックアップはこの端末の中に置かれるものです。機種変更や端末の紛失に
> 備えるには、設定の「バックアップを保存」でファイルを書き出してください。
> しばらく書き出していないと、アプリがそっと知らせます。

## スマホにインストールする

### 1. GitHub Pagesを有効にする（最初の1回だけ・手動）

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の **Source** を **GitHub Actions** に変更する
3. **Actions** タブ → 「Deploy to GitHub Pages」→ **Re-run all jobs**

この1手順だけは手作業が必要です。ワークフローから自動で有効化することは
できません（`GITHUB_TOKEN` にPagesサイトを作成する権限がないため）。

一度有効にすれば、あとは `main` に push するたび自動で公開されます。

### 2. スマホで開く

公開URLはこちら：

**https://rt95k9k468-cmyk.github.io/kaimono-note/**

初回のデプロイは1〜2分ほどかかります。
リポジトリの **Actions** タブで緑のチェックが付いたら準備完了です。

### 3. ホーム画面に追加する

- **iPhone（Safari）**
  共有ボタン <kbd>􀈂</kbd> → 「ホーム画面に追加」
  ※ Chrome や他のブラウザではなく **Safari** で開いてください
- **Android（Chrome）**
  右上の <kbd>⋮</kbd> → 「アプリをインストール」または「ホーム画面に追加」

追加すると、アドレスバーのないふつうのアプリとして起動します。
一度開いておけば、**電波がなくても使えます**。

### 更新するとどうなる？

`main` に push すると自動でデプロイされ、**ホーム画面のアプリも次に開いた
ときに新しくなります**。アプリストアの審査も再インストールも要りません。

仕組みとしては、デプロイのたびにコミットIDを `sw.js` に埋め込んで
キャッシュ名を変えています。これをしないと、Service Worker が
入れ替わらず古いJS/CSSが返り続けてしまいます。

反映は「更新をpush → アプリを開く（新しい中身を裏で取得）→ もう一度開く」
の流れになるので、変更が見えるのは次回起動時です。

## 手元で動かす

### そのまま開く
`index.html` をブラウザで開くだけで動きます。

### ローカルサーバーで動かす
オフライン動作（Service Worker）を試すにはサーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 構成

ビルドツールもフレームワークも使っていません。素のHTML / CSS / JavaScriptです。

```
index.html              画面の骨組み
manifest.webmanifest    PWA設定（アプリ名・アイコン・起動方法）
sw.js                   Service Worker（オフライン対応）
css/
  base.css              デザイントークン、リセット、アプリ全体のレイアウト
  components.css        ボタン・入力欄・シート・トーストなど共通部品
  screens.css           各画面固有のスタイル
js/
  util.js               HTMLテンプレート、金額・日付の整形、1個あたりの計算、アイコン
  store.js              データの保存・読み込み・移行、検索用のセレクタ
  ui.js                 ボトムシート、トースト、確認ダイアログ、各種ピッカー
  backup.js             自動バックアップ（世代管理・復元・書き出しの催促）
  insights.js           値段の記録から「気づいたこと」を組み立てる
  notify.js             やることの時刻のお知らせ（開いているあいだ／開いたとき）
  product-sheet.js      商品の詳細画面（数量・カテゴリ・内容量・価格・履歴）／お店ごとの値段の詳細
  screen-todo.js        やること画面（日付・時刻・くりかえし）
  screen-list.js        買い物リスト画面
  screen-prices.js      商品と価格の一覧画面
  screen-compare.js     お店くらべ画面
  screen-settings.js    設定画面
```

データはブラウザの `localStorage` に `kaimono-note-v2` というキーで保存されます。
以前のバージョンのデータ（`kaimono-note-v1`）は、初回起動時に自動で新形式へ移行します。
