# かいものノート 🛒

買い物リストを整理しつつ、商品ごとに「どのお店が一番安いか」をまとめて記録できるシンプルなWebアプリです。

## 主な機能

- **買い物リスト**: 商品名・数量・メモを指定してリストに追加し、購入済みはチェックで管理できます。
- **価格くらべ**: 商品ごとに複数のお店の価格を登録すると、自動で最安値のお店がバッジ表示されます（買い物リスト・価格くらべタブの両方から登録可能）。
- 買い物リストに追加した商品は自動的に価格データベースにも登録されるので、二重管理は不要です。
- データはブラウザの `localStorage` に保存され、サーバー不要で動作します。

## 使い方

追加のビルドは不要です。`index.html` を開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ファイル構成

- `index.html` — 画面構造
- `style.css` — スタイル
- `app.js` — アプリのロジック（バニラJS、フレームワーク不使用）
