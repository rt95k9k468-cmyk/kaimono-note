# 🛒 かいものノート

買い物リストを整理しながら、**「この洗剤はどのお店が一番安いか」** をまとめて記録できるアプリです。

ビルド不要・サーバー不要のPWA。スマホのブラウザから「ホーム画面に追加」すると、
ふつうのアプリと同じように起動でき、電波がなくても使えます。

---

## できること

### 買い物リスト
- 商品名を入れるだけで追加。**カテゴリは自動で振り分け**（「牛乳」→ 冷蔵・冷凍、「シャンプー」→ 日用品）
- カテゴリごとにグループ表示。チップをタップすれば絞り込みも
- 数量・メモ・購入済みチェック、購入済みはまとめて削除
- 入力中に既存の商品を候補表示（最安値つき）
- リストの下に **「最安値で買うといくらか」** の合計を表示

### 価格の記録
- 商品ごとに、お店ごとの値段を登録 → **いちばん安いお店に🏆バッジ**
- **単価で比較**：内容量を入れると「100mlあたり ¥60」のように自動計算。
  容量違いの商品もフェアに比べられます
- 同じ店の値段を何度も記録すると、**値段の推移がグラフ**で見えます
  （最新の値段が「今の価格」として比較に使われます）

### お店くらべ
- 買い物リスト全体で、**どのお店を中心に買うと総額いくらか**を自動計算
- 同じ買い物カゴで比較するので、取扱商品数が違うお店同士でも公平に並びます
  （その店にない物は「最安の店で買う」前提で計算）
- **最安の組み合わせ**（各商品を最安店で買った場合）との差額も表示
- 商品ごとの最安店を一覧表示

### そのほか
- ライト / ダークテーマ（自動切り替え対応）
- お店・カテゴリの追加、名前や色の変更、並び替え
- JSONでバックアップ・復元
- データは**この端末の中だけ**に保存されます（サーバーに送信しません）

## 使い方

### そのまま開く
`index.html` をブラウザで開くだけで動きます。

### ローカルサーバーで動かす（推奨）
オフライン動作（Service Worker）を試すにはサーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

### GitHub Pagesで公開する
このリポジトリには公開用のワークフローが入っています。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を **GitHub Actions** に設定
3. `main` ブランチに push すると自動で公開されます

公開後のURLをスマホで開き、ブラウザのメニューから
「ホーム画面に追加」を選ぶとアプリとして使えます。

## 構成

ビルドツールもフレームワークも使っていません。素のHTML / CSS / JavaScriptです。

```
index.html              画面の骨組み
manifest.webmanifest    PWA設定（アプリ名・アイコン・起動方法）
sw.js                   Service Worker（オフライン対応）
css/
  base.css              デザイントークン、リセット、アプリ全体のレイアウト
  components.css        ボタン・入力欄・シート・トーストなど共通部品
  screens.css           各画面固有のスタイル
js/
  util.js               HTMLテンプレート、金額・日付の整形、単価計算、アイコン
  store.js              データの保存・読み込み・移行、検索用のセレクタ
  ui.js                 ボトムシート、トースト、確認ダイアログ、各種ピッカー
  product-sheet.js      商品の詳細画面（数量・カテゴリ・内容量・価格・履歴）
  screen-list.js        買い物リスト画面
  screen-prices.js      商品と価格の一覧画面
  screen-compare.js     お店くらべ画面
  screen-settings.js    設定画面
```

データはブラウザの `localStorage` に `kaimono-note-v2` というキーで保存されます。
以前のバージョンのデータ（`kaimono-note-v1`）は、初回起動時に自動で新形式へ移行します。
