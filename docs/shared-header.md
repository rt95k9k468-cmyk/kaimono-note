# 上の帯と暦は、全タブで一つ（計画と決めごと）

2026年9月27日に決めた。利用者の言葉では「一番上のタイトル帯とカレンダーは、
全てのタブで共通に。タブを移動するときも、背面としての帯と暦は微動だにせず、
紙の器だけがスライドする」。買うもの・価格にも、ほかと同じ日付の題・右上の
さがす／設定・暦を置く。暦の段（なし／週／月）は全タブで同期する。

**触る前に読むもの：** `screens-nav.md`（画面の移り変わり・題）、
`calendar-swipe.md`（暦の三段・払う）、`sheet-scroll.md`（紙と送る器）、
`shopping.md`（買うもの・価格の重なり）。どれも「一度こわした話」でできている。

## 作り方：案A「本当に一つにする」

各画面が自分の帯と暦を持ったまま中身をそろえる（案B「一つに見せる」）のでは
なく、**帯と暦を `.screens` の外へ引き上げて一つの部品にする**。タブの流れ
（`app.js` の `show()`）は、帯より下——紙（と、買うもののカテゴリの札）——だけを
動かす。帯は流れの外に居るので、動かないことが作りとして保証される。
案Bは五枚が一画素も違わないことに頼るので、印の違い・測った高さの1px・
組み直しの一拍が、そのまま「ちらつき」になる。

## 決めたこと（2026年9月27日、全部おすすめどおり）

1. **いま見ている日は全タブで一つ。** やることで未来の日を見たまま daily・
   ダイエットへ移ったら、**その未来の日をそのまま見せる**（紙は見るだけ・
   書き込めない）。今日へ寄せると、移った瞬間に題が変わる。
   - daily・ダイエットの中から未来へは進めない（これまでどおり）。ただし
     **戻る向きは通す**——持ち込まれた未来の日から、今日へ戻る道が要るので。
   - その日を見ているあいだの ＋ は、**今日へ**書く。
2. **買うもの・価格の暦は「共通の日」を動かす盤。** 日を押すと共通の日が
   変わるが、買うものの紙そのものは変わらない（「その日に買ったもの」を出す
   のは、あとで足せる拡張）。紙を横に払って日を送る手つき（day-swipe）は
   買うもの・価格には付けない。
   → **2026年9月28日に改めた**（利用者：「買うもののアーカイブの下の空白を
   払っても反応しないのはおかしい」→「日を送る」を選んだ）。買うものは
   払うと日が動く。紙は組み直さず、指に少しついて戻るだけ（隣の紙は組まない）。
   行（★・アーカイブ）と掴み手（価格へ）から始まった指は取らない。価格の
   面には付けない（docs/calendar-swipe.md の「払いを、ゆるく・軽く」）。
3. **買うものの掴み手は、いまのまま価格へ**（下へ引くと紙が下がって価格の地）。
   暦の段は題を押す／ほかのタブで変える（同期しているので効く）。
   → **2026年9月28日に改めた**。掴み手はほかのタブと同じく暦を引くもの
   （`KN.head.shopPeek`）。価格へは、買うものに居るところで帯の「shopping」を
   押す。価格から戻るのは、これまでどおり留まった頭を上へ引く／帯を押す。
   買うもののカテゴリの札は外した（docs/shopping.md の冒頭）。
4. **暦のマスの印は、タブごとに替える。** 枠は動かず、印だけ替わる。
   **全タブ共通にしてはいけない**——daily にダイエットの達成の棒が出て、
   「daily は評価しない」を破る（`tests/daily-rules.js`）。買うもの・価格は、
   段3では印なし、段4から「その日に買ったもの」の丸（やることと同じ `.cal-mark`）。
5. **検索欄は暦の下（タブ側の、流れる部分）に開く。** 題と暦の間に開くと、
   開いているタブと閉じているタブのあいだで暦が上下する。虫めがねのボタンは
   共通、探す相手はタブごと。設定の「探す窓を出しておく」もこの位置で出す。
6. **題を押したときの応えは、いまのまま**（やること・ダイエット：週⇄月、
   daily：月を選ぶ紙）。買うもの・価格は週⇄月。見た目は同じで、応えだけが
   タブに合わせて違う。
7. **main への流し方：** 段1は単独で main へ。**段2と段3はそろってから一緒に**
   （段2だけだと、買うものへ移るときだけ帯が崩れる状態が実機に出る）。

決めなくても起きること：暦の出し入れの設定は三か所→一か所（外観の「表示」）。
だから「買い物のときだけ暦をしまう」はできない（しまえば全タブでしまわれる）。
買うもの・価格は暦のぶん縦が狭くなる。「shopping⇄prices」の題の入れ替わりは
無くなり、日付になる。設定（引き出し）は共通の帯ごと押しのける。

## 段1で入れたもの（2026年9月27日）

- **`KN.util.dayShare`**（`util.js`）：どの日か（null＝今日）と、変わったことを
  見分ける番号だけ。保存はしない（各画面の `viewDay` も前から保存していない）。
- **席を移るとき、`show()` が出ていく画面の `day()` を置く。** 入ってくる画面は
  `render()` の頭の `takeSharedDay()` で、番号が変わっていれば引き取る
  （日・印・暦の月の三つを書き換えてから組む）。日を持たない画面（買うもの・
  価格・設定）からは何も置かないので、前に見ていた日が残る。
  - 画面が答える `day()`：やること＝題の日（一日の紙なら `shownDay`、一覧なら
    `hereDay`）、daily＝`focusDay()`、ダイエット＝`curDay()`。
  - 自分で置いた番号で戻ってきても、同じ日なら何もしない（手で送っていた
    暦の月を巻き戻さないため）。
- **暦の段は `settings.calAll` の一つ。** 無ければ、これまでのやることの見かた
  （`calBy.todo` → 古い `calOpen`）から始まる。**`calBy` は消さずに残し、読まない
  だけ**——データの移行ではない。戻すなら `store.calPrefs` を戻せば元どおり。
  呼ぶ側の `calPrefs(tab)` / `setCalPref(tab, …)` は、引数を受けたまま使わない。
- 未来の日：daily は紙を `inert`（`.is-ahead`）、ダイエットは覗き見と同じ
  押せない紙（`peek`）。＋ は今日へ書く。

## 段2で入れたもの（2026年9月27日）

**置き場の組み**（`index.html`）：

```
main.screens
  div.deck#deck            ← 帯と紙の画面のひと組（z-index:0 で積み重ねを閉じる）
    div.head#head          ← 帯：題・今日へ戻る・さがす・設定 ＋ 暦の置き場 .head-cal
    div.panes#panes        ← daily・やること・買うもの・価格・ダイエット（.screen）
  section#screen-settings  ← deck の外。帯ごと押しのけて上に重なる一枚
```

- **`js/head.js`（`KN.head`）が帯を一つだけ組む。** 題の形は前と同じ
  `KN.util.dayTitleBar()`。歯車だけは head.js が自分で結ぶ（どのタブでも同じ）。
- **持ち主**（`KN.head.mine(id)`）：いちばん最後に出た、帯を持つタブ
  （`KN.head.TABS` ＝ archive・todo・diet）。`show()` が組む**前**に
  `KN.head.enter(id)` を呼ぶ。設定では持ち主を変えない（下に居るのは歯車を
  押した画面の帯のまま——左端から引くとそれが見える）。買うもの・価格では
  持ち主なし＋帯を隠す（段2の暫定）。
- **題・今日へ戻る・虫めがね は、各画面がいままでどおり自分で結ぶ**（同じ
  ボタンに三つが結ぶ）。押されたら頭で `mine()` を見て、持ち主でなければ黙る。
  題を塗る `paintDayTitle` も `mine()` で止める——止めないと、よそのタブの
  拍（やることの30秒の拍など）が帯の題を上書きする。虫めがねは
  `KN.ui.wireSearch` の `els.mine`。光り方と読み上げは `enter` が入ってくる
  タブの窓から決める。
- **暦の枠（置き場）は一つ、暦の要素はタブごと。** 各画面は前と同じく自分の
  `.cal` を組み（印がタブごとに違うので）、`render()` の中で
  `KN.head.putCal(id, cal)` で置き場に据える。同じ要素なら触らない
  （やることの盤の使い回しを壊さない）。入れ替わりは `show()` の同じ一拍の
  うちなので、前のタブの暦が描かれることはない。**暦を組む仕掛けそのもの
  （`fillCalendar`・輪・`calSwipe.wire`）は三つのまま**——まとめると
  `calendar-swipe.md` の決めごとを一つずつ移し替えることになり、段2の中身
  （動かないこと）には要らなかった。まとめるなら別の段で。
- **探しているあいだも暦は出したまま**（やること・ダイエットは前は外していた）。
  外すと帯の厚みが変わる＝探しているタブだけ帯が縮む。
- **やることの「期限切れがあります」は暦の中から画面の頭（`.js-late`）へ。**
  暦の中に居ると、やることの暦だけ背が高くなってタブを移るたびに紙が上下する。
  画面の頭も紙の外なので「どこまで送っても居る」はそのまま。
- **帯と暦の `is-stuck`（境目の線）は付けなくなった。** 帯は送られないので
  「貼りついた」が無い。付けていると、送った画面と送っていない画面で線が
  出たり消えたりして、一つの帯がタブごとに違う顔をする。`--topbar-h` を
  測る `fitCal` も外した（読む人がいない）。
- **検索欄はタブ側**：各画面の `.stack` の頭（＝暦のすぐ下）。
- **タブの流れ**：`show()` はこれまでどおり `.screen` を流す。帯は `#panes` の
  外なので動かない。**帯を持つタブ⇄持たないタブ（買うもの・価格）は流さず
  切り替える**（`cross`。流しながら帯を隠すと出ていく画面が帯の厚みぶん跳ねる）。
- **設定は deck ごと押しのける**：`show()` が deck に `is-push-under` /
  `is-pop-in` を付け、下の画面の同名の class は動かさない（base.css）。
  左端から引いて戻るとき `KN.app.underScreen()` が返すのも deck。
- 試験：`tests/head-still.js`（毎フレーム 0px・掴み手は本物のタッチ・印は
  タブごと・虫めがね・題の応え・設定・買うもの）。`shared-day.js` は題と暦を
  `#head` から読むように直した。

## 段3で入れたもの（2026年9月27日）

- **`KN.head.TABS` は五つ**（archive・todo・list・prices・diet）。`show()` の
  `cross`（帯を持つ／持たないのあいだは流さない）は外した——どのタブのあいだも
  帯の下の画面だけが流れる。帯が隠れる場面はもう無い（`enter` の隠す枝は、
  TABS の外の画面のためだけに残っている。いまは該当なし）。
- **買うもの・価格の自前の `.topbar` を外した。** 題の「shopping」⇄「prices」の
  入れ替わり（`.face-title` / `.face-t`、`--face-p` で薄めて入れ替える）も、
  それを伏せる `.is-face-back` / `.is-face-parked` の `.topbar` の規則も消えた。
  紙を下げて価格へ移っても、題は日付のまま変わらない。**入れ替わるのは札の
  帯（`.js-filter`）だけ**——あちらの決めごと（重ねない・地は後ろの札が持つ）は
  そのまま（docs/shopping.md）。`--topbar-h` を測る `fitBar` も両画面から外した
  （読む人がいない。掴み手は紙の上端 `top: 0`）。境目の線 `is-stuck` も付けない。
- **暦は印なしの一枚を、`head.js` が組む**（`KN.head.shopCal()`。段4で買ったものの丸を足した）。四つめの組み手を
  書いた——三つの組み手（`fillCalendar`）をまとめるのは段2と同じ理由で見送り
  （`calendar-swipe.md` の決めごとを一つずつ移すことになる）。
  - **買うものと価格は同じ要素を置く**ので、紙を下げて価格へ移っても `putCal` は
    何もしない（暦が差し替わらない）。試験は要素に印を付けて確かめている。
  - マスの `.cal-dots` は**空のまま置く**（段4からは買った日だけ丸が入る。無い日は空のまま）——マスの背丈をほかのタブとそろえるため。
    消すと、タブを移るたびに帯の厚みが変わりうる。
  - 日を押すと動くのは head.js の中の日（`sDay`）・輪・題だけ。**紙は組み直さない**
    （買うものの紙は日で変わらないので）。隣の月のマス（週の端）だけは、その月で
    組み直す。共通の日（`dayShare`）へは、席を移るとき `show()` が両画面の
    `day()`（＝`KN.head.shopDay`）を読んで置いていく——段1の流れそのまま。
    入るときは `shopCal()` の頭で引き取る。
    → **2026年9月28日から、紙の中身は組み直す**（`dayMoved` → `screen-list.js`
    の `dayMoved`。今日でない日には「その日に買ったもの」を頭に出すので。
    docs/shopping.md）。組み直すのは紙の中身（`renderBody`）だけで、暦は
    `render()` を通さない——通すと暦まで組み直して、動いている輪が跳ぶ。
    買うものの行そのものは、いまも日で変わらない。
  - 未来の日も押せる（やることと同じ。持ち込んだ先の daily・ダイエットは見るだけ）。
  - 暦そのものを横に払う（`calSwipe.wire`）のはほかのタブと同じ。**紙を横に払って
    日を送る手つき（day-swipe）は付けない**（決めたことの2）。→ 2026年9月28日
    から付けた（`slide` なしの使い方。`screen-list.js` の mount、`KN.head.shopGo`）。紙を引いて暦の段を
    替える `calPeek.wire` も付けない——掴み手は価格へのもの（決めたことの3）。
    → 2026年9月28日から付けた（`KN.head.shopPeek`。決めたことの3を改めた）。
- **題・今日へ戻る の応えは head.js が結ぶ**（ほかのタブは各画面が結ぶが、
  買うもの・価格は日を持たないので）。題＝週⇄月（`setCalPref`、組み直しは
  `subscribe` から）、今日へ＝暦を今日へ組み直すだけ。持ち主（`mine("list")` か
  `mine("prices")`）でなければ黙るのは同じ。
- **虫めがね**：両画面の `wireSearch` に `els.searchBtn = KN.head.els.searchBtn` と
  `els.mine` を渡す。窓は各画面の `.stack` の頭（暦の下）のまま。歯車は head.js。
- **価格の地**：`#panes` が帯と暦のぶん低くなるだけで、器（`#screen-prices` が自分で
  送る）も `--face-d` / `--face-cut`（どちらも取るときに実測）もそのまま効いた。
  直したところは無い。試験で、月に開いた暦でも「地は帯の下端から始まる・最後の
  行が下の帯より上まで送れる・留まった紙の頭は下の帯のすぐ上」を見ている。
- 試験：`tests/head-still.js` の `hops` に list を足して十二通り（価格は帯に席が
  無いので、掴み手を本物のタッチで引いて入り、帯の「買うもの」で戻る・価格から
  やること／ダイエットへ、を別に測る）。「買うものでは帯が隠れる」は「買うもの
  でも帯が動かない」に替えた。

## 段4で入れたもの（2026年9月27日。実機で気づいた二つ）

- **席を移るとき、暦の印だけを重ねて替える**（`head.js` の `snapMarks` /
  `crossMarks`、`base.css` の `.head-ghost` / `.cal.is-marks-in`）。前は要素を
  差し替えた一拍で印がいきなり替わり、「急に出てくる」感じがした。
  - `enter(id)` で持ち主が替わるとき、出ていく暦の `.cal-dots`（中身のあるもの・
    伏せた週でないもの）を写して位置を測る。組み直しの**前**なので、配置は前の
    一拍のまま＝測るのが安い。
  - `putCal` が要素を差し替えたら、写しを帯の直下の `.head-ghost` に同じ位置で
    重ねて薄れさせ（`--ease-in`）、入ってきた暦には `is-marks-in` を付けて印を
    浮かばせる（`--ease-out`）。長さは紙が流れるのと同じ `--m-nav`。済んだら
    写しを外し、class も外す。要素が同じ（買うもの⇄価格）なら何もしない。
  - **写しは `.cal` の外に置く。** 暦の中に置くと「帯の暦は一枚だけ」「daily の
    暦にダイエットの棒が無い」が、重ねのあいだだけ嘘になる（試験もそこを
    `#head .cal ...` で見ている）。写しは `aria-hidden`・`pointer-events: none`。
    暦（`--z-stick`、地が塗ってある）より手前に要るので同じ段に置き、あとに
    書かれたぶん上に来る。`.head` に `position: relative` を足した（配置は
    変わらない）。
  - 動きを減らす設定では写しを撮らない（`KN.motion.still()`）。
- **買うものの暦に、その日に買ったものの丸**（`head.js` の `boughtByDay` /
  `boughtArt` / `marksHtml`）。やることの暦と同じ `.cal-mark`（カテゴリの色に
  染まった丸・中は白抜きの品物の絵）。同じ品物は一つ、買った順に三つまで。
  隣の月のマス（週の端）にも出す。
  - 材料は daily の「その日に買ったもの」（`store.dayFeed` の③）と同じ——
    チェックの付いた項目の `checkedAt`。写しの入れ物は増やしていない。
    `checkedAt` は UTC の ISO なので `dayKey(new Date(...))` でローカルの日に直す。
  - 絵を決める順は `store.productMark` と同じ（手で選んだ絵→名前→カテゴリの名前）。
    当たらなければ、やることと同じ小さな丸（`.todo-mark.is-plain`）。包みの絵
    （`productIcons.fallback`）は色つきで、白抜きの丸に入れると塗りが潰れるので
    使わない。引いた答えは覚えておく（`findKey` が重いので）。
  - 暦は買うもの・価格の `render()` のたびに組み直される（前から）ので、買った・
    戻したは次の組み直しで印に出る。
- 試験：`tests/head-still.js` に「移った直後に写しが同じ位置で重なる・入ってきた
  暦は浮かぶ途中・暦は一枚のまま・写しは押せない・流れ終わると消える」と
  「買った日に丸が三つまで・買っていない日は出ない・丸の中に絵とカテゴリの色」を
  足した（113件）。

## 段4のあと、実機で直したもの（2026年9月27日）

- **印の替えは「重ねる」から「順に」へ。** 写しが薄れるのと、入ってきた印が
  浮かぶのを同時にしていたので、半ばで両方が半分ずつ見え、同じマスに二タブ
  ぶんの印が重なって見えた。いまは写しが `--m-marks`（0.2秒）で消えきって
  から、入ってきた印が同じ長さで出る（CSS の `animation-delay` に同じ
  `--m-marks`。`both` なので待つあいだは見えない）。写しを外すのは二回ぶん
  ＋40ms のあと。長さは `--m-nav` から切り離した（紙の流れと揃える必要は
  無く、順にすると `--m-nav` 二回では長すぎるので）。
- **ダイエットの飲酒の帯を淡く。** 地の色そのまま（青 `#4a8fd9`・`--c-primary`・
  `--c-danger`）で、暦の中でそこだけ濃く浮いていた。`.cal-mark` の丸と同じく
  地へ 55% 混ぜる（`.cal-bar i` の `--bar` に元の色を置き、混ぜるのは一か所）。
  青は直書きをやめて `--c-m-drink`（明るい基調では同じ値）、緑は塗りなので
  `--c-primary-fill`。
- 試験：`tests/head-still.js` に「写しと入ってきた印は、同時には見えない
  （毎フレーム測る）」「飲酒の帯は淡い色（元の色と地のあいだ）」（115件）。

- **印の替えを「順に」から「半分ずつ重ねて、ゆっくり」へ（2026年9月27日）。**
  消えきってから出すと間が空いて急に見えたので、`--m-marks` を 0.4秒に延ばし、
  入ってくる印の `animation-delay` を `calc(var(--m-marks) / 2)` に。多少
  重なるのは受け入れた（利用者の判断）。写しを外すのは一回半＋40ms のあと。
  試験は「同時には見えない」から「薄れはじめてから出る・重なる一拍がある」へ。

## このあとへ持ち越す注意（段4で整理。計画としてはここで一区切り）

- **実機で見ること**：
  - 印の替え（`--m-marks`＝0.4秒、半分ずらして重ねる）が「ふわっと」に足りるか。
    変えるなら `--m-marks` の値だけ——数字で書かない。
  - 買うもの・価格の暦は縦を取る（月に開くと、買うものの紙は画面の半分ほど）。
    「買い物のときだけ暦をしまう」は設定が一つなのでできない（決めなくても
    起きること）。狭さが気になるなら、そこで相談。
  - 掴み手の上下の往復・価格の地の送りの、指の感触（引き始めの重さ・留まった頭の
    掴みやすさ）。
- **暦の月は、まだ画面ごと**（段2から持ち越し）。日を動かさずに月だけめくって
  から別のタブへ移ると、入ったタブは共通の日の月を出す——帯の枠は動かないが、
  盤の中身（数字）が替わる。このときの印の替えは位置が合わない（写しは前の月の
  マスの位置で薄れる）。数字ごと替わる場面なので目立たないが、暦の月を一つに
  するなら一緒に見直す。
- **暦を組む仕掛けは四つ**（やること・daily・ダイエットの `fillCalendar` と、
  `head.js` の `fill`）。まとめるときは `calendar-swipe.md` の決めごと（`data-day`
  を外す・`--cal-h` の床・送りの覚え書き・払い終わりに組み直さない）を一つずつ
  引き継ぐこと。
- 買うもので日を選んでも紙は何も変わらない。暦に丸は出るようになったが、
  「その日に買ったもの」を紙に並べる拡張は未着手（決めたことの2）。
- やることが一件も無いとき、紙は「ありません」の一枚で、**掴み手が暦に
  結ばれない**（前からの作り。試験は一件足してから引いている）。
