## 1. 一言でいうと

2.0 は**作り直しではなく、再編集**。今ある画面・記録・iPhone で詰めてきた手触りは残し、
四つのことだけをする。

1. **同じ物は、どこへ行っても同じ物として動く**（変形）。連れが停留所になる。やることが
   明日へ運ばれる。＋が紙になる。買ったものが束へしまわれる。カードが紙になり、閉じれば
   そのカードへ帰る。
2. **道と人を、くらしノートにしか無いものとして育てる。** 人は「いま」まで歩いて追いつき、
   角では下へ回る向きになる。
3. **動き・身ぶり・紙の決まりを表にする**（動きの辞書・身ぶりの表）。新しい動きは、表に行を
   足してから作る。
4. **見た目は、見比べてから変える。** ガラス・カード・daily・からだ・ノートは、見比べの画像と
   重さを見て利用者が選ぶ。大きく変わるものは、設定の奥の切り替えで前と比べてから既定にする。

機能を足すのが目的ではない。足す動きは、どれも「いま何が起きたか」を見せるためのもの。

### 段A 土台

**V1 2.0 の切り替え**
- 何を：設定の外観の奥（`more()` で畳む）に切り替えを一つ。既定はオフ。オンなら `html` に印を
  一つ（例：`.is-v2`）付ける。付け外しは起動時と切り替えたときだけ（毎フレーム書かない。traps.md）。
- 2.0 の見た目の CSS は `.is-v2` の下にだけ書く。前の見た目は触らない＝オフにすれば一押しで戻る。
- 比べ終えたら V26 で、採ったほうだけ残して印を外す。
- データ：`settings` に一つ（`reconcile()` で既定 false）。
- 試験：オンとオフで主な画面が開く・`daily-rules.js`。
- **できた（2026年10月4日）**：設定 → 外観のいちばん下、畳んだ「試す」の奥に「2.0 の見た目」。
  `settings.v2`（`reconcile()` で true 以外は false）、`KN.app.applyV2()` が起動時と押したときに
  `html.is-v2` を付け外す。試験は `tests/v2-switch.js`。

**V2 速さの台本**
- 何を：`tests/` に台本を一つ（名前は作るときに）。CDP で CPU を4倍遅くし、日の横払い・一覧の送り・
  道を開く・帯を押す・紙を開く、のあいだの `requestAnimationFrame` の間隔を集め、長いフレーム
  （20ms 超）の数と 95% 点を出す。
- **門（`run-all.js --gate`）には入れない。** 機械の揺れで誤って止めないため。動きを足す項目の
  前後で手で回し、数字をその項目の節に書く（試験のブラウザの数字で、個人の記録ではない）。
- 厳密に言うと：試験のブラウザ（Chromium）と iPhone の Safari は描き方が違う。特にぼかし
  （`backdrop-filter`）の重さは目安にしかならない。最後は iPhone で触る。
- **できた（2026年10月4日）**：`tests/frame-pace.js`（run-all からも外した。`RUNS=<n>` の中央値、
  `V2=1` で `.is-v2` を付けて測る）。`page.clock` を使うと rAF が作り物の 16ms 刻みになるので使わない。

  道を開く 72／1／16.7ms・日の横払い 107／1／16.8ms・一覧の送り 108／4〜6／16.8〜33.3ms・
  紙を開く 44／12／33.4ms。揺れは ±2 フレームほど。紙を開くの重さが目立つ。

## 6. データを守る（2.0 全体）

- **移行は無い。** 足す鍵は二つの見込み：切り替え（V1、`settings`）と、前に見た点（V6、store の外か

## 7. やらないこと（2.0 で決めたもの）

| やらないこと | 理由 |
|---|---|
| AI の補助（写真から推定・自然文の解釈・検索の補助） | 利用者が反対（2026年10月4日）。柱1「端末の中の決まりだけ」。R30・R34 の答えとも揃う |
| 頭の「買うもの｜価格」の切り替え | 利用者が反対。掴み手と席の二度押しで足りている |
| 買い物中の姿（大きな字と✓だけの画面） | 店で困っていない |
| 上向き・斜め上の人 | 道に出てこない向き |
| 行の左右払い（その場で済ませる・送る） | 紙の横払い（日を移る、三画面共通）とぶつかる |
| 同じ時刻の停留所を一点に集める | 始まりが重なれば押して並べ、群の札に「ほか n」で足りる。一点に集めると「同時にする」と読める |
| JS を分けるためだけに分ける | 触る所だけ（読み込み順・TDZ・3か所の登録の事故の芽） |
| `-2.0.md` を何本も作る | 既存の docs と二重になる。本書一本＋該当する節 |
| 全部の画面・操作に動きを付ける | 意味のある変形だけ。何が起きたかを一行で言えない動きは作らない |
