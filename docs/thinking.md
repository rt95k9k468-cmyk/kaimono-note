# 思考のホーム（daily の冒頭・時刻ごとの日記・ノートへ移す・問い・読んだところ）

2026年10月12日。利用者の頼み：日々の記録だけでなく、思考・読書・研究を深められるように。書く前に分類を
選ばせない・達成と変化はやめる・種と読書はノートへ・日記は時刻つきの積み上げ・問いの一覧。
試験は `tests/diary-chat.js`・`tests/asks.js`。

## 決めたこと

- **冒頭は三枚の札と今日の問い**（10月12日夜・利用者の見本の画像と水彩の絵。`img/think/`）。「日記に書く」＝書く紙、
  「ノートを書く」＝その場で新しいノートの紙、「問い一覧」＝問いの一覧（10月12日、「問いから考える」から改名）。札の説明の副題は書かない（look の「説明は書かない」）。
  今日の問いは問いの元（`store.asks`）から日付で引く（問いの字はしまわない）。「別の問い」で進めた位置だけ設定 `askLast`（`{day,n}`。reconcile に足さず読むところで既定）に覚え、同じ日に開き直せば前回の続きから。その日より前に
  「？問い」を書いた問い（日記・作った日が前のノート）は引かない（全部書いたら一周）。三つに一つは自分で書いた「？」の問い
  （元の並びに無いもの）を「あなたの問い」として出し、「この問いから考える」は写さず書いたところ（ノートの行・その日）へ。
  答えの中身は読まない・覚えない（引くのは「？」の行の字だけ）。「この問いから考える」は**答える紙**
  （`KN.screens.notes.answer`。問いは欄の外＝答えに混ざらない・消せない。ノートが開けないときだけ「？問い」を頭に置いた日記の紙）。問いの言葉に評価の言葉を入れない（daily-rules）。
  札と今日の問いの地は半透明（`--think-a`・`--think-blur`。後ろの絵が見える程度に軽くぼかす。利用者の頼み。ぼかしが効かない・コントラストを上げる環境は透かさない）。札に「＞」は付けない。「この問いから考える」も塗り潰さず透けた地に主色を薄く（浮かせない）。
- **答える紙の保存**：閉じたとき（裏へ回る瞬間も）、頭の行を「？問い」にした新しいノート。同じ問いのノート（頭の行が
  その問い）があれば、終わりに「10月12日(月) 08:52」の行と答えを足す。打たずに閉じれば書かない。日記の書く紙のボタンは「保存する」。
- **問いの面**（10月15日・利用者の頼みで組み直し）：頭に「＋問いをつくる」、下へ「続きから考える」（答えのノート＝頭の行が
  「？問い」で中身のあるもの。最後に書いた順）・「まだの問い」（つくった問い＝頭の行だけのノートが頭、次に問いの元の
  まだのもの）・「ノート・日記に残した問い」（ほかの「？」の行・タグ。押せば元へ）・畳んだ「一区切り」。同じ問いは一度だけ。
  全部無いときだけ「問いはまだありません」。ノートの `onChange` は書いたときに来ないので、答えたあとは面を自分で組み直す。
  - **答える紙**は前の答え（頭の行のあと）を読むだけで上に出し、続きは欄から終わりに足す（上書き・消しはしない）。空で閉じれば何も変えない。
  - **つくる**：「？問い」だけのノート（`makeAsk`。入れ物・同期・控え・書き出しはノートのまま）。同じ問い（元の百も）はつくらず
    「同じ問いがあります」＋開く。今日の問いには前の日につくったものが「あなたの問い」で混ざり、押せば答える紙。
  - **一区切り**は答える紙の左下（「再開する」に替わる）。しまい先は設定 `askRest`（問いの字の鍵 → 時刻。reconcile に足さず
    読むところで既定）。問い・答えは触らない。続きを書けば再開。今日の問いに引かない。自動の判定はしない。
- **書く入口は一つ。** daily の冒頭の「日記に書く」と＋は、種類を選ばずに書く紙。書いたものはその日の日記の一件
  （時刻つき）。あとから「⋯」→「ノートへ移す」（新しいノート／選んだノートの終わり）。
- **積み上げはやめた**（同じ日の二度めの頼み）。下の「積み上げをやめた」。
- **種・問いはタグ。** タグの小窓に、まだ使っていなくても「種」「問い」を並べる（押せば付く）。
- **問い**＝行の中身（行頭の印のあと）が「？」か「?」で始まる行（ノートと日記）＋タグ「問い」のノート。
  ノートのホームの「問い」の行と daily の札から一覧へ。押せば元のノートのその行・その日の daily。数は出さない。
- **読書・論文はノートで。** 「⋯」→「読んだところ」が終わりに「### 10月12日 p.」（論文のタグなら「p.」なし）を
  足して、続きへカーソル。下に書くのは自分の気づき・問い・やってみること（チェック）。要約の欄・AI の口は作らない。
- **日記の見せ方**：時刻ごと（既定）／一枚（設定 → daily → 表示 → 日記）。一枚は前の紙のまま（冒頭の口も出さない。
  ＋はその日の日記の紙）。
- **時刻ごとは吹き出し**（10月13日・利用者の見本の C 案）：小さな時刻の下に角丸の地。一列・左揃え・影なし・相手役なし。
  地は透かして後ろの絵を見せる（利用者の頼み。数が多いので `backdrop-filter` は掛けない。コントラストを上げる環境は透かさない）。
  時刻の無い頭も時刻なしの吹き出し。長い一件は頭の三行と終わりの三行で畳み（間に「全文を読む」。終わりは写しの `.arc-post-tail`）。**吹き出しを押すと伸び縮み**（長いときだけ。
  短い一件は押しても何も起きない）。**直す・コピー（その一件の字だけ）は左の余白のボタン**（日付の欄の幅に縦二つ・
  吹き出しの高さのまん中。押す先が伸び縮みと被らないように。吹き出しの幅は変えない）。日付と育休の行だけの頭には出さない。
  畳むかは置かれてから測る（`watchFold`。隣の日の紙は document の外で組むので）。開いた一件は組み直しても開いたまま。

## 形（データ。移行なし）

- **日記の本文は一つの文字のまま**（`archive.days[].memo`）。一件＝**このアプリが書いた時刻の行**（`08:52` の終わりに
  見えない印 U+2060。書いた日が日記の日と違えば `10/12 08:52`＋印）から次のその行の前まで。一件目より前は頭（日付と
  育休の行・前からの地の文）。見分けるときだけ NFKC（全角の字も読む）。`js/diary-posts.js`（文字だけ。DOM・store に触らない）。
  - **印の無い時刻の行は分けない**（10月13日）。前は「時刻だけの行」なら何でも区切りで、前からの本文・取り込んだ本文の
    `6:30` で切れて見えた。本文の中の印なら、日ごとの欄と違って写し・控え・同期で本文とずれない。
  - 10月12〜13日の版が書いた一件（印なし）も分けずに一件で見せる（利用者が選んだ。推測で印を足さない）。
  - 印は NFKC でも `trim()`・`\s` でも落ちない。よそのアプリで落ちれば、その日は分けずに一件で見えるだけ（字は失わない）。
  - だから写し（diary-idb）・控え・書き出し・取り込み・コピー・検索・鍵は、何も変えずに同じ本文を運ぶ。
- 足す：終わりの空白を落として、空の行一つ・時刻の行・中身。本文の無い日は頭に `dailyStamp`（コピーは日付を
  言わないので、一枚の紙の下書きと同じものを置く）。時刻は打ち始めた時。
- 直す・外す：**開いたときの字が同じ場所にあるときだけ**（`swap`・`take`）。無ければ書かない——直す紙は上書きせず
  新しい一件として残す（どちらに転んでも字は消えない）。**開いて閉じただけでは書かない**（空行の多い一件の形も
  変えない）。直しても時刻の行は打ったまま。空にして閉じると外れ、「元に戻す」。
- ノートへ移す：ノートに書き、`KN.notes.flush()` のあと `KN.notes.pending(id)` が偽（入れ物に書けた）なら日記から
  外す。書けなければ日記はそのまま。日記がそのあいだに変わっていたら外さない（「ノートに写しました」）。
  新しいノートの作った日＝その一件の時刻。前からのノートには「10月12日(月) 08:52」の行と字を終わりに。
  元に戻すで両方戻る（新しいノートは手を入れていなければ消す、入れていれば最近削除へ）。
- 問いはどこにもしまわない（開くたびに引く）。ノートの形・入れ物の版・同期の欄（`notes-sync.js` の FIELDS）・
  書き出しは変えていない（「？」もタグも、前からある本文と欄）。
- **問いの元は端末の記録 `store.asks`＝`{ g, w, from, hint, q }` にだけ持つ。配る器（js/）には載せない**（10月16日・利用者。
  利用者の記述から書いた字で、GitHub Pages は誰でも読める）。`js/ask-list.js` で配っていた分は一度だけ写してから
  外した（ファイルごと）。新しく書いて渡すときは .json を利用者へ送るだけで、リポジトリには置かない（下書きも）。入れ替えは設定 → バックアップ →「問いの元を取り込む」（`{ kind: "asks", asks: [...] }`。前に控えを取る）。
  丸ごとのバックアップには乗る。asks の無い古い控えから戻すと空になる——取り込み直す。元が無い端末で自分の問いも無ければ、
  今日の問いの札は出さない。試験は `tests/lib.js` の `ASKS`（無難な字）を入れて使う。答えたかは本文で
  照らす（欄を足しても記録は作り替えない）。重さは今日の問いを引く日にだけ効かせる（平日は 3 を、休みの日は 1 を外す。
  外すと空なら外さない）。画面に出さない（daily は評価しない）。
  - **出典（from）と文脈（hint）は利用者の記述群から書いた**（10月15日・利用者の頼み。思い出すきっかけで要約ではない）。
    今日の問いと答える紙で、太字の問いの下に畳まずに出す（`.ask-ctx`）。一覧は出典だけ。人の名前（家族は妻・娘のように続き柄で）・
    daily-rules の言葉は入れない（渡す前に照らす）。門の `daily-rules.js` は、配る器に問いの元が無いことを見張る。
- 設定 `diaryView`：`"page"` だけ一枚。無い・ほかの値は時刻ごと（reconcile に足していない。読むところで既定）。

## 積み上げをやめた（2026年10月12日・利用者の頼み）

- 前からの記録（`archive.entries`）は**一度だけ一冊のノートへ**（`js/entries-note.js`）。題「積み上げ（〜2026年10月）」・
  タグなし・日付の古い順（同じ日は書いた順）。日ごとに `### 2026年10月3日(土)`、一件は頭の行
  「読書『題』著者 p.10–30・08:30から30分・タグ」（論文は「論文」）と、下にメモそのまま。
- **記録そのものは消さない・書き換えない**（保存にも控えにも残る。まとめ方を誤っても作り直せる）。
- 印は設定 `entriesNote`（ノートの id、積み上げの無い端末は `""`）。`addMany` で書けてから付ける——書けなければ次の
  起動でもう一度。ノートの id は `n-tsumiage` に決めてあり、それがあれば（最近削除でも）作らない＝二台でも一冊。
- 画面から外したもの：daily の積み上げの段・記録の紙・暦の種類の絵・まとめの「積み上げ」・「あの日」の記録の行・
  設定（積み上げのメモ・上に出すもの）・ぜんぶをさがす・年の本の章・ノートの橋の札・やることの「積み上げ『…』」の札・
  daily の書き出し（月・期間）の `entries`/`counts`。「あの日」「年々」は地の文のある日だけ。
- 活動（道）：済ませても記録を作らない。道具箱を過ぎた時刻に置けば**済んだ act 付きの用事**。前からの積み上げで時刻と
  長さのあるものは道が読むだけで描き（`arc:`）、押せばこのノート。前に置いた長さ・「活動」の行は act 付きの用事と
  前からの記録の両方から引く（`activity.js` の `pastActs`）。試験は `tests/entries-note.js`・`tests/activity.js`。

## 罠

- 印を付けるのは `KN.diaryPosts.mark()` だけ。時刻の行を自分で組まない（印が無いと地の文になる）。試験は `tag()`。
- 一枚の紙で手で打った「08:30」の行は分けない（印が無い）。コピーには印が乗る（見えない）。
- 時刻ごとの行（`.arc-log-row.is-chat`）は押すものではない。直す紙は `.js-post-edit`、伸び縮みは吹き出し（キーは
  `.arc-post-more`）。ボタンは `click` を伝えない（吹き出しの伸び縮みに届かないように）。空の日・読めない日・
  本文を外した日は一枚のときと同じ一行（`daily-rules.js` の「この日のことを書く」）。
- 冒頭の口は `.day-slide` の頭。まとめ（`.arc-counts`）を上にしても Daily Log のすぐ上はまとめのまま。
- 一枚の紙を前提にする台本は `diaryView: "page"` にしてから（`daily-tail` ほか。台本の頭に書いてある）。

## やらなかったこと（いまは）と代わり

- 日記の一件にタグ → 本文に印を足さない。タグが要る一件はノートへ移してから。
- ノートに「読書」の欄（著者・ページを形で持つ）→ 本文の「### 月日 p.」とタグで。欄を足すと同期・書き出し・
  取り込みの三か所と形の版（`format`）に触る。
- 日記の一件と、移した先のノートのつながりを持つ → 持たない（移した先の頭の行の日付・時刻でたどる）。
