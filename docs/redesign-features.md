# 機能の計画「一冊だからできること」（2026年11月10日・全面リデザインの機能の側）

利用者の依頼（11月10日・二つめ）：「デザインだけでなく機能も最高に。アプリやサイトを調べ尽くして計画を。3月までの制約は一切考えずに」。
見た目と骨組みは `docs/redesign.md`（R1〜R8）。ここは**働き**——何を足し、何を採らないか。作る段のセッションは該当する節だけ読む。
調べたのは 2026年11月時点の公開情報（検索 約40回。頁を直に開く道はこの環境では閉じていたので、検索の要約による）。出典は 7節。

## 1. 見立て

- **働きの数では、もう最高峰に並んでいる。** 自然文の「いつ」・くり返し（済ませてから◯日・この回だけ）・自動の詰め・自分の速さ・
  長押しで時刻を動かす・記録から逆算した消費・飲みたくなったの図鑑・食事の言葉の候補・値段の移り変わり・あの日・年の本——
  Things・Structured・MacroFactor・Day One が売りにする働きの多くを既に持つ（2節）。見えにくいだけで、そこは redesign が直す。
- **足りないのは四つ。** ①3台の同期の仕上げ ②店を軸にした買い物（店で絞る・税・その場の値段）③ノートのつながり（リンク・
  戻りのリンク・記事の取り込み）④席をまたぐ気づき（一冊だから出せる。単機能のアプリには出せない）。あとは小さな足し。
- **2026年の流行の多くは採らない。** アプリの中の AI（Day One の Daily Chat・Todoist の Ramble・Tiimo の co-planner・写真からの食事）・
  連続記録やバッジ・気分の採点・集中タイマー・献立と家計——どれも利用者が前に断ったもの。3月の縛りとは別なので、そのまま。
- **iPhone の Web アプリに新しい口は増えていない**（Safari 27 はホーム画面の Web アプリに追加なし。共有の受け口・ウィジェット・
  バーコード・リンクで開く、は今も無い）。外との橋はこれからも ショートカット＋中継所＋Dropbox。

## 3. 足すもの

確かさ：◎＝無いことをコードで確かめた／○＝作る前に今の形を確かめる。どれも**記録の形は変えず**、欄を足すなら `reconcile()` で後方互換に。

**土台 B**
- **B1 同期を段5まで**（◎）：sync.md の順と門（影の2週間・利用者の「ずれなし」）のまま。3月の縛りが無くなったぶん、門が開きしだい次へ。
- **B2 保存の背骨**（○・**移行＝先に報告して訊く**）：元は localStorage（約5MB の枠）。数十年ぶんを持つなら IndexedDB を正に、
  localStorage は立ち上げの小さな写しに。同期が段5で落ち着いてから案を出す（storage.md「R26 の案」の続き）。それまで手を付けない。
- **B3 読み上げと鍵盤の総ざらい**（○）：VoiceOver で五つの席を一巡り（名札・順・済ませたの知らせ）。R8 と一緒に。

**shopping S**（いちばん効く。店と値段の記録は既にある）
- **S1 店で絞る・店ごとに分ける**（◎）：紙の頭に店の札（すべて｜店…）。押すと「その店が最安の品＋値段の無い品」だけ。
  「分ける」で最安の店ごとの束に並べ替える（合計は出さない）。並べ替えの `onCross` は束の中だけ。
- **S2 済ませたその場で値段**（○）：店で絞っているあいだ、丸を押した行に値段の欄が一拍だけ出る（その店・今日で保存。打たなければ消える）。
- **S3 税抜で打って税込で持つ**（◎）：値段の鍵盤に「税抜」の札。食品 8%・ほか 10%（カテゴリから。品ごとに直せる）。保存は今までどおり一つの数。
- **S4 底値の一言**（○）：品物の紙に「これまでの最安 ¥◯（店・日）」と、入れた値段が前回より上か下か。
- S5 店ごとの売り場の順（後で。S1 を使ってみてから）。

**notes N**
- **N1 リンクを書く・戻りを見る**（○書く口／◎戻り）：`[[` か道具の帯から題で選ぶ → `[題](note:id)`。ノートの足もとに「ここへのリンク」
  （本文から引く。欄は足さない）。題を変えても id なので切れない。
- **N2 受け口のフォルダと記事**（◎）：Dropbox の `inbox-notes/` に置いた .md・.txt・PDF を、次に開いたときノートへ取り込む
  （今の取り込みの道。元の URL は頭に一行）。Safari の共有 → ショートカット（記事を取り出す → Markdown → Dropbox に保存）で一手。
  中継所は通さない（鍵も worker も触らない）。
- **N3 マーカー**（◎）：`==字==`。見たままの編集・読む姿・書き出しに。色は山吹の淡い面一つ。
- **N4 ふと出会う**（◎）：ノートの入口に一枚——去年の今ごろ直したノート／長く開いていない★。数や促しは出さない。
- **N5 写して新しく**（○）：⋯ に。ひな形はこれで足りる。

**health H**
- **H1 見通し**（◎）：体重のカードに「この傾きなら 62.0kg は◯月◯日ごろ」。傾きが逆・記録が少ないときは出さない。日を選ぶと「その日はおよそ◯kg」。
- **H2 お酒の週**（○）：今週の純アルコール・本数に換算・飲まなかった日を一行の事実で（色で採点しない＝今の決め）。
- **H3 席をまたぐ気づき**（○）：`insights.js` に足す——飲んだ翌朝の体重／歩いた日の夜の睡眠／予定の多い日と飲みたくなった／
  夕食の時刻と翌朝の体重。出すのは「30日のうち◯日」の事実と、そろった日数。助言は書かない。

**tasks T**
- **T1 長さを引いて変える**（◎）：持ち上げた札の下の端を引くと5分きざみで長さ（今の持ち上げの続き。`tl-layout` の y の逆）。
- **T2 帯に合計と空き**（◎）：redesign の「一日の帯」に「予定 4時間30分・空き 3時間」。
- **T3 前の題で、手順・長さ・分類ごと**（◎）：題の候補を選んだら、その用事の手順も付く（外せる）。

**daily D**
- **D1 偶然の一日**（◎）：あの日の並びの端に「どこかの一日」。押すたびに書いてある日のどれかへ。

**共通 X**
- **X1 さがすを一つに**（○）：どの席でも同じ窓・同じ並び（いまの席の当たりを先に、続けてほかの席・日付の言葉・設定の入口）。
- **X2 鍵盤だけで一通り**（○・広い幅）：1〜5 で席、N で足す、↑↓ で行、Space で済ませる、Enter で開く、/ でさがす、? で一覧。
- **X3 行の小窓**（○）：右クリックと長押しで、その行にできること（動かす・明日へ・写す・消す）。隠れた身ぶりを見える形に。
- **X4 ショートカットの作り方集**（○）：設定に、店に着いたら買うものを開く・寝る前に日記・Apple Watch から足す、の作り方（`more()` で畳む）。

## 4. 調べたうえで採らないもの

アプリの中の AI（会話で日記・声の束から用事・写真から食事）／連続記録・バッジ・気分の採点／集中タイマー・四象限／献立とレシピ・合計と家計・
チラシ／バーコード（iPhone の Web に読む道が無い）／ウィジェット・ロック画面・Siri の直の口（Web アプリに無い。ショートカットで代える）／
端末のカレンダーを重ねる（断られた。TimeTree は口を閉じた）／同期の様子をいつも出す（断られた）。理由は plan.md 3節のまま。

## 5. 訊くこと（答えが出るまで作らない）

1. **今日の一枚**：日記に写真を一日一枚だけ（置き場はノートの画像と同じ棚＝端末と Dropbox）。前は「置き場と控えが膨らむ」「手がかりは少し」で外した。
   置き場の心配は消えた。一枚だけなら「手がかりを少し」とも合う。最高峰の日記との、いちばん大きな差。
2. **天気の一行**：日ごとに天気と気温。自動なら中継所ごしに取りに行く（通信先が一つ増える）／手で選ぶ／入れない。
3. **しるし帳**：くり返しの用事を月の表に（済んだ日に印。連続の数・割合・色の警告は出さない）。tasks の月の面に。
4. **B2 保存の背骨**：時期が来たら案を出して訊く（移行なので）。
