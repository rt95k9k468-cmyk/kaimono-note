# 買うもの・価格（紙と、その後ろの地）

CLAUDE.md から見出しごと移した、詳しい決めごと（2026年9月26日）。
本文は移す前と一字も変えていない。入口（どの docs を読むか）と、どの画面でも
踏む罠は CLAUDE.md にある。**新しい決めごとは、ここ（該当する docs）に書く。**

### 買うものの紙と、その後ろの地としての価格

**2026年9月27日（段3）から、上の帯は全タブで一つ**（docs/shared-header.md）。
買うもの・価格の自前の帯は無く、**題は日付のまま入れ替わらない**。下の節の
「題の入れ替わり」（`.face-t`・決まり目・「買うもの」＋「価格」が一塊）の話は
経緯として残してあるが、いま入れ替わるのは**札の帯だけ**。「後ろの面は自分の
バーを伏せる」のバーも、もう無い（探す欄と札は伏せる）。

#### 価格への入口は帯の「shopping」
**2026年9月28日から、価格への入口は帯の「shopping」**（利用者：「shopping
タブでも、持ち手を下に引くと暦が週から月に変わるように。その代わりに
shopping のアイコンを押すと prices になるように」）。

- **買うものの掴み手は暦のもの**（ほかのタブと同じ `cal-peek.js` の三段。
  暦は head.js が持つので、結ぶのも `KN.head.shopPeek`）。押しても何も
  起きない——`role` も名札も外し、`aria-hidden`（ほかのタブの掴み手と同じ）。
  探しているあいだは引かない。
- **買うものに居るところで帯の「shopping」を押すと、紙が下がって価格へ**
  （`faceTo(1)`、動きは前に掴み手を引いたときと同じ）。価格でもう一度押すと
  戻る（`faceTo(0)`、前から）。よそのタブから押したときは買うもの。
- **価格から戻る手つきはそのまま**：留まった紙の頭を上へ引く・押す
  （`wireFaceGrip`）。価格の画面に暦は関係ないので。掴み手が一本で二役なので、
  `wireFaceGrip` は紙が上に居るあいだ（`faceAt()` が 0）は何もせず、`cal-peek`
  は紙が留まっているあいだは引かない（`KN.app.faceAt` を見る）。名札と role は
  `syncFaceGrips` が state に合わせる——`faceUnpark` からも呼ぶこと（価格から
  よそのタブへ移ると faceSettle を通らないので、呼ばないと押せる名札が残る）。
- **買うもののカテゴリの札の帯は外した**（「使わないから」）。札があると暦と
  掴み手のあいだに一段はさまって、ほかのタブと同じ形にならない。絞り込み
  （`categoryFilter`）ごと外したので、送る文の題に札の名前が付くことも、
  「このカテゴリに未購入の商品はありません」も無くなった。カテゴリの組・
  切れ目の線・丸の色はそのまま。**価格の札は残す**（品数が多く、絞る場面が
  あるので）。
- 札の入れ替わり（下の「帯の中身は、じわっと入れ替わる」）は、入れ替える相手が
  いなくなったので外した。買うものの紙は暦のすぐ下から始まり、価格の札はその
  紙の下に居て、紙が下がると露出する。地は後ろの札が持ったまま。
- 以下の節の「掴み手を下げると価格へ」「札と題の入れ替わり」は経緯として残す。
- 試験：`tests/head-still.js`（帯を押して価格へ・紙が下がって行く・頭を本物の
  タッチで上へ引いて戻る／戻っても暦の段は変わらない・買うものの掴み手で
  週→月→週→暦なし→週・押しても価格へ行かない・札の帯が無い）。

#### 9月28日（夜）の手直し
**2026年9月28日（夜）の手直し**（実機で見て）。

- **価格から戻るとき、一瞬後ろが暗くなっていた。** 戻りきる直前まで、紙の
  落ち影（`.14`）と価格の札の帯（地つき）が紙の上に居残り、着いた瞬間に
  ぱっと消えていた。価格の札の帯は買うものの紙の頭より**上**から始まるので、
  紙が戻っても覆われない。どちらも `--face-p` の 0〜.3 で薄れさせる
  （影は `rgba(…, calc(.14 * clamp(0, p/.3, 1)))`、札の帯は `opacity`。離して
  滑るあいだは `is-face-settle` で両方に `transition`）。実測：頭が家から 12px
  以内のフレームで、影 0.14 → 0.00・札の帯 1 → 0.00。
- **戻るのが速すぎた。** 紙の行き来は `glide` の基準を `--m-face`（.46s）に。
  払い（`--m-swipe` .28s）と同じ基準では、画面の丈ほどの紙一枚が駆け抜ける。
- **その日に買ったもの。** 暦で今日でない日に合わせると、その日に買ったもの
  （`checkedAt` をローカルの日で）が紙の頭に出る（`dayBought`）。行はアーカイブの
  行そのまま——線と薄さが「過去」の印。下のリストはそのまま（買うものは日に
  属さない）。今日・何も買っていない日・探しているあいだは出さない。記録の
  入れ物は増やさない（暦の丸と同じ相手から、そのつど引く）。同じ行が下の
  アーカイブにも居るので、`data-flip` は `day:<id>` に替える（同じだと
  flipRows が取り違える）。日を動かすのは head.js の `pick` / `shopGo` / 週の
  払いで、そこから `dayMoved` で紙の中身だけ組み直す。
- 試験：`tests/shop-day.js`。

#### 同じ日（夜・二度目）の手直し
**同じ日（夜・二度目）の手直し**（実機で見て）。

- **前の日から帯の「今日へ戻る」で戻ると、紙が前の日のままだった。** head.js の
  ボタンは `sDay = null` にして暦を塗り直すだけで、`dayMoved` を呼んでいなかった
  （試験は `shopGo(今日)` で戻っていたので通っていた）。ボタンも `shopGo` を
  通すようにした——日を動かす道は `pick` / `shopGo` / 週の払いの三つだけにして、
  どれも `dayMoved` を呼ぶ。新しい道を足すなら `shopGo` を通すこと。
- **買うものの行の横払い（右で★・左でアーカイブ）は外した**（利用者：「左右
  フリックで日付を変えたいので」）。行の上で指が二つの意味を取り合うので。
  day-swipe の `ignore` から `.item-wrap` を外し、行の上からも日を払える。
  ★は行の★を押す。**アーカイブは価格の画面の払いで**（価格・やることの行の
  払いは残す——`KN.ui.swipeActions` はそちらが使う）。
- 試験：`tests/shop-day.js` に、ボタンで戻る道と、行の上を本物のタッチで払うと
  日が動き★もアーカイブも起きないこと。

#### 紙は一枚、後ろは地（二組）
**2026年10月1日から、この「紙と後ろの地」は二組**（daily の裏にノート。
`app.js` の `PAIRS`。docs/notes.md）。`faceTo(p, id)`・`faceAt(id)` は組を
名指しできる（名指ししなければ、いま居る画面の組）。

**紙は一枚だけです。** 買うものの紙が一枚あり、その後ろにあるのは価格の
**地**——札も一覧も、面に乗らずに並んでいるだけ。掴み手を下げると紙が
**指について**下がり、後ろの地が露出します（`KN.app.wireFaceGrip`、
`role: "front"`）。

**前は二枚ありました。それが崩れの原因でした。** `screen-prices.js` も
買うものと同じ `.tl-sheet` ＋ `.tl-grip` を組んでいたので、めくっている
最中に**丸角の白い紙と掴み手が二組**そろって出ていました（実測：背面の紙も
掴み手も top 42、前面のものと同時に見えていた）。「乗っている」を、二枚の
ページを重ねて片方をずらすことで表そうとしていた、ということです。
**丸角と掴み手を持てるのは、前に居る一枚だけ**——それが「乗っている」の
意味なので。価格の側は `.prices-ground`（面なし・丸角なし・掴み手なし）。

- 価格の行は、もともと地の上で読めるように作られていた
  （`.product-wrap:not(.is-tile-wrap) .product` は `background: none`、
  区切りは上の細い線、絵の丸の地は `color-mix(--cat 16%, var(--c-bg))`
  ——**地の色を混ぜてある**）。白い紙は、そこに要らないものだった。
#### 動くのは紙だけ・帯の中身の入れ替わり
- **動くのは紙だけ。二つの帯——題も、カテゴリの札も——動かない。**
  札の帯も紙と一緒に下げていた（「札は紙の連れだから」）。実機で見ると
  **帯までが指について降りてくる**——紙が下がるのではなく、画面ごと崩れて
  いくように見える。この二つはどちらか一方の面の持ちものではなく、
  **器の側の帯**：位置はいつも同じで、変わるのは**中身だけ**。
- **帯の中身は、じわっと入れ替わる。順に、重ねずに。**
  前の札と題が薄れきってから（p .04→.30）、後ろのが出てくる（p .30→.62）。
  クロスフェードを外した理由（日本語は字が詰まっていて、二語が重なると
  別の字に読める。実測「買うもの」＋「価格」が一塊）は生きているので、
  **重ねない**。決まり目で切り替える階段はやめたが、同時には見せない。
  **札と題は同じ拍・同じ区間**にすること。
  - 地は**後ろの札が持つ**（`background`、薄めない）。前を薄めただけだと、
    消えきった一瞬に地も無くなって、札の帯に価格の行が透ける。
  - 離した先へ滑るあいだは、濃さにも `transition` を掛ける（`is-face-settle`
    を**二枚とも**に付ける）。指で引くあいだは `--face-p` が毎フレーム動く
    ので要らないが、離すと数が一度に跳んで、紙だけが滑って題と札はぱっと
    切り替わった。
- 数はひとつ（`--face-p`、0〜1）。紙の位置も題と札の入れ替わりも、そこから
  出る。**書くのは `#screens`**（前の面ではない）——カスタムプロパティは
  書いた要素から下へしか伝わらないので、前の面に書くと**後ろの面から読め
  ない**。後ろの札もこの数を読むので、二枚の親まで上げる。
  道のりは `--face-d`（紙の頭から、下の帯の上まで）で、**取ると決めた時に
  一度だけ**測る——途中で測り直すと指の下で速さが変わる（暦の `span` と
  同じ決めごと）。指の換算にも同じ数を使うこと。
#### 測るのは掴み手
- **測るのは掴み手**（紙の箱の上端ではない）。掴み手は sticky でいつも
  見えている「頭」そのものなので、一覧を下へ送ってあっても同じところに
  留まる。紙の箱の上端は、送った先では画面の外にいる。
- 後ろの面は**自分の上の一組——バー・探す欄・カテゴリの札——をまとめて
  伏せる**（`visibility: hidden`。`display:none` にすると、伏せたぶんだけ
  後ろの一覧が上がって、着いた瞬間に下へ跳ぶ）。そこには前の面の同じ三つが
  居るので、二枚重ねると字が重なる。
  **札が抜けていた。** 伏せていたのはバーと探す欄だけで、札はそのまま出て
  いた。前の札は紙の連れなので紙と一緒に下がり、空いた同じ場所へ後ろの札が
  居残る——実測で、前の札が top 300、後ろの札が top 42 に並んでいた
  （＝**二段の札**）。札は「その面の上の一組」の一部なので、バーと探す欄と
  同じときに伏せるのが正しい。
- 前の面は**地を透かす**（`background: none`）。そのぶん、地を持っていな
  かった**探す欄とカテゴリの札には地を敷く**——敷かないと、札のあいだから
  後ろの一覧の行が覗く（実測：札の隙間に価格側の牛乳の絵が出ていた）。
- 行き先は 0（買うものが全面）か 1（下がりきって価格が全面）。途中で離したら
  近いほうへ滑る（`FACE_DONE` = 0.26）。着いてから `show(..., "settled")`
  ——「呼んだ側がもう動かし終えた」の合図で、ここで重ねて動かすと指で置いた
  ところから跳ねます。
- **題は量ではなく名前なので、途中の姿を持たない。** 決まり目（0.26）で
  ぱっと入れ替える（`.face-t`、`clamp` を1000倍して階段にする）。薄めて
  重ねるのも縦に送るのも試したが、どちらも途中で二語が同時に見えた
  ——日本語は字が詰まっているので、重なると別の字に読める（実測：
  「買うもの」と「価格」が一塊になった）。
#### 価格はタブではない・掴み手は押しても効く
- **価格はタブではない。** 帯は四つ（daily／やること／買うもの／ダイエット）
  で、ふた面の点も無い。帯が言うのはその席の名前で、価格を見ているあいだも
  「買うもの」のまま——いま居るのは買うもののタブで、その紙を下げているだけ
  なので。`TABS` の `holds: ["prices"]` が「この席が受け持つ画面」。
  帯を押したら**紙を戻す**（`KN.app.faceTo(0)`）——差し替えではなく。
- **掴み手は、押しても効く**（`role="button"` / Enter / 空白）。引くのが
  本筋だが、そこにしか道が無いと、指で引ける人しか価格へ行けない。暦の段と
  違って、あちらにはこの画面でしか見られない中身（商品・値段・店）がある。
  やること・daily・ダイエットの掴み手は**引くだけのまま**（あちらは押しても
  何も起きない）。
#### 価格に着いたら紙は頭だけ残って留まる（`is-face-parked`）
- **価格に着いたら、買うものの紙は頭だけ残って留まる**（`is-face-parked`）。
  下げきったところで紙を画面から出しきると、**指で戻る道がどこにも無く
  なる**——価格は地なので掴み手を持てないから。のぞかせる量は掴み手ぶん
  （`--face-peek`、app.js が実測して書く。数字を二か所に書かない）。
  実測：紙 top 750／掴み手 750〜779／下の帯の上端 779。
  - **中身はそのまま持たせる。** 一度 `max-height` で頭だけに切った
    ——すりガラスの帯を通して買うものの行が透けるのが気になったので。
    **やめた**：あれは紙が下へ滑っていっただけで、下に隠れているのは本当に
    その紙の続き。切ると、頭は「紙の頭」ではなくそこに貼られた棒になる。
    （切っていたころは、`overflow: hidden` が紙そのものを「送る器」に変えて
    sticky の基準が画面から紙へ移り、掴み手が 750 のはずが 793＝下の帯の裏へ
    落ちた。切らないなら、その手当ても要らない。）
  - 触れるのは掴み手だけ（面は `pointer-events: none`）。紙の本体は帯の下に
    隠れているので、触れるようにすると帯ごしに買うものの行を押せてしまう。
  - **かわりに、掴み手のすぐ下から薄れさせる**（`--face-fade`）。切らないと
    決めた以上、続きは下の帯の裏にいる。帯はガラスなので、そこに居る行の字が
    **そのまま透けて帯の字と重なっていた**——実測：掴み手より下の **12.9%** の
    画素に中身が出ていて、「玉ねぎ」「¥158」「業務スーパー」が tasks・health の
    字の上に並んでいた。薄れさせたあとは 0.09%（いちばん強い差 34）。
    **切るのではない**——薄れるだけなら、続きは続きのまま、帯の裏では読めなく
    なるだけ。
  - **マスクを掛けるのは面（`.screen`）で、紙ではない。** 紙に掛けると、
    マスクは箱の外を透明にするので、**頭の上の落ち影ごと**切り取られる
    （実測：マスクあり 240,239,243 ／ なし 218,217,221——影がまるごと消えた）。
    面の箱なら、影はその中に収まる。
  - 境目は **`--face-cut`**（`app.js` が測って書く、下の帯の上端を面の箱の中の
    座標にしたもの）。**数字を二か所に書かない**——帯の丈が変われば、ここも
    ついてくる。薄れきるまでの 22px は帯の裏に収まる長さ（実測：帯の上端 771、
    画面の下 844。44px だと帯の上のほうで「¥158」がまだ読めた）。
    **この一枚は使う要素の上で組むこと**——`:root` に置くと、そこで
    `--face-cut` を焼きつけて配られる（＋のコーラルが消えたのと同じ罠）。
#### 掴み手の `data-pull-own`・往復・片づけ
- **掴み手には `data-pull-own` を付ける。** これが無いと、下へ引いた指を
  「引いて更新」も一緒に取ります。あちらは `.screen` ごと平行移動させる
  （`pull-refresh.js` の `screenEl.style.transform`）ので、**上のバーと
  カテゴリの札まで指について降りてきます**——紙が下がるのではなく、画面ごと
  崩れていくように見える。やること・daily・ダイエットの掴み手には前から
  付いていて、**買うものだけ抜けていました**。
  裏取り（実測、150px 引いて）：印あり → 題帯 -1／札帯 42／transform none。
  印を外す → 題帯 **67**／札帯 **110**／transform 67.77px。
- **掴み手は一つで往復する。** 向きは `opts.role` ではなく**いま紙がどこに
  居るか**（`faceAt()`）で決まる：上に居れば下へ、留まっていれば上へ。
  役目を固定していたころは、下ろしたあとの掴み手が「下へしか行けない」まま
  で戻り道が塞がっていた。名札も state で言い直す（`syncFaceGrips`）。
- **買うもの・価格から離れるときは、留まった紙を片づける**（`show()` の
  `faceUnpark()`）。のぞかせた頭は「この後ろに買うものがある」という札なので、
  daily やダイエットの上に残っていては嘘になる。

カテゴリの札は、**買うもの側は手持ちのぶんだけ・価格側は全部**。これは
もともとそうなっていた（`renderFilter` が数えている相手が違う）。

紙は画面の下まで届かせる（`#screen-list .tl-sheet` が下の余白を引き受ける）
——途中で切れると、その下の地が「まだ何かある」に見える。**価格の地には
この手当ては要らない**（器の `padding-bottom` がすでに帯のぶんを持っている
ので、`.prices-ground` は `flex: 1` だけ）。

### このリストを送る（D4）・買い物中は画面を消さない（D5）

2026年9月26日（`docs/improvements.md` の D4・D5・B2）。

- **送るのは、いま画面に出ている買うものそのまま**（`shareRow` / `listText`）。
  ★があれば「今回買うもの」「そのほか」に分け、札で絞っていればその札のぶん
  だけ（題に札の名前）。並びも画面と同じ——組み分けは `groupsOf` を
  `appendGroups` と分け合う（二か所に書くと、片方だけ直した日に順がずれる）。
  買ったもの（アーカイブ）は入れない。**探しているあいだは出さない**——探した
  結果はリストではなく、リストの見方なので。
- 行の書式は `・品名 ×個数（メモ）`。個数は2以上のときだけ。メモの改行は空白に。
- 置き場所は**買うものの終わり、アーカイブの手前**。右上には置かない（右上は
  「どの画面でも同じ二つ」、`docs/screens-nav.md`）。見た目は「今日の予定に
  入れる」と同じ一本（`.trip-plan-btn`）——どちらも、このリストを外へ渡す口。
- 渡し方は共有シート（`navigator.share({ text })`）。無い端末はクリップボードへ
  写して「リストをコピーしました」。**共有シートを閉じただけ（`AbortError`）なら
  何もしない**——取り消しを失敗と取り違えて写すと、閉じた人のクリップボードが
  黙って書き換わる。
- **画面を消さない**（`awake`、Screen Wake Lock）：買うもの（と、その紙の後ろの
  価格）が出ていて、まだ買うものが残っているあいだだけ。設定は置かない

  - **最後に触ってから5分で手放す**。机に置いたままの画面を点けっぱなしに

    入ったとき（`onEnter`）・戻ってきたとき（`visibilitychange`）。
  - **組み直し（買った・消した）では延ばさない**（`recheck` は「要らなく
    なったら手放す」だけ）。組み直しでも延ばすと、ほかの仕掛けが組み直すたびに
    5分が数え直されて、いつまでも手放さない。
  - 隠れるとブラウザが自分で手放すので、戻ってきたら持ち直す。
  - iOS のホーム画面アプリで効くのは **18.4 から**とされる（実機では未確認）。
    机の上の Chromium では、偽の `navigator.wakeLock` と止めた時計で試している。
- 押す範囲（B2）：カテゴリの札（高さ40px）と品物の絵の丸（40×40）は、見た目は
  そのまま、指の的だけ44pxへ（`components.css` の `.hit-44` の並び）。札の帯の
  上下の余白は4pxなので、2pxずつ広げても帯の中に収まる——**縦の送りは生まれない**
  （試験で `scrollHeight - clientHeight = 0`）。掴み手（上端 90px）には届かない
  （札の的の下端は 88px）。

### 一行に並べたものを、分けて入れる（R1・2026年9月28日）

「牛乳、卵、パン」を一度に打てば三つ入る。分ける部品は `js/split-items.js`
（純粋。表は `tests/split-items.js`）。

- 区切りは読点（、）・カンマ（, ，）・改行。**「・」では分けない**（「ハム・ソーセージ」）。
  **数字に挟まれたカンマも分けない**（「1,000円」。全角も元の字のまま）。
- **登録済みの品物の名前に読点が入っていれば、その名前は分けない**（いちばん長く
  合うものを先に取る。照らし方は `findProductByName` と同じ）。候補から選んだ品物は
  分けない。
- 名前の欄は一行（input）なので、**貼りつけた改行は「、」にして見せる**——黙って
  消すと「牛乳卵パン」という一つの名前になる。
- ボタンが先に「3つに分けて追加」と言う。棚は一つずつ推し直す（手で選んだ棚だけは、
  新しく作る品物みんなへ）。★とメモは、どの行にも付ける（消すより直すほうが安い）。
  もう載っている品物は足さず、トーストの括弧で数だけ言う。
- トーストの「ひとつにする」：分けて足した行と、**そのとき作った品物**を片づけて、
  打ったとおりの一つの名前で入れ直す（作った品物に値段が付いていたら残す）。
  一つにした名前は読点を持つ登録済みの名前になるので、次からは分けない。
