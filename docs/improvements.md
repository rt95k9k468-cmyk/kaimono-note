## 一覧の原文

Markdown に直した）。行番号は書かれた日のもの。原文の「CLAUDE.md の〜」は、いまは

### A. 不具合・データ保全（優先）

**A1. 日記の本文が約5MBの箱に入り続けている【最重要・要相談】**

- 日記は今、ほかの記録と同じ localStorage（約5MB）に入っています。
- 大きな箱（IndexedDB、数百MB）に暗号化してしまう仕組み js/diary.js は作ってあるのに、どの画面からも呼ばれていません。参照はゼロでした。
- tools/diary-import.html の説明にある「設定 → 日記を取り込む」も、アプリ側にありません。
- 厳密に言うと：diary.js 自身の実測で「2151日×600字＝4.1MB」です。自動控えも同じ箱を最大1.5MB使うので、本体に使えるのは3.5MB前後です。満杯になるとデータは消えませんが、その後の変更が保存されなくなります（store.js:1031）。
- 日記を移すのはデータ移行なので、決めごとどおり実行前に相談します。先に「使用量を設定に出す」（読むだけで安全）から始められます。

**A2. 自動控えは、記録が増えるほど黙って効かなくなる**

- 控えは毎回データ全体を写します（backup.js:167）。上限は合計1.5MBです（backup.js:49）。
- 本体が1MBになると控えは1個しか残らず、「昨日の状態に戻す」ができなくなります。
- 控えを IndexedDB へ移すのが直し方です。backup.js を触るので要相談です。

**A3. 「バックアップを保存しました」が、保存したか分からないうちに出る**

- iPhone の保存画面でキャンセルしても「保存しました」と出て、30日ごとの催促も止まります（screen-settings.js:2192）。
- iPhone の共有シートに変えると、保存できたかどうかを受け取れます。そこから iCloud Drive・AirDrop・LINE へ一押しで出せるので、端末をなくしたときの備えにもなります。

**A4. 復元すると「絵の報告」だけが戻らない**

- importJSON()（store.js:3291〜）の戻す一覧に、iconReports と iconOverrides がありません。
- 書き出しには入っているので、「書き出したのに戻すと消える」形です。直すのは2行ですが、復元処理なので相談のうえで。

**A5. 日付が欠けた記録が、どの日にも出ない記録になる（今は起きていない不具合）**

- 体重・お酒・食事・健康の記録で日付が欠けると、「今日」ではなく時刻つきの UTC 文字列が入ります（store.js:269/347/472/521 の || today()）。
- その文字列はどの日とも一致しないので、記録が画面に出なくなります。todayKey() にすべきところです。
- 取り込みや AI の返事を通ると起こりえます。読み込みの経路なので相談のうえで。

**A6. 設定を開くと、下の帯の印が席と席のあいだに取り残される（実測で確認）**

- 設定では＋ボタンが消えて帯の席が広がります（health の席は 239–314 → 287–378）。印は 242–312 のまま動きません。

**A7. Android のショートカット「お店くらべ」が daily に飛ぶ**

- #compare に当たる画面がありません。
- テーマ色 #2f8f5b も、manifest と index.html の両方で昔の緑のままです。

**A8. ソースに見えない NUL 文字が2か所ある**

- 場所は ui.js:835 と screen-settings.js:1956 です。これのせいで GitHub の差分が「バイナリ」扱いになり、中身が読めません。
- "\u0000" に書き換えれば、動きは同じまま差分が読めるようになります。

### C. 動き・手触り

土台はもうかなり揃っています（行が滑って収まる動き、指の勢いを引き継ぐ滑り、押したところから紙が育つ動き）。残りは次の4つです。

- C1. iPhone では一度も震えていません。 iPhone の Safari には振動の機能が無いからです（motion.js:30 にも書いてあります）。iOS 18 以降なら、隠したスイッチ入力を切り替えると軽い振動が出る手が知られています。非公式で将来壊れうるので、済ませた・置いた・閉じたの3つに絞って試す程度です。
- C2. 押した行の丸薬が、そのまま紙の頭の丸薬へ伸びていく「つながり」の動き。今は押した点から紙が育つところまでです。
- C3. 起動の一瞬の固まり。 CPU を4倍遅くすると、190〜290msの固まりが1つ出ます。起動のたびに JS を2.6MB読んでいて、そのうち icons-v2.js（400KB）と予備の絵2本は、ふだん絵として使われていません。キーワードと絵を分けて、絵は要るときだけ読む形にできます。
- C4. 済ませたときの手ごたえ（やること・買うものだけ。daily は採点しない決めごとなので対象外です）。C1 と組むと効きます。

## D1 の設計（14回目に決めた。2026年9月27日。15回目に作った——作り方の違いは下の「やったこと（D1）」）

**利用者が決めたこと**（AskUserQuestion で二択ずつ）

1. 中身の守り方：**時刻だけ渡す・題は端末から**。中継所が知るのは「いつ鳴らすか」の
   時刻の列と、押し先（iPhone の Web Push の宛先）だけ。題・メモは端末から出さない。
   （退けた案：題も出さず「やることの時刻です」だけ／題を暗号にして預ける——後者は
   守りの強さがほぼ同じで手間だけ大きい）
2. 置き場所：**いまの中継所（relay/）に足す**。置き直しは D2 の置き直しと一回で済む。
   （退けた案：別の Worker を建てる）

**作り方の案**（次のセッションで、docs/todo-items.md・docs/storage.md・docs/health.md・
relay/README.md を読んでから。変えてよい）

- **中継所**（`relay/worker.js`）
  - 棚（slot）とは**別の鍵**に置く：`bell:sub`（押し先）・`bell:times`（時刻の列）・
    `bell:vapid`（署名の鍵の組）。**GET の「ぜんぶ渡す」に混ぜない**（アプリの取り込みが
    健康データとして読んでしまう）。道は例えば `PUT <URL>?bell=sub`・`PUT <URL>?bell=times`・
    `GET <URL>?bell=key`・`DELETE <URL>?bell=all`。
  - 署名の鍵（VAPID）は**中継所が初めて頼まれたときに自分で作って KV に置く**——利用者に
    Secret を一つ増やさせない。公開のほうだけ `?bell=key` で渡す。
  - `wrangler.jsonc` に `"triggers": { "crons": ["* * * * *"] }`、`scheduled()` で毎分
    `bell:times` を読み、`at <= いま`（10分より古いものは鳴らさず捨てる）を押して列から消す。
  - 押すのは**中身なし**（payload なし）。中身の暗号（RFC 8291）が要らず、VAPID の JWT
    （ES256、WebCrypto の ECDSA P-256）だけで済む。`TTL`・`Urgency: high`。押し先が
    404 / 410 を返したら `bell:sub` を捨てる。
  - KV の無料枠：毎分の読み＝1日1,440回（読みは10万回まで）。書きは時刻の列が
    **変わったときだけ**（1日1,000回まで）。
  - 手でコードを貼って建てた人は、Cloudflare の Settings → Triggers → Cron で
    `* * * * *` を足す必要がある（ボタンから置いた人は設計図が足す）。`embed.js` で
    `js/relay-code.js` を作り直すのを忘れない（ずれるとテストが落ちる）。
- **アプリ**
  - 設定の「時刻のお知らせ」を入れていて、中継所がつながっているときだけ。
    `reg.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey })` で押し先を
    作り、中継所へ `?bell=sub`。
  - 今日から7日先までの「時刻のあるやること」（くり返しは `store.fallsOn` で開く）を、
    時刻（エポックのミリ秒）だけの列にして `?bell=times`。やることが変わるたび
    （間を置いて）と、開くたび。**7日開かなければ鳴らなくなる**ことは設定に書く。
  - 同じ列の {時刻, 題, id, 回} を、**端末の IndexedDB に写す**（Service Worker が読む
    ため）。記録ではなく、毎回まるごと書き直す控え——消えても作り直せる。
    CLAUDE.md の「記録用の入れ物を増やさない」の例外として docs に理由を書くこと。
- **Service Worker**（`sw.js`）
  - `push` で IndexedDB の写しを読み、いま（±2分）の題を `notify.js` の `tick()` と
    同じ形（「19:30 題 ほか◯件」）で出す。見つからなければ「やることの時刻です」。
  - 鳴らした {id, 回} を IndexedDB に残し、アプリは開いたときにそれを
    `store.markAnnounced` へ渡す——でないと、開いた瞬間に同じものをもう一度鳴らす。
- **確かめること（実機）**：iPhone のホーム画面のアプリで、中身なしの押しで鳴るか。
  鳴らなければ、意味の無い合図だけを暗号にして載せる（RFC 8291）に切り替える。
- **データの移行は無い**（設定に欄を足すだけ。`reconcile()` で既定値へ）。
