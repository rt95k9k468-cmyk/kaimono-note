# 画面の移り変わり・帯の構成・上の題

CLAUDE.md から見出しごと移した、詳しい決めごと（2026年9月26日）。
本文は移す前と一字も変えていない。入口（どの docs を読むか）と、どの画面でも
踏む罠は CLAUDE.md にある。**新しい決めごとは、ここ（該当する docs）に書く。**

### 画面は、帯と同じ向きへ流れる

daily → やること と押したなら、画面も左へ流れて次の面が右から入ってくる。
並びは**下の帯の並び**（`app.js` の `SLIDE`）。出ていく面は流れ終わるまで
残す（`is-leaving`）——消してから動かしても、動くものが無い。`.screens` に
`overflow: hidden` を足してあるのは、外へはみ出したぶんを見せないため。

**組み立ては、動かす前に済ませる**（`show()`）。前はここが逆で、入場の class を
付けて transition を走らせてから `render()` を呼んでいた。組み直しは重い仕事
（やることで 117〜168ms／CPU 4倍）なので、**動き出した直後に main thread が
そのぶん固まる**——CSS の transition は時計で進むので、固まっているあいだも
動いたことになり、手が空いたときには途中まで進んでいる。実測（CPU 10倍、
入ってくる面の transform を毎フレーム拾って）：最初に描かれた位置が
**390 → 161／102**（＝道のりの 59〜74% を飛ばしていた）。組み立てを先にすると
**390 → 254**（35%）で、残りはちゃんと 9 コマ描かれる。

- **見える状態にしてから組むこと。** 隠れた面（`hidden` ＝ display:none）の中で
  組むと、測るものが軒並み 0 を返す——暦の厚み（`fitCalH`）、選んでいる日の輪の
  位置、「いま」の線。だから先に `is-active` だけ付けて、**動かす class
  （`inCls`）は輪の中で付ける**。二つのあいだに描画は挟まらない（同じ一拍）ので、
  前の席が消えて見えることはない。

**引き出し（設定）は「押しのけ」で、並んで流れるのではない。** 詳しくは
設定の節の「引き出しは押しのけ、タブは並んで流れる」。

**買うもの ⇄ 価格 は横へ流さない。** あれは横に並んだ二つのタブではなく、
**買うものの後ろに価格がいる**という重なりなので、動くのは紙だけ
（`--face-p`、上のバーは動かない）。横へ流すと「横から来た」に見えて、
後ろに居たことが伝わらない。

### 帯は四つ、右上は二つ

- **下の帯**（`app.js` の `TABS`）… daily／やること／買うもの／ダイエット
  の**四つだけ**。価格は席を持たない（買うものの紙の後ろに敷いた一枚で、
  そこへは掴み手で行く）。`holds` が「その席が受け持つ画面」で、価格を
  見ているあいだも帯は「買うもの」のまま。
- **設定はタブではない**（`OFF_BAR = ["settings"]`）。場所ではなく、直したい
  ときに開くもの。どのタブの右上の歯車からも開き、`KN.app.backScreen()` で
  呼んだ画面へ帰る。設定の帯の「‹」は二段ぶん働く（中→目次→呼んだ画面）。
- **右上は二つだけ**——さがす と 設定。**どの画面でも同じ二つ**。
  外したものの行き先：
  - 並べ方（タイル／リスト）→ 設定の **外観**（`settings.layout` は三画面が
    分け合う一つの札なので、画面ごとではなくここ）
  - 暦の出し入れ → 設定の **外観**の「表示」に一つ（`calSwitch()`。2026年9月27日から
    全タブで一つ——docs/shared-header.md。前は やること／daily／ダイエット の三か所）
  - daily の月の書き出し・ダイエットの取り込み → もともと設定にあった
  - 価格の「◯商品・◯店舗」→ 設定の 買うもの（`listRows()` のカードの下の一行）
- **上の帯は 43px**（前は55px）。上下の詰めは `--sp-1`（4px）、帯の中の
  `.icon-btn` だけ34px（**指の的は44pxのまま**——`.icon-btn::after` が持つ）。
  題の日付（高さ26px）の指の的も、**帯いっぱい（0〜42px）まで**広げてある
  （`.topbar-day::after`、2026年9月26日、improvements の B2）。その下は暦の帯が
  上に乗るので、暦の的は一画素も取らない。

### やること・daily・ダイエットは、上が同じ

**2026年9月27日から、上は「同じ」ではなく「一つ」**（買うもの・価格も段3で
同じ帯に載った。題は日付、暦の印は段4から「その日に買ったもの」の丸）——帯と暦は各画面の外、
`#head`（`js/head.js`）に一つだけ居て、タブの流れはその下の画面だけを動かす。
持ち主・`mine()`・暦の置き場・設定の押しのけは docs/shared-header.md の
「段2で入れたもの」。下の決めごと（題の書式・今日へ戻る）はそのまま生きている。

**題はひとつの部品**（`KN.util.dayTitleBar` / `paintDayTitleInto`）。三画面が
これを借りる——書式を三か所に書き写すと、片方だけ直した日に三つの題が違う顔を
する。画面が答えるのは「ここでの『いま見ている日』は何か」だけ。

書式は「2026年9月8日(火)」。**曜日まで書く**——日付だけだと、その日が
何曜だったかを数えないと分からない。予定を組むときに要るのは、たいてい曜日の
ほう。

**括弧は半角。** 全角の `（火）` は前後に見えない余白を抱えていて実測 3文字ぶん、
半角なら 1.6文字ぶん。浮いた 1.4文字ぶんが右の「今日へ戻る」に回る。
**実機で括弧が上下にずれて見えたら、`dayTitleParts` の一行を全角へ戻すこと**
——ASCIIの括弧はラテン字の中心に合わせて描かれているので、漢字と並べたときの
座りは書体しだい（iOS では括弧が SF Pro、漢字が Hiragino と**別の書体から**
来るので、ここは実機でしか確かめられない。コンテナには Hiragino も SF も無い）。

色を当てる相手は二つ。**年（`.day-y`）はいつも差し色**、**日にちの数
（`.day-d`）は当日のときだけ差し色**（`.is-today`）。参考画面が暦の帯で今日の
数だけ色を変えているのと同じ理屈で、「開いているのが今日かどうか」を字の色
そのものが言う。残り（`.day-pre` / `.day-post`）は黒。

**大きさは、どの日を見ていても同じ。** 字はいつも一つの `clamp` だけ。
実測（49日 × 320/375/390/428px）で、字の大きさ・題の高さ・帯の高さ・題の
左端が**どれも一通りしか無い**こと。

**題の右は「今日へ戻る」**（`.topbar-today`、`icon("back")`）。**`›` は外した**
——`--cal-p` で回して暦の開き具合を言っていたが、daily では題を押すと月を選ぶ
紙が開く（暦の開閉ではない）ので、あそこでは回る意味が無かった。やること・
health では効いていたが、開いているかどうかは暦そのものの高さがもう言っている。

- **今日を見ているあいだは隠す**（`hidden`）。前に外した同名の札は当日でない
  ときだけ出て、そのぶん**題の字**を一段落としていた——今日とそれ以外で題の
  大きさが変わって見えた原因はそれ。ここが違うのは、**題の幅は vw基準の
  clamp で、この矢の有無とは無関係**なこと。矢を隠しても、動くのは矢の右に
  ある探す・設定の位置だけで、題の字も帯の高さも動かない
  （実測 49日 × 320/375/390/428px で確認済み）。
- **向きが二つある。** 未来の日から戻るのは時間を遡る＝左向き
  （`arrow-u-up-left`）、過去の日から戻るのは時間を進める＝右向き
  （`arrow-u-up-right`）。**絵は左向き一つだけ持ち、右向きは CSS の鏡映し**
  （`.is-flip` → `transform: scaleX(-1)`）——`arrow-u-up-right` はこの絵の
  ちょうど鏡像なので、絵を二つ持つ必要がない。今日は向きが決まらないので
  隠す、というのが上の一行の理由でもある。
- **絵は Bold weight。** 他の UI アイコンは全部 Regular（256の升目に16＝
  24pxに直すと1.5px相当）だが、ここだけ目立たせたいという指示で Bold へ
  ——`.check` の ✓ と同じ、weight の例外。
- 絵は 17px（前の `›` と同じ）、指の的は 44px（`::after`。`.icon-btn` と
  同じ手で、幅を増やさずに的だけ広げる）。
- **絵は `arrow-u-up-left`（Bold、`back`）。** `arrow-arc-left`（弧を描く矢）
  や `undo`（＝`arrow-counter-clockwise`、ほぼ一周する矢）も検討したが、
  後者は「もう一度読み込む」に読める——health には本物の引いて更新が居る
  ので、隣に置くと紛れる。
- 置き場所は `›` の跡地、つまり**題のすぐ右**（題の幅ぶん動く）。実測 320px の
  いちばん長い日付（2026年10月22日(木)）でも、右の二つとのすき間は 27px。
- 今日へ戻る道は暦にもあるが、今日から離れる道が増えた（暦を払う・紙を払う・
  暦の日を押す）のに対して、戻る道は「暦から今日のマスを探して押す」しか
  無かった。今日が出ていない週まで行っていると、その一手が二手三手になる。

暦の見出しの行・`‹ ›`・「週／月」の札は、どの画面にも無い（ぜんぶ題に吸収した）。
暦の下は紙（`.tl-sheet`）で、掴み手つき。紙を横に払うと、やること・daily は
**日**が動く。

**daily の「日を選んでいなければ月まで」は廃止した。** 月ぜんぶを縦に並べて
いたころの決めごとで、紙が一日ぶんになったいま、題だけ月を言うと**紙と題が
違うことを言う**。日を選んでいないときに紙が出しているのは `focusDay()` で、
そこをそのまま題にする。

**幅の実測**（曜日が加わったぶん）：`clamp(16px, 5.4vw, 23px)`。もとの
`clamp(18px, 6.4vw, 26px)` のままだと「（火）」の3文字ぶんで、実測 320px の
画面で19px・375pxでも1px、字が欠ける。

**暦の下に「今日へ」「今月へ」の札を出していたのは、無くした。復活させない。**
隠れているあいだは場所を取らないボタンだったが（`.cal-now` / `.js-now`、暦の
一段いちばん下に追記）、出た瞬間だけ暦の高さがそのぶん伸びて、**下の紙が押し
下げられていた**——他の日・他の月を見に行くたびに、紙の位置が動いて見えた
正体はこれ。今日へ戻る道は、いまは**題の右の `.topbar-today`**（上を参照）。
あれが良いのは、**暦の外・上のバーの中に居る**から——出たり消えたりしても
（今日は隠れる）、動かす高さは暦にも紙にも無い。壊れていたのは「暦の中で
高さを持つもの」が出入りすることで、場所そのものが違う。

**daily の題を押すと、月を選ぶ紙が出る**（`openMonthPicker`）。前はここで
暦の開き具合を切り替えていたが、それは紙を引く手つきがすでに持っていて、
同じことを二か所でやっていた。題が言っているのは年と月なので、押したときに
応えるのは「ほかの月へ」。まだ来ていない月は選べない。やること側の題は
これまでどおり（あちらは日ぶんを出す画面なので、月を選ぶ意味がない）。

### ぜんぶをさがす（R8・`js/search-all.js`、2026年9月28日）

**虫めがねの役目は変えない**：押せばそのタブの窓が開き、打った字でそのタブの中を
絞り込む（`KN.ui.wireSearch`）。そこへ一つだけ足した——打った字が**ほかの場所**にも
あれば、窓のすぐ下に「ほかの場所に ◯件 ›」の一行（`.sa-hint`）。押すと場所ごとに
まとめた紙（「『〜』をぜんぶから」）が開き、行を押すとその日・その品へ。

- 一行を**窓の下**に置いた（roadmap の案は一覧の「終わり」）。長い一覧の終わりには
  指が届かず、タブの中に一件も無いときほど要るので。
- 場所：やること（済んだもの・日付の無いものも）・買うもの・価格（品物。リストに
  あれば買うもの、無ければ価格へ）・daily（日記の本文・積み上げ）・からだ（食べた
  もの・食事のメモ・お酒）・ノート（2026年10月1日、docs/notes.md の段3。押すと daily の裏でそのノートを開く）。**いまのタブの場所は数えない**（もう絞り込んで見えている）。
  一つの場所は30行まで、あとは「ほか◯件」。
- 行き先：日のあるものは、先にそのタブへ移ってから共通の日（`dayShare`）を置いて
  組み直す（移るとき `show()` が出ていく画面の日で上書きするので、順番が逆だと
  効かない）。やることは `goDay`。日の無いもの（品物・長期タスク）は、そのタブの窓に
  同じ字を入れて絞り込む。
- **過去の日付の言葉**（「2025年9月」「2025/9」「去年の夏」「去年の9月」「先月」「9月」
  「おととし」）は「◯年◯月の daily へ」の口として一行に並べる（`pastWhen`）。
  `when-parse` は先の日しか読まない決めごとなので、別の読み方を持つ。先の月になる
  言葉は出さない。季節は始まりの月（春3・夏6・秋9・冬12。今年の冬で12月前なら1月）。
  年だけ・「おととし」は1月。飛ぶ先は今月なら今日、過ぎた月なら1日。
- 日記の本文は照合に使い、行には当たった前後を40字ほど。`KN.diaryIdb.body()` が
  "ok" でない（読み込み中・読めない日）ときは本文を探さず、紙に一言
  （docs/storage.md の「読み込み中と、読めない日」）。
- 記録は増やさない。畳み（`foldKana`）は字ごとに覚えておき、打ち終わりを 180ms 待つ。
- 試験：`tests/search-all.js`。

### 身ぶりと紙の表（roadmap-2.0 の V13、2026年10月4日）

**同じ身ぶりは、どこでも同じ意味。** 決まりは五つ。新しい手つきを足すときは、まずこの表に
載るかを見る（載らない意味を持たせない）。

1. **押す**＝その物の紙が開く。丸（`.check`）は済ませる。題は暦の開閉。
2. **長押し**＝持ち上げる（並べ替える・別の場所へ運ぶ）。掴み手（四本線）は押した瞬間に持ち上がる。
3. **紙の横払い**＝日を移る（左へ払うと次の日、右へ払うと前の日）。**行ごとの横払いは置かない**
   （roadmap-2.0 の7節）。
4. **縦の引き**：掴み手を下へ＝暦の段（暦なし／週／月、`cal-peek.js`）。紙の本体は送るだけ
   （端の give。引いて更新は無い——sheet-scroll）。下から出た紙は頭か掴み手を下へ払うと閉じる。
   後ろの面（価格・ノート）に居るときだけ、残った紙の頭を上へ引く＝前の面へ戻る（`wireFaceGrip`）。
5. **左の端から右へ**＝一段戻る（`edge-back.js`）。

| 画面 | 押す | 長押し | 横払い | 縦の引き | 左の端から |
|---|---|---|---|---|---|
| やること（時間割） | 行・絵＝用事の紙（丸薬から伸びる）／丸＝済ませる | 行＝持ち上げて順番か時刻へ、週の帯の日へ運ぶと日付／道の連れ＝道へ運んで停留所／**手順の丸＝できなかった**（例外） | 紙＝日（隣の日の紙が入る）／暦＝週・月 | 掴み手＝暦の段 | — |
| やること（一覧：時間割オフ・タイル・さがす最中） | 行＝用事の紙／丸＝済ませる／絵＝絵を選ぶ | 行＝並べ替え、棚をまたぐと日付 | 紙＝日（隣は組まない。題・暦・その日の棚へ）。さがす最中は紙が無いので払わない | 掴み手は引かない（暦の段は時間割のときだけ） | — |
| daily | 行＝その日の記録／**題＝月を選ぶ紙**（例外） | 日記の行＝字を選ぶ（端末の選択） | 紙＝日／暦＝週・月 | 掴み手＝暦の段 | — |
| 買うもの | 行＝品物の紙／丸＝買った／★／絵＝絵を選ぶ | 行＝並べ替え | 紙＝日（隣は組まない。題と暦だけ） | 掴み手＝暦の段 | — |
| 価格（買うものの後ろの地） | 行＝品物の紙 | 行＝同じカテゴリの中で並べ替え | **行＝右でリストへ・左でアーカイブ**（例外） | 前の紙の頭を上へ＝買うものへ戻る | — |
| からだ | 欄・行＝記録の紙 | — | 紙＝日／暦＝週・月 | 掴み手＝暦の段 | — |
| ノート（daily の後ろの面） | 行＝ノートの紙（行から伸びる） | — | — | 前の紙の頭を上へ＝daily へ戻る／書く紙は頭を下へ払うと閉じる。2.0 の中では**一番上まで送ってあれば中身を下へ引いても閉じる**（V19） | 2.0 の中では書く紙で**右へ＝戻る**（カードへ縮む。V19） |
| 設定 | 行＝一段奥へ | 店・カテゴリ＝並べ替え | — | 送るだけ | 一段戻る（いちばん外は呼んだ画面へ） |
| 下の帯 | 席へ。いる席をもう一度＝後ろの面（買うもの→価格、daily→ノート） | 押しているあいだ印が膨らむ | — | — | — |

**例外として残したもの（理由）**

- **価格の行の横払い。** 価格は日を持たない後ろの地で、紙ではない（暦も払う日も無い）ので、
  「紙の横払い＝日」とぶつからない。アーカイブとリストへの一手はここにしか無い。
- **手順の丸の長押し＝できなかった。** 押すものが行ではなく丸で、手順の並べ替えは掴み手が持つ
  ので、持ち上げる意味と取り合わない。
- **daily の題＝月を選ぶ紙。** 決めた理由は上の「daily の題を押すと、月を選ぶ紙が出る」。

**V13 で揃えたもの：やることの一覧の行の横払い**（右で今日に・左でアーカイブ）を外し、紙の
横払いを「日」に。時間割と一覧で同じ指が違うことをしていた（買うもので同じ理由から外したのと
同じ——shopping の「買うものの行の横払いは外した」）。棚は紙の中の一枚（`.tl-shelves`）に入れ、
指につかせるのはそちら（紙そのものは送る器で、縦の give が transform を書く——traps）。
**アーカイブは用事の紙の ⋯**（「アーカイブする」／しまったものは「アーカイブから戻す」）。
時間割からもしまえるようになった。今日にするのは、今日の棚へ運ぶか紙の日付で。
試験は `tests/gesture-map.js`。

**紙の種類**

| 種類 | 何のため | 出方・閉じ方 | いまあるもの |
|---|---|---|---|
| 小さな紙（小窓） | 一つを選ぶ・決める | 押したもののすぐ下にポッと出る（`popMenu`・`popCalendar`）。外を押すと閉じる | ⋯ の中身、日付・時刻・くりかえし・期限の暦、ノートのタグ・ノートブック |
