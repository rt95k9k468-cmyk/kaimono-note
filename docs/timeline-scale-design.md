## 1. 依頼
- 時間割の札の**幅（＝縦の長さ）を、時間にしっかり比例**させる。
- **重なったら2列**（以上）にする。

## 2. いまの作り（変えるものの輪郭）
- 行は並び順のリスト。**空きは長さによらず一定（`TL_FREE_H`=36px）、札は `nodeH`**（30分まで50px、1分＝0.8px、170px頭打ち、
  長さ未定は50px）。重なりは `is-clash`（丸薬を上下へ14pxずつ育ててめり込ませる）。
- 「いま」は `nowY`/`axisOf` が行の中の位置を測って置く層。過ぎてもまだの用事は `growOf` で「いま」まで伸ばす。
- 並びは `plan.buildDay`（`js/plan.js`）が作る `{items[atMin, untilMin, fixed, doneAtMin], free[]}`。**ここは時刻の計算で、描きに依らない。そのまま使える。**
- 触る量：`screen-todo.js` の tl 周り 43 箇所、`screens.css` 122 箇所。台本は 20 本が `tl-row`・`tl-free`・`is-clash`・`--tl-h`・`tl-axis` を掴む
  （`timeline-late`・`timeline-overlap`・`timeline-rail`・`row-heights`・`road-place`・`done-time`・`task-card`・`upcoming`・`pill-morph` ほか）。

## 3. 目指す形

```
  時刻  │ ┌────────┐ ┌────────┐   ← 重なった二件は左右2列（同じ時間帯）
  9:00  │ │ 会議   │ │ 電話   │
        │ │        │ └────────┘
 10:00  │ │        │
        │ └────────┘
        ┆  〜 12:00 まで予定なし 〜        ← 長い空きだけ畳む（一定の高さ）
 13:00  │ ┌─────────────────┐
```

- **縦軸＝時間**。1分＝`PX_MIN`（案：1.2px＝1時間72px）。札の top は始まり、height は長さ。上限は設けない。
- **札は絶対配置**（`.tl-list` を `position: relative`・高さ＝軸の総長）。今の `<li>` の並び（grid 3列）は廃止。
  左の列＝時刻の目盛り（時刻のある札の頭に字、1時間ごとに薄い目盛り線）、右＝札の領域。
- **長い空きは畳む**（既定 90分以上の予定なし。一定 44px の「〜 ◯時まで予定なし 〜」）。これが無いと夜の10時間が
  720px になり「一日が一画面に入る」を失う（今の docs の取り引き）。畳まない設定にはしない（足さない）。
  畳んだ区間では物差しが切れる——その区間は目盛りを描かず波線で言う。
- **長さ未定の用事**（`minutes` 無し・`plan` の仮の30分）は、**札の高さを最低高（44px）で描き、長さは言わない**
  （今の「仮の数は決めた数のように読める」の決めごとを守る）。置き場所は仮の30分ぶんを取る。
- **短い札**（15分＝18px）は最低高 36px で描く。重なり判定は**描いた高さ**で行う（見た目で重なるなら2列）。

## 4. 重なり＝列の割り当て
- 区間グラフの標準：始まり順に並べ、重なる連なり（クラスタ）ごとに、空いている最初の列へ置く。
  クラスタの列数 N で幅を `1/N`（札の領域を等分、列間 4px）。**N は 3 まで**、4 件目以降は3列目に「＋n」の札へまとめ、押すと一覧の紙。
- `is-clash`・`is-clash-above`・めり込みの白い抜き・`landsInside` は**不要になり削除**（重なりは列が言う）。
  ※ 済ませた用事が長い用事の途中に入る場合も同じ列の規則（`doneSpan` の時間で）。
- 列をまたぐ「いま」の線は札の領域の全幅。

## 5. 他の部品との付き合い
| 部品 | 扱い |
|---|---|
| 「いま」(`nowY`/`axisOf`) | **簡単になる**：y＝(いま−始まり)×`PX_MIN`＋畳んだ区間の補正。行の中を測らない |
| 過ぎてもまだ（`growOf`） | 札の下端を「いま」まで伸ばす＝同じ y の式。`--tl-grow` は廃止 |
| 道（`day-road.js`）・道の色の連動 | 独立。札の色（`tlColorOf`）と過ぎたぶんの色（`--pass`）は y から出す。`--p` は「札の中の割合」でそのまま |
| 空き（`freeRow`・`TL_JOIN_GAP`・実線/点線） | 余白に置き換わる。「30分以内は実線」は**札と札のあいだの細い線を描くかどうか**に翻訳、または廃止（要決定） |
| 手順をひらく | §6-3 |
| つまんで動かす（`wireDrag`） | **作り直し**。指の y→時刻（5分刻み）に直接対応でき、今より素直。列の入れ替えは考えない |
| 組み直しの滑り（`flipRows`） | 札ごとに `transform: translate` の滑りに（FLIP の元は top の差） |
| 済んだ行・畳み（`is-done-shut`） | 済んだ札を非表示にしたとき、軸を詰めるか空けるか（§6-4） |
| 長期タスクの欄・「これから」 | 札の領域の下に今まで通り |
| 日をまたぐ・5:00〜23:00 | `dayStart`〜`dayEnd`（設定）。範囲外に置かれた札は端に寄せて描く（今と同じ） |

## 6. 決めてほしいこと（既定を添える）
1. **縮尺**：1時間＝72px（案）／96px／可変（札の数で自動）。既定＝72px。
2. **畳む**：90分以上の空きを畳む（案）／畳まず全部描く（夜は短くして描く・不均一）。既定＝畳む。
3. **手順をひらいたとき**：(a) 札の中で段が広がり、**下の札を押し下げる**（時間に比例しない継ぎ目が出る・今に近い）
   (b) 札の下に重ねて浮かせる (c) 手順は紙（詳細）だけで開く。既定＝(a)（ひらいた間だけ比例を外す、と決めごとに書く）。
4. **済んだ行を畳んだとき**：軸をそのまま（空く）／詰める。既定＝そのまま（物差しなので）。
5. **列の上限**：3列＋「＋n」（案）／2列固定で残りは「＋n」。既定＝3列。
