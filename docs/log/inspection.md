## 見つけたもの（1・2 は10月8日に直した）

### 1. daily に入るとき、1.2秒のあいだ毎フレーム画面ごと当てはめ直す（中）

- 何が：`css/screens.css` の `@property --season-c`（inherits: true）を `#screen-archive`・`#screen-notes` で
  `transition`（`--m-season` 1.2s）。使うのは背景の2か所だけなのに、子の全部（daily で 1,643）が毎フレーム
  当てはめ直しになる。
- いつ：色が変わるときだけ（`setVar` は同じ値を書かない）。**開いて初めて daily・ノートに入ったとき**
  （透明 → 候の色）と、**日を払って候が変わったとき**。
- 測った数（試験のブラウザ・CPU 1倍）：1年ぶんの記録で daily に入る仕事 約840ms（うち様式の計算 約470ms＝
  96回×約1,690要素）。空の記録で約350ms（様式 約100ms）。滑り込む動き（260ms）と重なる。
- 罠：`.tl-sheet` には紙を滑らせる transition（transform・opacity と、状態ごとの none）がある。**そこへ
  transition を足すと詳細度で上書きして壊す。**
- 案（見た目は同じ）：受け継がない別の名前（例 `--season-k`、inherits: false）を使う要素に置き
  （`--season-k: var(--season-c)`）、背景はそれを読む。移すのは CSS の transition ではなく、`season-art.js` の
  `apply` から使う要素へ Web Animations（`el.animate`）で。毎フレーム当てはめ直すのは一つだけになる。
  小さく済ませるなら、初めの一度（`data-season` が無いとき）だけ移さない（いちばん多い場面だけ消える）。
- → **直した（10月8日）：案のとおり。** `--season-k`（inherits: false）を daily の紙・ノートの画面に置き、
  `season-art.js` の `fadeTo` が前の色から Web Animations で移す。紙は描き直すたびに作り直されるので、移る途中で
  組み直されたら新しい紙に同じ時刻から付け直す。`.tl-sheet` の transition には触れていない。見た目は同じ
  （1.2s・`--ease`・初めは透明から・動きを減らす設定では切り替えるだけ）。`tests/season-art.js` が見張る。
  `heavy-pace.js`（CPU 1倍）：daily に初めて入る 仕事 717 → 385ms・様式の計算 99 → 99回、延べ 135,025 → 8,669要素・
  404 → 51ms（回数はそのまま、一回が紙一枚ぶんになった）。

### 2. 夜に tasks を開いていると、いびき（z Z）が止まらない（中・電池）

- 何が：`.road-bed.is-snore .road-z` の `road-snore`（2.6s・infinite）。SVG の中の動きは合成に乗らず、
  毎フレーム様式と配置をやり直す。起きる前・寝たあとに tasks を開いているあいだ、ずっと。
- 測った数（CPU 1倍）：じっと5秒で仕事 487ms（配置 307回・様式 308回）。ほかのタブ・昼の tasks は 10ms 前後。
  試験のブラウザ（Chromium）の数。iPhone で同じかは確かめていない。
- 案（決めてもらう）：(A) 三回ほど いびきをかいたら止めて、置いたまま（動きを減らす設定と同じ姿）。
  開き直す・触ると また三回。(B) いまのまま。
- → **利用者の答え（10月8日）：A（三回で止める）。**
- → **直した（10月8日）。** `road-snore` を3回にし、続けて `road-snore-rest`（最初の姿から置き場所へ出てくる）で
  止める——止まった姿は動きを減らす設定と同じ（そちらは `animation: none` のまま）。大きい Z は半拍早く止まる。
  開き直す（画面が出直すと頭から）・道に触る・アプリへ戻る（`day-road.js` の `snoreAgain`）と、また三回。
  のぼっている最中に触っても頭からにしない。`tests/road-bed.js` が見張る。
  `heavy-pace.js`（CPU 1倍）：夜の tasks じっと5秒（開いて1.5秒後から）517ms → 550ms（配置 300 → 301回。まだ
  三回の途中なので同じ）、**止んだあと**（足した行）60ms（配置 0回・様式 0回）。前は夜じゅう5秒ごとに約500ms。
