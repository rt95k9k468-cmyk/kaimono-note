# デザイン・UI の総点検（2026年10月21日）

利用者の「くらしノート全体を見て、デザインと UI をより良く・洗練させる方略を。関係アプリやサイトを調べ尽くした上で」を
受けた記録。main の `36743fe` を、**実際の画面を撮って**見た。**ここに書いたのは案**——決めたものは plan.md と該当する
docs（look・glass・icons ほか）へ短く移す。次に点検するときは、下に日付の節を足す。

## 0. 結論

1. **部品の札を作る段階は済んでいる。** 余白8段・角5段・行の背丈3つ・札の背丈2つ・絵2段・太さ2つ・言葉の札・ガラス7つ・
   字の濃さの実測が、札と門の試験になっている（look.md・glass.md）。外から来る「余白・字・色の基準を作りましょう」という
   助言の大半は、ここではもう終わっている。
2. **残っている伸びしろは二つ。** (a) 同じ役目の部品が、画面ごとに別の顔をしている（選ぶ部品が3通り・紙の頭が2通り・
   見出しの色）。(b) 見張り（試験）の外に落ちている場所がある（紙・グラフ・帯の下）。崩れはそこに溜まっていた。
3. 実画面から出た診断は12（Y1〜Y12、3節）。効く順に **Y7 見張りの穴 → Y3 紙の頭の字 → Y1 主色の役目 → Y2 選ぶ部品 →
   Y8 王冠**。
4. **iOS 27 は Liquid Glass を透けにくい既定へ戻し、濃さのつまみを足した**（2026年6月）。くらしノートのガラス（地 52%・
   ぼかし 22px）は一度見比べる。
5. 進め方は **見張りと撮る道具（段A）→ 決めることの無い直し（段B・C）→ 見比べで決めるもの（段D・E）**。どれも記録の形は
   変えない（データ：なし）。

### Y1 主色が「押せる」の合図として薄まっている

- `color: var(--c-primary)` は css に76か所。押せるもの・選んだ札・今日の丸・＋・保存に加え、**押せない見出し**
  （からだの「今日の◯◯」`.diet-hero-label` ほか・「Daily Log」`.arc-log-head h2`・「10月のまとめ」`.arc-stack-head h2`・
  ノートの棚の頭 `.nt-row.is-head`）と、道・体重の線まで同じ色。からだの上半分だけで主色が7か所。
- 押せるかどうかを色で言えなくなる。iOS は tint を押せるものに取っておく。
- 案：主色は**押せる・選んでいる・いま**の三つ。見出しは墨（`--c-text`）、立たせるのは大きさと前の空き。見出しの頭の
  小さな絵だけ主色に残すと、色が一点残って画面の性格は保てる。
- 見比べ1：A 今のまま／B 見出しを墨／C 墨＋頭の絵だけ主色。勧めは C。

### Y2 一つを選ぶ部品が3通り

- 今日｜週｜月 ＝ 主色の塗り（`.wk-faces .seg-btn[aria-pressed]`・高さ 34px）／用事の紙の「やること｜予定」「仕事｜くらし」
  ＝ 白い持ち上げ（`.seg-btn` の既定）／体重の期間 ＝ ばらばらの丸札（`chipRow`）。
- 案：役目で二つに。**見方を切り替える**（一つだけ・2〜5個）＝ `.seg`（白い持ち上げ）。**絞る・選んで入れる**（カテゴリ・店）
  ＝ `.chip`（選ぶと塗る）。体重の期間は `.seg` へ。34px は札の背丈の 40 へ。
- 見比べ2の下段。今日｜週｜月だけ主色を残す案もある（席の中でいちばん強い切り替えなので）。
- 決めたら look.md に「形の札」を一表（言葉の札 U10 と同じやり方）、門の台本で上書きが戻らないことを見る。

### Y3 紙の頭の字が読めない

- 用事の紙の頭（`.sheet-hero`）は地が `color-mix(--cat 82%, #000)`、字は白。基調の塗り（`--c-primary-fill`）の地で、
  題 **3.02:1**、上の添え字「今日 8:30」（`.hero-cap`・`--fs-sm`・白 78%）**約 2.4:1**。カテゴリの色では題が 3.5〜4.9。
  品物の紙の頭（`.pd-hero`）は淡い地に墨の字で読める——同じ部品が2通り。
- 試験が捕まえないのは、`legibility.js` が7画面だけを見て紙を開かないから（Y7）。
- 案：用事の紙も `.pd-hero` と同じ淡い地＋墨。丸薬は今の色のまま。見比べ2の上段（その B は × と ⋯ の印が白いまま
  消えている——作るときは品物の紙と同じ、白い丸に墨の印）。

### Y4 ＋が右端の列にかぶる

- ＋は帯の右上（2026年10月11日の形）。そこは買うものの「済ませる丸」・時間割の済みの印・週の面の主色のボタンと同じ列。
  最後の行は `--fab-room` で避けているが、送る途中の行の丸を＋が隠す（特大の字で特に）。
- 案：下へ送るあいだは＋を小さく引っこめ、止まるか上へ戻すと出す（iOS 26 のタブバーが送ると縮むのと同じ考え。
  「帯は縮めない」には触れない）。動きなので実機で触って決める。

### Y5 絵の様式が6つ・景色が字の下まで

- 出ている絵：線の記号（Phosphor Regular）・シルエット（品物・こと）・水彩の挿絵（daily の三枚 `img/think`）・写真（帯の空・
  daily の紙）・浮世絵（ノートの地）・道の上の色つきの人とベッド。記号の側は icons.md で三系統に締めてあるが、
  **挿絵と景色には置き場の決めごとが無い**。
- 景色が字の並ぶ一覧の下まで来ているのはノート（「最近直した」が広重の上）。daily は 10月8日に「上の帯 430px で紙の色へ
  溶かす」にしてあり、こちらのほうが読める。
- 案（決めごとを一つ）：**景色は帯と紙の頭まで。字の並ぶ一覧の下には敷かない。挿絵は一系統。** ノートの広重は消さず、
  daily と同じく上の帯に収める。道の人とベッドは水彩か記号のどちらかへ。どれも利用者が見比べて選んだ絵なので、置き場と
  描き方だけを見比べで。

### Y6 折り返しと切れ

- 夜のやることの「このあと、決まった予定はありません・明日は 11:00 歯医者」の後ろの「から」だけが次の行に落ちる。
  css の `text-wrap` は空の画面の balance の2か所だけ。
- 道の札は「資料をまとめ…」「買い物へ行…」「洗濯物をたた…」とほとんどが切れる。時刻が字数を食っている。
- 案：一〜三行で終わる知らせ・見出し・空の画面に `text-wrap: balance`。日記・ノートの本文には付けない（`text-autospace`
  で iPhone の幅の見積もりに懲りたので、入れたら iPhone で必ず見る）。道の札は「時刻は目盛りに任せて題だけ」か
  「二行まで」を見比べ。

### Y7 見張りの穴

- **紙**：`legibility.js` は7画面だけ。Y3 はここで漏れた。
- **SVG の字**：体重のグラフの軸と目標の札は **8px**（`.diet-axis`・`.diet-goal-tag`。描かれた高さ 10px）。暦の小窓の今日は
  9px（`.pop-cal-day.is-today small`）。「字は 11px 未満にしない」の外。`--fs-k` を掛けない理由（SVG の寸法の計算）は
  look.md にあるが、11px の下限とは別の話。
- **帯の下**：送った中身の字（「AI推計」「アイコンについて」）がガラス越しに読めて、席の名前と字が重なる（Chromium で撮影。
  iPhone の Safari のぼかしでの見え方は確かめていない）。
- 案：legibility.js に主な紙（用事・品物・daily の記録）と SVG の字を足し、出たものを直す（軸は 11px にして寸法の計算を
  合わせる）。帯の下は、帯の裏に地の色から透明への幕を一枚（ぼかしは足さない＝重くしない。iOS の hard に近い）——
  実機で見比べ。

### Y8 比べる相手が無いのに最安の王冠

- 値段が一つの店にしか無い品物にも王冠が付く（試しでは鶏むね肉・食パン・卵）。ほとんどの行に王冠が付き、王冠が何も
  言わなくなる。roadmap-2026-10 の柱7「出している事実を、正しくする」と同じ話。
- 出しているところ：`screen-list.js`（908行）・`screen-prices.js`（359・388行）・`product-sheet.js`（226行）。
- 案：王冠は**二つ以上の店の値段があって、その中でいちばん安いとき**だけ。一つなら店の名前だけ。

### Y9 設定の一行カード・大文字小文字

- 「目標」「AIに分析してもらう」「記録を書き出す」「取り込み」が一行ずつ別のカード。束ねると一画面ぶん短くなる
  （iOS の設定は、関係する行を一つの束にする）。
- 節の見出しが「health」（小文字・席の名前）と「General」（大文字）。そろえるなら「general」。

### Y10 からだ：記録の無い日の空の輪

- 歩数・総消費・睡眠・飲酒の4つの灰色の輪が「—」で並び、画面の上半分で「まだ」を4回言う。
- 案：記録の無い指標は輪を描かず、名前と「—」の低い札に。記録が入ったら輪になる。

### Y11 暗い面の道のオレンジ

- 明るい面の淡い桜色の道が、暗い面ではあざやかなオレンジになり、画面の主役になる。明暗で意味と強さが同じに見えるかを
  実機で。

### Y12 週の面の「（日）」

- 今日｜週｜月 の右に、薄い「（日）」が透ける（貼りついた切り替えの下に見出しが重なっている）。撮った瞬間だけかも
  しれない。週の面を開いて確かめる。

## 4. 方略（柱）

- **A 色は三つの意味だけ**：押せる・選んでいる・いま＝主色／分類＝カテゴリ・棚・食事の時の色／それ以外＝墨。→ Y1・Y11
- **B 同じ役目は同じ形**：言葉の札（U10）と同じやり方で「形の札」を look.md に一表（選ぶ部品は二つ・紙の頭は一つ・
  設定は関係する行を一つの束）。門の台本で戻りを見張る。→ Y2・Y3・Y9
- **C 絵の文法**：記号（三系統のまま）／景色（帯と紙の頭まで）／挿絵（一系統）。→ Y5
- **D 見張りを画面の外まで**：見た目の決めごとは、試験があることで守られてきた（太さ・行の背丈・言葉）。紙と SVG にも
  同じ網を。→ Y3・Y7
- **E 事実の見せ方を正しく**：比べていない王冠は出さない・記録の無い指標を輪にしない。→ Y8・Y10
- **F iOS 27 の手触りへ（足さずに）**：ガラスの濃さを見比べる。検索の席は足さない。帯の下の幕だけ借りる。→ Y7
- **G 決め方を安くする**：利用者は書体・数字・ガラス・季節の絵を、見比べの画像で決めてきた。そのたびに撮る台本を
  書き起こしている。撮る道具を `tools/` に一本（試しの記録・明暗・時刻・特大・紙を開く・差し替えの style・並べて番号を
  書く）。tests/ と同じく配らない。
