# 動き（--m-* と曲線・指を離したあとの滑り）

CLAUDE.md から見出しごと移した、詳しい決めごと（2026年9月26日）。
本文は移す前と一字も変えていない。入口（どの docs を読むか）と、どの画面でも
踏む罠は CLAUDE.md にある。**新しい決めごとは、ここ（該当する docs）に書く。**

### 動きは、名前で持つ（`--m-*` / 曲線）

**速さを数字で書かない。** CSS の `transition` / `animation` に生の秒数を
置くと、同じ出来事が場所ごとに違う速さで返るようになる——実際にそうなって
いて、「押した」が `.08` / `.1` / `.12` / `.14` 秒の四通り、「状態が変わった」が
三通り、「画面が変わる」が三通りあった（**リテラル60か所**）。いまは **0か所**。

速さの名前（`css/base.css` の motion の節）：

| | |
|---|---|
| `--m-press` | 指の下で起きること |
| `--m-state` | 押した**あと**、札や欄が新しい姿に落ち着く |
| `--m-check` / `--m-strike` / `--m-number` | 印が付く／取り消し線／数が変わる |
| `--m-add` / `--m-delete` | 増える・減る（減るほうが速い） |
| `--m-reorder` | **位置が変わる**（よける・暦の輪が滑る・電卓の上下） |
| `--m-settle` | 組み直したあと、行がもといた場所から滑って収まる（FLIP） |
| `--m-sheet-open` / `--m-sheet-close` / `--m-sheet-grow` | 紙が開く／閉じる／＋から育つ |
| `--m-nav` / `--m-push` | 席を移る／引き出しが押しのける |
| `--m-swipe` | 払って、指を離してから行き先まで滑る |
| `--m-grow` | **器そのもの**が伸び縮みする（暦・帯・欄） |
| `--m-spark` / `--m-flash` | 一度だけ出る光／一度だけ見てほしい |
| `--m-success` / `--m-warn` | うまくいった／気をつけて |

曲線も同じ（`--ease` / `--ease-out` / `--ease-in` / `--spring` / `--push-e` /
`--ease-glide` / `--ease-settle`）。**出てくるものは `--ease-out`、去るものは
`--ease-in`。** 四つの面の指定が全部 `--ease-out` で、去る面が「出てくる動き」で
出ていっていた。

- **開く速さと閉じる速さは、class の付け外しで分ける。** 素の `.sheet` に
  閉じる速さ、`.sheet.is-open` に開く速さ。`--m-sheet-close` は用意だけして
  **誰も読んでいなかった**——紙は開くのも閉じるのも同じ .3s だった。
- **JS 側に数字を二重に持たない。** `KN.motion.ms("--m-nav")` と
  `KN.motion.ease("--push-e")` が CSS から読む。`app.js` の `SLIDE_MS`/`FACE_MS`、
  `ui.js` の閉じる待ち時間、`edge-back.js` の曲線は、もうここを通る。
  `edge-back.js` は `"cubic-bezier(.32,.72,0,1)"` を**文字列でべた書き**していて、
  それは `--push-e` と同じ数だった（`--push-p` / `PARALLAX` と同じ罠）。
- **`--m-reorder` は .32s → .24s に直した。** 書いてあったが**どこからも読まれて
  おらず**、実際の CSS は .24s を直に書いていた。名前を現実に合わせた側。
- **`KN.ui.flipRows` は、行のある三画面ぜんぶが通る**（買うもの・daily・
  **やること**）。組み直す前に行の居場所を測り、組み終わってから `settle()` を
  呼ぶと、動いた行が**もといた場所から**滑ってくる。新顔だけが `is-arriving`
  で名乗る。
  - やることは長いあいだ**呼んでいませんでした**——`.tl-row` には前から
    `data-flip` が付いていたのに、見る人が居なかった（目印だけあって、
    使われていない。`--m-sheet-close` や `--m-reorder` と同じ形の見落とし）。
    時間割に一件足すと、その下の行がいっせいに瞬間移動していたのはこれ。
  - **丸ごと入れ替わるときは、向こうが見送ります**（新顔が半分を超えたら
    「編集ではなく行き先の変更」）。日を替えたときに全部の行が「もといた
    場所」から飛んでくると、別の日の行が滑ってきたように見えるので。
    実測：一件足すと 8 回ぶん置き直され、暦で昨日へ移ると 0 回。
  - 紙を横に払って日を替える道は、そもそも組み直しを通らない（`adopt`）ので
    ここには来ません。

### 指を離したあとの滑りは、一本から出す（`KN.motion.glide`）

**決まった時間で滑らせない。** day-swipe 200ms・cal-swipe 200ms・edge-back
260ms・紙の面 280ms と、四か所が自分の数を持っていた。指の速さ（`vx`）は
計算してはいたが、**「行くか戻るか」の真偽にしか使われていなかった**
——だから 27px で離すと 363px を 200ms で駆け抜け、380px まで引いて離すと
10px を 200ms かけて、**同じ時間**。前者は弾かれたように、後者はもたついて
見える。

`KN.motion.glide(dist, v, {span, base})` が `{ms, ease}` を返す。決めるのは二つ：

- **時間** … 勢いがあれば「その速さで行けば着く時間」（`dist / v`）、無ければ
  **残りの道のりに比例**（`span` に対する割合）。短いほうを採り、`base` の
  0.45〜1.6倍で頭打ち。実測：27px→126ms、363px→261ms、363px を 2.5px/ms で
  払えば 145ms。
- **曲線** … **出だしの傾きを、離したときの指の速さに合わせる**。ベジェの
  初速は `p1y/p1x` なので、`p1x` を 0.25 に固定して `p1y` を `v·t/d` に
  合わせる。これが「勢いを引き継ぐ」の正体で、`--ease-out` を一律に当てて
  いたころは、ゆっくり離しても出だしだけ速く、指の動きと繋がらなかった。

決めごと：

- **`dist` も `v` も符号つきで渡す。** 向きが合っているかは glide が見る
  ——呼ぶ側に掛け算させると、いつか符号を落とす日が来る。
- **`span` は必ず渡すこと。** 渡さないと道のりの割合がいつも 1 になり、
  近くで離しても遠くと同じ時間になる。
- **`--m-swipe` が唯一のつまみ。** 上下の頭打ちもそこから出るので、「全体に
  もう少し速く」はこの一行だけ。
- 動きを減らす設定では `ms: 0` を返す。呼ぶ側は `g.ms ? … : ""` で足りる。

**端の向こうは `KN.motion.rubber(over, limit)`。** 行けない向きに引いた指も、
ついてはくるが進まない——止めてしまうと、そこで指と絵が切れる。実測：
-20→-14.3、-100→-33.3、-400→-44.4（limit 50 を越えない）。

### iPhone で震わせる（`KN.motion.tick`・C1）

2026年9月27日。iOS の Safari は `navigator.vibrate` を持たない。iOS 18 から、
`<input type="checkbox" switch>` が切り替わるときに端末が軽く震えるので、head に
見えないつまみを一つ置き、その札を押したことにして震えだけを返す。

- **公式の道ではない**（いつかの iOS で黙って止まりうる）ので、**三つだけ**：
  `check` 済ませた（やること・買うもの）・`drop` 持ち上げて置いた（時間割・
  買うものの並べ替え）・`close` 紙を下へ払って閉じた。押すたびには震わせない。
- 動くのは Apple の端末で `navigator.vibrate` が無いときだけ。Android はこれまで
  どおり `buzz` / `haptic()` が震わせる（呼び出し側は両方を呼んでいてよい）。
- 押したことにした click は、札とつまみの上で止める（外を押したら閉じる、などに
  届かないように）。**並べ替えの「click を食べる」より前に呼ぶ**こと（reorder.js）
  ——後にすると、震わせるための click まで食べられる。
- 机の上の Chromium では「つまみが切り替わったか」までしか確かめられない。
  **震えるかどうかは実機でしか分からない**（iOS 18 より前は震えない）。
- C4（済ませたときの手ごたえ）の見た目——光る・線・丸がひと回り・落ちる——は
  前からある。C4 の残りは iPhone の手ごたえで、それがこれ。
