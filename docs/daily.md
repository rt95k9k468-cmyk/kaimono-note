# daily（一日ぶん）

CLAUDE.md から見出しごと移した、詳しい決めごと（2026年9月26日）。
本文は移す前と一字も変えていない。入口（どの docs を読むか）と、どの画面でも
踏む罠は CLAUDE.md にある。**新しい決めごとは、ここ（該当する docs）に書く。**

### daily は、一日ぶん

Daily Log は**暦で選んでいる日の一日ぶんだけ**を出す（`settings.dailyScope`、
既定は `"day"`。設定で `"month"` にすると月ぜんぶを縦に並べる）。月ぜんぶを
並べていたが、書いた日が増えるほど今日の一行は下へ流れていく——毎日開くのは
今日を書くためなのに、今日がだんだん遠くなる作りだった。日を移すのは暦の役目。

- まだ何も無い日は、**空のまま一行出す**。無いことを言うためではなく、押せば
  書けるところがそこに要るから。「押して、この日のことを書く」（`is-blank`）。
  その日は起床・就寝も帳簿（作成・更新）も出さない——書いていないので。
- **空の一行は「この日のことを書く」と言う**（2026年9月26日、
  `docs/improvements.md` の B8）。「—」だけでは押せる行だと伝わらず、日記の
  いちばん大事な入口が横棒一本だった。言うのは**一日ぶんを出しているとき
  だけ**——月ぜんぶを並べると、書いていない日ごとに同じ字が並んで「書かなかった
  日」の一覧になるので、そちらは「—」のまま。色は薄い字（`.is-blank`、
  `--c-text-3`）のまま。
- **「何も書いていない日」は、記録が無い日だけではない。** 日記の紙を開いて
  何も書かずに閉じると、`ensureDayLog` が**空の一件**を置いていく。それを
  「ある日」として描いていたので、意味のない横棒が四つ並んだ
  （「20 日 — 起床 - ・ 就寝 - 作成 -」）。**有無ではなく中身で見分けること**
  ——`memo` が空で `wake` も `sleep` も無ければ `isBlank`。
- **`createdAt` は、持っていなければいま押す。** 空の一件は `createdAt` を
  持たない（まだ人が書いていないので）。`cur ? cur.createdAt : stamp()` と
  書いていたころは、**紙を一度開いてから書いた日だけ「作成 -」のまま**
  残った。`(cur && cur.createdAt) ? cur.createdAt : stamp()`。
- **日付の下書きは、本文に触れたときだけ残す**（`openLogSheet` の `memoOut`、
  2026年9月26日）。空の日を開くと本文の頭に日付と「育休完了まであと◯日」を
  下書きするが、保存は本文・起床・就寝をまとめて比べて走るので、時刻だけ
  入れても下書きの日付だけの本文が残っていた。触れていなければ本文は元のまま。
  （`docs/improvements.md` の A5）
- **月のまとめは、日を絞っていても出す。** Daily Log が一日ぶんになったいま、
  この一段だけが月の話をする。
- **線は引かない。** 一段ごとに上下へ線を入れていて、一画面に六本並んでいた。
  分かれていることは**余白のほうが言う**（`.tl-sheet.is-daily` の gap、16→32px）。
- **紙を左右に払うと、月ではなく前日／翌日**（`goDayTo` ／ `js/day-swipe.js`）。紙に出ているのは
  「その日」なので。月は上の題を押せば選べる。先の日へは行かない。
- **本文は 16px の両端揃え**（`text-align: justify`）。日本語は字幅が揃って
  いるので、右端がそろうと一枚の紙の面として落ち着く。右の余白は左より広く
  ——本文が縁に触れると、読み終わりが窮屈になる。
- **字は一段ずつ大きい**（見出し 14→16px、日の数字 14→19px）。
  小さい字はそれ自体が静かな画面の作りかたではあるが、毎日読むものとしては
  小さすぎた。静けさは字の小ささではなく、**空きの多さ**で持たせる。
- 「今日を書く」ボタンは外した——すぐ下の行が押せば開くもので、＋の紙にも
  同じ口がある。同じことへ三つ目の入口を作ると見出しが重くなるだけ。
- 積み上げの札は**あるものだけ**。五種類ぜんぶを always 出していたので、
  一件も書いていない月でも六つの丸が並び、その下は空だった（中身より操作の
  ほうが多い画面）。並べ替えとお気に入りも、並べる相手がいるときだけ。

### 本文が「読み込み中」「読めません」のとき（2026年9月28日）

日記の本文は大きな保存場所（IndexedDB）の写しが基準（docs/storage.md の
「写しが正しい」）。`KN.diaryIdb.body()` が `"ok"` 以外のとき：

- `"loading"`（開いた直後、写しとの突き合わせの途中）：本文は元の字のまま出す
  （段1 のあいだは元にある）が、日記の紙は開かず、写す（コピー）・月の書き出しも
  断る。「読み込んでいるところです」とだけ言う。
- `"off"`（大きな保存場所を読めなかった日）：Daily Log の本文の欄と「あの日」の
  本文だけ「読めません」（薄い字 `.is-blank`。責める色は当てない）。書いていない
  日も同じ字——元から本文を外したあとは、どの日に書いたかも分からないので。
  起床・就寝・作成・更新・その日の記録は通常どおり。行を押すと紙は**本文の欄なし**で
  開き、起きた・寝たは書ける（`setDayLog` へ本文を渡さない）。
- 済んだら `KN.diaryIdb.onChange` で daily を描き直す（app.js）。読めなかった日は、
  前に出てきたとき・行を押したときに読み直す（`retry()`、5秒あけて）。

### 季節のひとこと（R2・2026年9月28日）

一日ぶんのとき、Daily Log の見出しのすぐ下（その日の行の上）に、その日の
**二十四節気・七十二候**を小さく二行、名前つきで（「二十四節気　秋分」「七十二候　蟄虫坏戸（むしかくれてとをふさぐ）」。2026年9月29日、利用者が「何を指すか出して」と。`KN.season.rows`）。**期間も付記**（節気は約15日・候は約5日。「9/23-10/7」の形（利用者が選んだ）。年をまたいでも月日だけ（「12/22-1/4」）。`KN.season.span`、境目の判定は `of()` と同じ＝日の終わりの黄経）。期間は日付の途中で折り返さない（`nowrap`）。

- 計算は `js/season.js`（端末の中だけ・通信なし）。太陽の視黄経を Meeus の簡略式で
  出し、**その日の終わり（翌日0時、端末の時刻）**の黄経で決める——その日のうちに
  境目を越えたら、その日が初日。固定の日付表ではないので、どの年でも合う
  （2025〜2027年の節気の初日を暦要項と照らした。`tests/season.js`）。
- 月ぜんぶを並べるときは出さない（どの日の、が一つに決まらない）。
- 色は変えない。字を一行足すだけ（`--fs-sm`・400・`--c-text-2`）。長い読みは折り返す
  （切ると言葉が欠ける）。
- 設定 → daily の「季節のひとこと」（`settings.showSeason`、既定 true。鍵が無い保存は
  `reconcile()` で true）。
- 数えも比べもしない、ただの暦の言葉。字が daily の禁止語に当たらないことは試験で見る。

### ＋は記録の紙から、日記は頭の札（2026年9月28日）

＋を押すと「Daily Log／記録」の二択が出ていたが、毎回どちらかを選ぶ一手がはさまって
いた。＋で書きたくなるのはたいてい記録なので、**＋は記録の紙（`openEntrySheet`）を
直に開く**。日記へは、紙の種類の札の並びの**先頭の「日記」**から一押し。

- 日記の札は種類ではなく行き先なので、同じ大きさだと埋もれる——一回り大きく
  （`--fs-md`・余白9/16px）、主色の字（`--c-primary`）と薄い主色の地、あとに余白
  （`.arc-pick-diary`）。並びは `align-items: center`（伸ばすと皆同じ高さになる）。
- 押すと紙を `tryClose()` で閉じてから（書きかけがあれば、ほかの閉じ方と同じく保存を
  試す）その日の日記（`openLogSheet(writeDay())`）。直す紙には出さない。
- 種類の既定は今までどおり読書（前回の本を下敷き）。
- 試験は `tests/capture.js` の終わり。

### 同じ日の年々と、出さない日（R9・2026年9月29日）

「あの日」の一枚は、**同じ月日の記録が過ぎた年に二つ以上ある**ときだけ、紙の10年日記の
ように年ごとに一行ずつになる（`store.archiveYears()`、`screen-archive.js` の `yearsCard`）。

- 遠い年から（10年前まで）。**記録の無い年は行ごと出さない**——空いた年を置くと、
  書かなかった年の一覧になる。年の数も言わない（「◯年分」を出さない）。
- 一行は「2024年 日」と、本文（2行で切る）か、本文が無ければ積み上げの題を二つまで
  （三つ目からは「ほかにも」）。本文が読めない日（`"off"`）は「読めません」の薄い字。
- 枠は押せず、**行が押せる**（その日へ `goToDay`）。一つなら、いつもの一枚のまま。
- 出すかどうかは今までの「「あの日」を出す」（`showThen`）がそのまま効く。

**出さない日**：その日を「あの日」「年々」「過ぎた日のどれか一つ」に出さない印。

- 置き場は `archive.quiet`（日付の並び）。**日の行（days）には持たせない**——空にした
  行は行ごと消えるので、印まで一緒に消える。鍵の無い保存は `reconcile()` で `[]`
  （移行なし・どの日も今までどおり出る）。古い版で開くと印だけ落ちる（記録は無事）。
- 付け外しは、その日の log の紙（`openLogSheet`）の終わりの小さなボタン
  「この日を「あの日」に出さない」⇄「「あの日」にまた出す」。**消すのではなく出さない
  だけ**——暦から行けばいつでも読めるし、ぜんぶをさがす（R8）にも出る。
- 一覧（出さない日の並び）は作らない。数を出すことになるので。
- daily-rules.js の「archive の器」は `entries`・`days`・`quiet` の三つ。quiet は
  日付だけで、数も目標も持たない。
- 試験は `tests/then-years.js`。

### 年の本（R10・2026年9月29日）

一年ぶんを、**事実だけ**の一冊に書き出す（`js/yearbook.js` の `KN.yearbook`）。置き場は
daily の画面ではなく**設定（daily の歯車）→ 書き出し → 年の本**——daily に置くと
禁止語（平均・先月 など）に当たりやすく、設定に置けば daily の画面は変わらない。
（2026年9月30日まではバックアップと書き出しの中。docs/settings.md の「二段の一覧」）

- 章は四つ、この順：**積み上げ**（種類ごと・日付の順。読書は著者も、メモは本人の字のまま）・
  **初めて買ったもの**（その品物の、残っている買った記録のうち最も古い日がその年のもの）・
  **よく買ったもの**（その年に二回以上。回数つき、多い順に十まで）・**日記**（日付の順、本文そのまま）。
  中身の無い章は章ごと出さない（「ありません」と書くと、無いことの一覧になる）。
- **記録の形は変えない。** 新しい入れ物を持たず、書き出すそのときに store から引いて組む
  （「写さず引く」）。試験で state が書き出しの前後で一字も同じことを見る。
- **比べない・率を出さない・目標を言わない。** 数を言うのは「よく買ったもの」の回数だけ。
  日記の日の数・積み上げの件数は言わない。ほかの年と並べない。
- 種類「達成」は、本の中では**「やったこと」**と書く（禁止語に当たるので）。記録の種類は変えない。
- 買った記録は「買ったもの」に残っている `items`（`checked` と `checkedAt`）から。買ったあとで
  消した行・チェックを外した行は入らない（残っているものだけの事実）。
- 出さない日（R9 の `quiet`）も本には入る。あれは「あの日」に**ひとりでに出てこない**印で、
  自分で一年を書き出すときに抜く印ではない。
- 選べる年は記録のある年だけ（新しい順）。今年に記録があれば今年、無ければいちばん新しい年。
- **印刷**は別の窓を開かない（ホーム画面のアプリでは Safari へ飛ぶ）。本の一枚
  （`#yearbook-print`）を body の直下に置き、`html.is-printing-book` のあいだの
  `@media print` でほかを隠す（components.css の「年の本」）。紙は白地に黒い字。日記の章は
  新しい紙から。`afterprint` で片づける。iPhone では印刷の画面から「PDF に保存」。
- **Markdown** は `kurashi-YYYY.md`。指で触る端末は共有シート、ほかはダウンロード。
- 本文が入るので、月ぶんと同じ門（`monthExportBlocked`）：読み込み中・読めない日は断る。
- 試験は `tests/yearbook.js`。

### メモの無い積み上げに「-」を出さない（R27・2026年9月29日）

積み上げの行（`.arc-row`）は、メモが無ければ `.arc-memo` の段ごと出さない。前は「-」が
一つ置かれていて、書かなかったことを指さす印に見えた（daily は評価しない）。
`tests/daily-rules.js`。

## 記録を書く：変化の札を外した（2026年10月2日）

利用者の希望で、書く札から「変化」を外した（札が一段減る）。種類（`store.ARCHIVE_TYPES`）と書いた
記録はそのまま——種類から消すと、読み直し（`reconcile`）で「達成」に化ける。変化の記録を直すとき
だけ札が出る。

## 鍵：daily とノートだけを閉じる（2026年10月3日、`js/lock.js`）

端末を手に取った人が daily とノートを開けないようにする**表の鍵**。中身は暗号にしない
（localStorage・バックアップ・日記の写しはそのまま。開発者ツールなら読める）。鍵は記録に
一切触れないので、なくしても消えるものは無い。設定は daily の歯車 → ロック ›。

- **開けかた**：この端末の Face ID / Touch ID / Windows Hello（WebAuthn、あれば）が主。顔が合わなければ
  iPhone 純正のパスコードの画面が出る（`userVerification: "required"`）。アプリの**番号**（必ずある）は予備で、
  新しく決めるのは **4桁か6桁**（前に決めた 4〜12桁はそのまま通る）。Face ID を登録していれば、覆いは大きな
  「開ける」一つで、鍵盤は「番号」を押すまで畳む（V27、10月5日の利用者の声）。パスコードは PBKDF2（10万回）で崩した形と桁数だけを
  `settings.lock` に置く——設定なのでバックアップに乗って別の端末へも行く。Face ID の鍵（credential
  の id）は端末ごとなので state に置かず、localStorage の `kaimono-note-lock-dev` にだけ置く。
  本人確認（UV）の印が立っていないと通さない。
- **閉じる時**：立ち上げ・裏へ回ったとき（`visibilitychange` hidden / `pagehide`）。開けたあとは
  タブを行き来しても閉じない。
- **覆う所**：daily・ノートと、そこから潜った設定（`openedFrom()`）。覆いは画面ぜんぶ
  （`--z-lock`、紙もトーストも隠す）。**下の帯だけは覆いの上に残す**（`.is-locked .tabbar`）——Face ID を
  断ったあともほかのタブへ（V27）。帯の無い設定の上だけ、左上の tasks の絵。
  `show()` が**組む前に**覆うので、中身は一瞬も出ない。タブを押して来たときは押した一拍の
  うちに Face ID を自分から試す。開いたとき・表へ戻ったとき（`pageshow`・`visibilitychange`・`focus`）も
  パスコードで待たずに自分から出す（2026年10月3日、利用者の希望）。閉じるたびに一度だけ——300ms 未満で
  断られたら「iOS が出さなかった」として数えず、次の合図でもう一度。
- **漏れ口**：daily・ノートの中身を読むほかの画面は全体の検索だけ（2026年10月3日に grep で
  確かめた）。閉じているあいだ `search-all.js` は daily とノートを探さない（`KN.lock.hides`）。
  新しく daily・ノートの中身を出す画面を作るときは、ここに並べて同じく伏せる。
- **外す・変える**にはパスコードが要る。外すと Face ID の鍵も忘れる。パスコードを忘れたら
  画面からは開けない（記録はバックアップから別の端末で読める）。
- iOS のアプリ切り替えの絵：裏へ回る（hidden）より前の、窓が手を離れた瞬間（`blur`）にも覆いだけ被せる
  （`.is-shield`、錠の絵だけ。鍵は閉じず、`focus` で外す。共有の紙・ファイルを選ぶ画面でも被さる）。
  それでも間に合う保証は無い（V27）。
- 試験は `tests/lock.js`。

## 2.0 の daily の紙（roadmap-2.0 の V21・2026年10月4日。V26（10/5）で既定）

- 日記の抜き出し（あの日の `.arc-then-memo`）は**五行**（Daily Log は下の「終わりの数行」に変わった）。
  三行だと頭の決まった行で埋まり、地の文まで届かなかった。積み上げのメモ（`.arc-memo`）は三行のまま。
  **切った Daily Log は両端揃えにしない**（`text-align: start`）。iPhone では切った最後の行まで引き伸ばされ、
  「…」が字に重なった（V26、利用者 10/5）。全文のときは両端揃えのまま。
- 紙の器（`.tl-sheet.is-daily`）は下の角も丸く（`--r-xl`）。帯の下に 16px のぞく端を、切れた紙に見せない。
- カードは今のまま（V11 で A を選んだ）。試験は `tests/v2-switch.js`。

## 期間を選んで書き出す（roadmap-2.0 の V22・2026年10月4日）

設定（daily の歯車）→ 書き出し →「期間を選んで書き出す」。始まり・終わりを年・月・日のドラムの小窓
（`KN.ui.popDate`、V27。前は暦の小窓）で選ぶ。決まるのは小窓を閉じたとき（既定は今月の一日から今日。始まりを終わりより後にすると終わりが追う）。
- 中身は `store.exportRange(from, to)`：両端の日を含む、月ぶんと同じ形（`kind: "daily-range"`・`from`・`to`）。
  **読む用だけ**。`kind` を持つのでバックアップとしては読まない（`readBackup`）。月ぶんは前のまま。
- 本文が入るので、月ぶんと同じ門（`monthExportBlocked`）。紙に出す数は月ぶんの行と同じ（Daily Log ◯日・積み上げ ◯件）。
- 機械の時刻（`createdAt`・`updatedAt`）は外す（10月4日、利用者が見本に印を付けた）。記録からは消さない——
  写しから外すだけ。ほかの欄（`id`・起床の印・空の欄）は残す。試験は `tests/daily-range.js`。

## コピーは、その日のことだけ（2026年10月5日）

Daily Log のコピー（`dailyCopyText`）から「明日以降の予定」「長期タスク」を外した（利用者：未完のものは日が変わってもほとんど同じ）。
写すのは本文・起床就寝・済んだやること・買ったもの・からだ・食べたものだけ。試験は `tests/daily-rules.js`。

## 書く紙はノートと同じカード（2026年10月6日）

日記（`openLogSheet`）と積み上げ（`openEntrySheet`）の紙を、ノートの書く紙と同じ四隅の丸い白いカードにした
（利用者「メモ欄が狭いし色合いも暗い」）。`KN.ui.sheet` に `cls: "is-card"`・`clear: true`。形の数は
`.sheet.is-note` と同じ（電話の幅で `--sp-2` 浮かせる・底は `max(--sp-2, --safe-b)`）。背いっぱいに伸ばし、
余った高さはメモ欄（`.arc-memo-field`）が取る（最小5行。読書の欄が多い記録でも「書く」が画面に残る）。
払って戻る・引いて閉じるは付けていない（ノートだけ）。試験は `tests/capture.js`。

### 記録の紙：札は一列・書籍と論文は別に覚える（2026年10月6日）

- 日記＋種類の札は折り返さず一列（`.arc-pick` は `nowrap`、札は余白を詰めて幅を分け合う。375px でも入る）。
- 読書の「本」は「書籍」、「名前」は「タイトル」。
- 書籍と論文は、タイトル・著者の下敷きと候補を別々に覚える（`store.readingCandidates(kind)`・`lastReading(kind)`。
  引数なしは前のまま）。新規で札を切り替えると、その種類の前回（書きかけならそれ）に入れ替わる。直すときは入れ替えない。
- 論文は開始・終了ページの欄を出さず、保存も `null`。前から持っている論文のページは消さない。

### 日記の紙：見出し・「あの日」の札を外した（2026年10月6日）

- 本文の欄の見出し「その日あったこと・したこと」は置かない（紙の題で足りる。欄は `aria-label="日記"`）。
- 「起きた」「寝た」は「起床」「就寝」。
- 「この日を『あの日』に出さない」の札は外した（利用者「要らない」）。R9 の印も読まない（`isQuietDay` はいつも
  false。利用者が選んだ）——どの日も「あの日」に出る。印のデータ（`archive.quiet`）は消さずに残す。試験は `tests/then-years.js`。

### 打っているあいだは、メモ欄だけ（2026年10月6日）

利用者「キーボードが出るとメモ欄が狭すぎる。日付で場所をとりすぎ」。
- 記録の紙の日付は一行（`.arc-date-field`：字と欄を横に）。
- `.kb-open` でカードのメモ欄（`.arc-memo-field`）に字を打っているあいだは、ほかの段（札・日付・起床就寝）と
  「メモ」の字を `display:none`。余った高さはメモ欄が取る（最小3行）。日記の紙にも効く。電話の幅だけ。CSS の `:has()` だけで、
  キーボードを下げれば戻る。試験は `tests/card-memo-kb.js`。

## Daily Log の「3行」「5行」は終わりの数行（2026年10月6日）

見せ方は「全文／3行／5行」（利用者）。切るときは**頭ではなく終わり**を出す——日記は頭に決まった行が並び、その日の地の文は終わりにある。
- 設定は `logFull`（前のまま）＋ `logLines`（3／5、無ければ5）。前の「数行」は5行として読む（移行なし）。
- `.arc-log-memo.is-tail`：中身を `<span>` に包み、器を flex-end・`max-height: 1.85em × --tail-n`・overflow hidden。あふれた頭は上へ出て隠れる。
  切れたときだけ `is-cut`（頭を mask で薄く）。行は紙に付く前に作るので、測るのは ResizeObserver（`tailSeen`）。
- 両端揃えにしない（V26 のまま）。積み上げのメモ・「あの日」は頭から切るまま。試験は `tests/daily-tail.js`。

## 活動の長さ・道へ（3.0 の A1・2026年10月6日）

記録の紙に「道に置く」（新しく書くとき。読書・学習）と「道に記録する」（前の記録）。積み上げの行に長さ（「30分」）、

## 季節の絵（3.0 の E1・2026年10月6日・`js/season-art.js`）

daily の紙の**中身の後ろ**（紙の地）に、選んでいる日の七十二候の色と、あれば浮世絵をごく薄く。上（Daily Log の頭の
あたり）でいちばん見え、下へ向かって紙の色に溶ける。絵は72候すべてに一枚ずつ（2026年10月6日。広重『名所江戸百景』、
NDL イメージバンク。対応表と手順は `docs/season-art.md`）。
- 層は紙の `background` に上から：候の色のぼかし（`--season-tint` 38%、暗い色 14%）・紙の色の幕（絵の濃さ `--season-alpha`
  8%、暗い色 5%）・絵（`--season-img`）・紙の色。紙は送る器なので、地は送っても上に留まる。掴み手と Daily Log の段
  （`.card.arc-log`）は紙と同じ地を持っていたので、季節の色の上では透かす（色の無いときと見た目は同じ）。
- 値は `KN.seasonArt.apply(#screen-archive, 日)` がこの画面に書く（`:root` に書かない）。`render` のたび。`data-season` に
  候の番号（`season.of(day).k`、春分の初候から 0〜71）、絵が読めたら `data-season-img`。
- 色は二十四節気の淡い色を、候ごとに次の節気へ三分の一ずつ寄せたもの。絵の平均の色は使わない（どれも灰色だった。
  `docs/season-art.md`）。
  候が変わると `--m-season`（1.2秒）でゆっくり入れ替わる（`@property --season-c`）。
- 絵は72枚を前もって読まない。今の候と次の候だけ、手の空いたときに。`sw.js` が `img/season/` を別の名前のキャッシュ
  （`kurashi-season-v1`。`kaimono-note-` で始めない＝版を出しても消えない）に、先にキャッシュ・無ければ取りに行って覚える。
  読めない絵は重ねない（色だけ）。
- 設定：daily →「季節の絵」（`settings.seasonArt`、既定は入）。出典は同じところに畳んで（`S.more`「絵の出典」。頭に NDL の求める一行 `SOURCE`）。
- 字の濃さの比：本文の字と背景のいちばん濃い所で 4.5:1 以上、見出し（主色の大きな太字）は 3:1 以上（`tests/season-art.js`。
  大きさ 1枚25KB・合計2MB と一緒に門で見張る）。
