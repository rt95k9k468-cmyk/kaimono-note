# 絵を描く・なぞる・型・画風・崩れの測り方

CLAUDE.md から見出しごと移した、詳しい決めごと（2026年9月26日）。
本文は移す前と一字も変えていない。入口（どの docs を読むか）と、どの画面でも
踏む罠は CLAUDE.md にある。**新しい決めごとは、ここ（該当する docs）に書く。**

### 新しい絵が要るとき（順番）

**いま入っている絵のうち76型が「想像描き」**（食材71・道具4・こと1）で、これを
消していく計画が `ICON-DEIMAGINE.md` にある。作業台の表と、採否を決める二つの門
（`core ≥ 0.45` と 既存71型との距離 `≥ 0.18`）はそちら。**セットで置き換えると
25pxで崩れる型が多い**ことも実測済みなので、食材を触る前に必ず読むこと。

1. **まず確立したセットを探す。描くのは最後の手段。** 想像で描き直すと、
   直すたびに骨格がずれて別物になる。`npm pack` で取れる
   （proxyの`noProxy`にnpmがあるので通る。phosphoricons.comやjsdelivrは403）。
   手持ちの候補：Phosphor Fill（MIT）、Material Symbols rounded fill
   （Apache 2.0）、Tabler filled（MIT）、Remix Icon fill（Apache 2.0）、
   Bootstrap Icons fill（MIT）。
   - Phosphor 由来は `P(d)` を使い、**`fill-rule` を付けない**（Phosphorは
     穴を逆回りで描くnonzeroの作り。evenoddにすると重なりが打ち消されて崩れる）。
   - よそのセットは viewBox がばらばらなので `F()`（`icons-todo.js`）で
     正規化する——外枠（`getBBox`）を実測し、長辺216・中心128,128に合わせて
     `<g transform>` を被せる。数字はスクリプトが出すもので手でいじらない。
   - **崩れにくさ（core）が低くても、実物で読めれば採用する。** 線ベースの
     絵は必ずcoreが低く出るが、それは読めないことと同義ではない。丸薬32px・
     暦11px（3倍の実機画素）で実際に撮って確かめること。
2. **セットに無ければ、描く前に参考画像をもらう。** その束（20型ぐらい）を
   見終わってから、描くことになった絵を一覧にしてまとめてもらう。想像で
   描くと形が壊れる（実例は `ICON-TODO.md`）。
3. **もらった画像は、手で写さずに「なぞる」こと。** 白黒化→輪郭抽出→
   Douglas–Peuckerで簡略化→長辺208・中心128,128へ写す（scratchの
   `trace.js`、ε=1.2px）。閉じた輪はいちばん遠い点で割ってからRDPに掛ける
   （そのまま掛けると2点に潰れる）。手描きの絵は `S(...)` で従来どおり
   evenodd。
   - 手で写すのは、なぞれない場合だけ。そのときは**割合**（丈に対する幅・
     ひもの長さ・位置）を写す。**線の太さだけは写せない**——参考画像の
     輪郭線はうちの升目で0.3pxにしかならず靄になる。線は抜きに変えるか
     16以上に太らせる。忠実に写すほど溶けるので、骨格を写して寸法は
     25px側へ寄せる。

### 25pxで崩れないための描画ルール

崩れにくさ（`core`：25pxに描いて1px侵食したあとに残るインクの割合。低いほど
「線でできた絵」）を測って直した経験則。新しく描くときはここを守る。

- **枠だけ抜くと消える。** 画面・パネルは塗ったまま、蝶番・アンテナ・受話口
  のような**外の形**で言わせる。
- **棒を板・骨組みに重ねない。** 接するところまでにする（重ねるとevenodd
  相殺で1pxの帯に割れる）。
- **窓・仕切りは一枚〜数本まで。** 多いと柱・仕切りが1px未満になる
  （こと用は仕切り1枚まで、食材の房の仕切りは3本まで）。
- **小さな抜きを並べすぎない。** 数を減らして大きくする。
- **細長い抜き（麺など）は本数を絞る。** 抜きは2本まで、束にするなら3本まで。
- **茎など細い部位は42以上の太さを取る。**
- **縦の棒ものは一族が混みあう。** きゅうり・にんじん・注射器・歯ブラシの
  ように縦長の輪郭は近づきやすいので、横に寝かせて離す。
- **線は太さ2.0以上か、描かない。** 目盛り・細い脚・針金は数を減らして面にする。

実測ログ（こと用の12事例・食材用の事例）は `ICON-TODO.md` /
`ICON-SILHOUETTE.md` を参照。

### `fill-rule="evenodd"` は、重なりを打ち消す

- **union は一筆で描く。** 二つの形を重ねて一つにしない。
- **接するのは可**（皿の上辺と盛りの下辺を同じyにする）。1でも重ねると
  そこに白い線が出る。
- **抜きは、抜く相手の中に完全に収める。** はみ出すと輪郭が欠ける
  （せんべいの「ひとくち」はそれを**わざと**使っている）。
- **抜きどうしを交差させない**（チョコの格子は、横帯のあいだにだけ縦を置く）。

### 食材のシルエット71型（`js/icons-food.js`）

`icon-types.json` の71型を、「こと」の絵と同じ文法で描いたもの。丸いもの
（りんご・卵など）は輪郭に出っ張りを付けて描き分けてある。いまは**どの画面
でも**（買うもの・価格・やること・ダイエットぜんぶ）品物の絵の代わりに出る
——単色と色つきが混在すると、食材の行だけ薄れて見えて画面全体が持たない
ため（2026年9月5日切り替え）。絵を選ぶ紙も同じ差し替えを通す。
実測値は `ICON-SILHOUETTE.md`。

### 商品アイコンの画風は、定数4つが決めている

708枚を描き直さずに画風を動かせる場所が `js/icon-system.js` の頭にある。
「絵が古く見える」と感じたときは、まずここを疑うこと——絵の腕ではなく
画風の語彙のほうが古い、というのが実際だった。

- `GLOSS` … 丸いものの白い光沢。**0**（置かない）。`.55` に戻せば旧画風に戻る。
- `LINE_W` … 輪郭の太さ。**0.7**（元 1.0）。
- `LINE` … 輪郭の色。**`#8a7f74`**（元 `#4a423b`）。
- `C` の彩度 … 元の **0.72倍**、明度は `(1-l)` に比例して +4%。

**輪郭を 0 にしてはいけない。** 白いもの（たまご・牛乳・トイレットペーパー）
が白いカードに溶ける。輪郭は「白いものが消えない」ための仕事をしている。
明度の持ち上げは比例にすること（一律に足すと `paper` が白飛びする）。
`ink` / `inkD` は絵の暗部の錨なので触らない。

### 光学サイズは、実測して外れ値だけ引き戻す

`js/product-icons.js` の `FIT` 表。絵は描き直さず、`ICONS` を組んだ直後に
`<g transform="translate(12,12) scale(s) …">` を被せるだけ。物差しは
**箱の長辺とインク量の相乗平均**（どちらか一方だけだと外れ値を誤って拾う）。
中央値から±15%より外だけを0.90〜1.28倍で直す。

- **軸は 12,12**（絵の重心ではない）。いまの置き場所を保つため。
- **線の太さは倍率で割り戻す**（`LINE_W / s`）。拡げた絵だけ線が太くなると
  一貫性が崩れる。
- 拡げた結果が升目からはみ出すものは、出ないところで止める。

測り直しは Playwright で `getBBox()`（viewBox単位を返す）と canvas の
アルファ数え。データURIで画像化するときは `xmlns` を足すこと（`<img>`
経由だと無いと読めない）。実測結果は `ICON-TYPES.md`。

### 型に寄せる（`ICON-TYPES.md` / `icon-types.json`）

708個を「25px で形が残る単位」にまとめる作業。**絵はまだ一枚も消していない**
——あるのは割り当ての表だけ。

- **型は外形で切る**（幅・高さ・上の作り）。中で描き分けても、その差は 25px
  まで残らない。**色は型に縛られない**——同じ形でも、とまとは赤・ぴーまんは緑。
- **キーもキーワードも変えない。** 保存済みの `t.icon` はキー文字列なので、
  キーを変えると利用者の絵が外れる。変えるのは「どの絵を出すか」だけ。
- **効くのは食材と容器だけ。** 道具・家電・家具はほとんど減らない
  ——冷蔵庫と洗濯機を同じ形にはできないので。無理に寄せると意味が壊れる。
  詳しい実測値・見込みは `ICON-TYPES.md`。

#### 寄せすぎた型を、一件ずつ点検する（`icon-fold-audit.json`）

**707鍵が、いま182種類の絵しか持っていません**（型168＋個別14）。659件が
誰かと絵を共有していて、その中には**実物として別物なのに同じ絵**になって
いるものが混ざります（実例：ごま・だしぱっく・ドライイーストが**カレー皿**、
絆創膏・包帯・湿布が**おむつ**、粉ミルクと製氷皿が同じ**箱**）。

`icon-fold-audit.json` はその総点検の作業台です。群ごとに、中身の鍵・名前・
絵選び紙の棚・引く言葉を並べ、`verdict` の欄を空で持ちます。

- **物差しは「実物が同じ形か」**。25pxで見分けられるかどうか**ではない**
  ——見分けられないなら、嘘をつくのではなく**絵を持たない**。
- 判定は三つ。`keep`（醤油と酢の瓶）／`drop`（ごまとカレー。絵を外す）／
  `split`（別物で絵が要る。外したうえで「絵が無い言葉」の一覧へ）。
- **`split` も、絵ができるまでは外したまま**にします。間違った絵を残す
  ほうが高くつくので。
- **疑いは「見出しをまたぐか」で絞れます**（`cross`）。別の棚のものが同じ
  絵になっている＝飲み込みの疑い。実測で **52群・319件**——659件を全部
  見るより、ここから始めるほうが速い。
- **型の名前を信じず、絵を見てから判定すること。** 名前と中身が食い違う
  型がいくつもあります——`boxAppl` は**プリンター**の絵（電子レンジも洗濯機も
  炊飯器もプリンターになっていた）、`diaper` は**絆創膏**の絵（だから湿布や
  冷却シートのほうが合っていて、おむつのほうが浮いていた）、`clip` は
  **画びょう**の絵（ホチキスもクリップも画びょうだった）、`service` は
  **給油機**（クリーニングも洗車もコインランドリーも給油機）、`train` は
  **バス**、`testKit` は**注射器**、`remote` は**十字キー**。名前で判定すると、
  直す先を取り違えます。52型を一枚に並べて撮る道具はスクラッチに置きました。
  - **絵も、見間違えます。** `tofu` を46pxの一覧で「納豆」と読み違え、
    判定を丸ごと逆に書きました（正しくは**お椀に盛った豆腐にごま**）。
    迷ったら、その型の**出典コメント**（`icons-food.js` / `icons-goods.js`
    の絵の直前）を読むこと。何をなぞったか、どのセットのどの絵かが
    書いてあります。
- 鍵もキーワードも変えません。変えるのは割り当てだけなので、利用者が手で
  選んだ絵（`product.icon` / `t.icon`）は一つも動きません。

**総点検は終わりました（2026年9月16日）。** 707鍵の判定は
**keep 401／split 282／move 9**（＋個別14・もともと絵なし1）。割り当てへ
流したので、**282鍵がいま絵を持ちません**（無地の色つき丸）。

- **絵が要るものは `icon-fold-audit.json` の `verdict: "split"` に載って
  います。** ここが次の作業（探す／なぞる。手順は `ICON-DEIMAGINE.md`）の
  入力です。
- **畳んでよい折りかたは残してあります**——丸い果実（りんご・桃・梨・柿）、
  切った肉、ペットボトルの飲みもの、チューブの薬味、菓子の袋。どれも
  「実物が同じ形」だから。**容器が同じなら畳んでよい、ではありません**
  ——袋菓子の袋は実物そのものだが、洗剤のボトルと化粧水のボトルは
  実物として別の品物です。
- 使われなくなった絵が一枚あります（`babyRoom`）。**消していません**
  ——`split` の鍵に絵を与えるとき、当たるかもしれないので。

### 崩れは「core」で測る。25pxで実質いくつの絵かも測れる

**目で決めずに測ること。** アイコンを触るときの物差しは二つある。

- **① core — 崩れにくさ。** 25px に描いて、1px 侵食したあとに残るインクの
  割合。細部が2px未満だと消えるので、そこが低い絵は「線でできている」絵。
  直しかたは一つ：**数を減らして太らせる。細い線は面にする。** 前に使って
  いた「中間アルファの割合」は単色の絵には通じない（べた塗りは輪郭が全部
  中間アルファになり、読めていても数字が高く出る）。
- **② 25pxでの形の距離 — 細分化しすぎていないか。** 12×12に落とした
  アルファを比べて、距離0.085未満なら「その大きさでは同じ絵」。

  **かつてここには「同じ入れもの（ボトル等）は同じ形でよい——中身の違いは
  色が言う」と書いてありました。その前提は 2026年9月5日に死んでいます**
  ——品物の絵を単色シルエットへ切り替えた日に、色が何も言わなくなったので。
  それに気づかないまま型を畳み続けた結果が、19本のボトルが見分けられない、
  という状態でした。**いまの物差しは「実物が同じ形か」だけ**（次の節）。
  距離は「畳んでよいか」ではなく「**新しく描いた絵が、既にある絵と
  ぶつかっていないか**」を見るために使います。

測り方は Playwright で canvas に描いて画素を数えるだけ。スクリプトは
セッションのスクラッチに置き、コミットしない（テストと同じ扱い）。
実測結果・過去の数値は `ICON-TYPES.md`。
