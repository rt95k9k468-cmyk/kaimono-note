## 1. 守るもの（上書きされない）

- **データ**：保存の形・控え・復元・同期・`reconcile()` の後方互換。記録の移行・作り替えはしない。設定の欄は足すだけで、
  `settings.attire`・`accent`・`font` は消さずに読み替える。表紙・柄・色は記録に欄を足さず、今ある値から引く。

  JS は束ねない。View Transitions は使わない。断られた AI・家計簿・通知の類（plan.md 3節）は出さない。

## 7. 動き・なめらかさ（測るのは `tests/smooth.js` と `heavy-pace.js` の SWEEP。調べ直しはしない）

- **押した瞬間**：`:active` の縮み（.965・120ms）と色で返す。JS があとで付ける札を待たない。
- **紙の開閉**：clip-path をやめ、translate／scale と opacity だけ（電話は下から 420ms、広い幅は .96 → 1 の 300ms）。中身は動き出す前に組み、
  動きのあいだ layout を起こさない。目標は CPU 4倍遅で 20ms 超のコマ 0（今 18／40）。「行から広がり行へ戻る」は transform（FLIP）で残す。
- **席の移り**：今の向きのまま、入る中身は 8px 上がりながら 260ms で現れる。**日・週・月**：今の払いのまま（暦が紙へ移るぶん塗り直しが減る）。
- **送り**：ぼかしを外す。`:root` に毎フレーム書かない（traps）。**済ませる**：丸が若竹で満ち、✓ が 260ms で描かれ、題に線。戻すのは一言の「元に戻す」。
