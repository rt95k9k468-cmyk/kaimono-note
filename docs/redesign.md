## 7. 動き（超なめらか・継ぎ目なし。あるべき所ぜんぶ）

利用者（11月10日）：「超滑らかでシームレスなアニメーションを、あるべきところ全てに。真の最高のユーザー体験を」。前の「全部の操作に動き」を外した決めは、
**何が起きたかを言える変化には必ず動きを付け、言えない飾りは付けない**、に読み替える（docs/motion.md の辞書の種類のまま。行を足してから作る）。

**原則**
1. 動かすのは transform と opacity だけ。辞書の「重」（`top`・`width`・`height`・`margin`・`left`）と長い「塗」（clip-path・filter・影・background-size）を無くす——
   背は入れ物を先に取って中身を transform で、影は重ねた層の opacity で、線は scaleX で。帯・＋・カードのぼかしは外す。`:root` に毎フレーム書かない。
2. 指についてくる・途中で掴める・戻せる。離した速さを引き継ぐ（`glide`）。動いているあいだも押せる（写しを被せない＝View Transitions は使わない、のまま）。
3. 同じ物はつながって動く：行→紙→行、＋→紙→＋、札→小窓、写真の小さい一枚→大きな一枚、週⇄月、席の印の滑り、足した行は紙の頭から行へ。
4. 曲線は札で一組（ばねは CSS の `linear()`）。長さは辞書の名前だけ。毎フレームの JS より CSS と Web Animations。
5. 中身は動き出す前に組み、背を先に取る（あとから動く中身 0）。待つあいだも回る輪は出さず、前の姿を残す。
6. 「動きを減らす」では終わりの姿だけ。震え（FEEL）と音は今の表に一行ずつ足す。
