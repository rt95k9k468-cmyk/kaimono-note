## 決まったこと（2026年10月1日、利用者が承認）

### 置き場所：daily の裏

- 帯は4つのまま。daily に居て daily の席を押すと、daily の紙が下がって後ろの
  ノート（地）が出る——買うもの⇄価格と同じ手つき（docs/shopping.md）。
  戻るのはもう一度押すか、留まった頭を上へ引く。
- 席の名前と絵は notes（`app.js` の `FACES.notes`、絵は Phosphor Regular の
  note-pencil を `icon("notes")` として足した）。**ノートを見ているあいだ、
  daily の席は「notes」と note-pencil を出す**（`TABS` の `names`）。価格は
  これまでどおり席の名前（shopping）のまま——価格は札の帯が入れ替わって
  後ろに居ることが見えるが、ノートの面には札が無く、帯の題も日付のままなので、
  ほかに「いまノートに居る」を言うものが無い。
- 裏は二組（`app.js` の `PAIRS`）。いま動かしている組は `pair`、帯を押したときと
  掴み手を引いたときに、その席・その紙の組へ切り替える（`faceTo(p, id)`・
  `faceAt(id)`）。前の決め打ち `FRONT="list", BACK="prices"` はこの一覧の一行目。
- daily の紙は render のたびに作り直される（`.arc-body > .tl-sheet`）ので、
  掴み手も作り直しのたびに `wireFaceGrip` へ渡す。控えた掴み手のうち、外れた
  ものは `syncFaceGrips` が捨てる。CSS の紙の規則は `.stack > .tl-sheet` と
  `.arc-body > .tl-sheet` の両方に効かせる。
- daily の掴み手の暦（cal-peek）は、紙が裏へ留まっているあいだ引かない
  （`faceAt("archive")`）。買うものと同じ。
- 帯の上の暦は daily のものをそのまま置く（`KN.screens.archive.cal()`）。
  同じ要素なので、行き来しても `putCal` は何もしない（買うもの⇄価格と同じ）。
- 起動のときに `#notes` で開かれたら daily に降ろす（留まった紙の無いノートは
  戻り道が無いので）。

### データ：IndexedDB の新しい入れ物

- 入れ物 `kaimono-note-notes`、版1の決め打ち。棚は `notes {keyPath:"id"}`・
  `meta {keyPath:"k"}`。`idb.js`・`diary-idb.js`・`backup.js`・既存の
  `kaimono-note` には触れない（版も上げない）＝**データの移行は無い**。
- 1ノート1件：`{id, title, body, notebook:"", tags:[], fav:false, createdAt,
  updatedAt, deletedAt:null}`。時刻は ISO（`KN.util.today()`）、日でまとめる
  ときは `dayKey` 系。
- 開いたら全件を記憶に読み（`KN.notes`）、一覧・検索は記憶の上で（毎回 JSON に
  しない）。読み始めるのは**アプリの起動時**（ノートの面を開いたときではない）
  ——書き出しと Dropbox が中身を待つので。
- 書くのは打ち終わりの少しあと（`SOON`）、そのノート1件だけ。隠れるとき
  （pagehide / visibilitychange）にも書き切る。記憶は打つたびに直す。
- localStorage には何も書かない（段1で要る設定が無い）。**記録（store）にも
  触れない**——試験が localStorage の大きさで見張る。
- 何も書かずに閉じた新しいノートは残さない（その紙で作って、閉じたときに題も
  本文も空なら消す。前からあるノートを空にしたものは残す）。
- 消す → `deletedAt` を付ける（「最近削除した項目」。一覧のいちばん下の一行から
  開き、戻せる）。30日たったら、開いたときに本当に消す。
- 入れ物が使えない・開けない日は、ノートの面に一言出して書かせない（＋も
  出さない）。localStorage へは退かない。

### 本文は素の文字

- 装飾（段4）は Markdown の行頭の印で持つ（「# 」「- 」「1. 」「- [ ] 」
  「- [x] 」「> 」「---」）。段1では装飾の道具は作らないが、**この形を壊す加工
  （行頭の空白を削る・trim して保存する）はしない**。保存するのは打ったまま。
  空かどうかの判定にだけ trim を使う。
- 段4は「書くときは印、読むときに整える」から始め、iPhone で触ってから Apple
  メモ型に上げるか決める。一行の中の装飾（太字・斜体）は入れない。画像は段5。

### 書く紙

- ＋を押したら、選ぶものを挟まずに、本文の欄にカーソルが入った紙
  （`KN.ui.sheet`）を開く。**iOS は押した流れの中で同期的に focus() しないと
  キーボードが出ない**ので、`KN.ui.focusNow` を `sheet()` の直後に同じ拍で呼ぶ
  （await や動きのあとで focus しない）。
- 開いたノートもそのまま書ける（読む画面と編集ボタンは作らない）。開いたときは
  カーソルを入れない（キーボードを出さない）。段4から、開いたときは整えた姿で、
  押すとその行から書ける（下の「段4」）。
- 題の欄は任意で、置き字は「タイトル」の一語。本文の欄は高さが伸びる（中で
  送らない。紙のほうが送る）。
- 保存は黙ってする。失敗したときだけ一言出す。紙を閉じても払っても保存する
  （`onClose` で書き切る）。保存のボタンは無い。
- 紙の「⋯」に★と削除（段2で前の版。段4からはその場の小窓）。

### 一覧

- 題（無ければ本文の一行目）・本文の冒頭・更新日・★。新しく直した順。★は
  押して付け外しできる（★では並びも更新日も動かさない）。
- 件数・連続・比べる言葉は出さない（daily の席なので、`tests/daily-rules.js` の
  禁止語に当たらないこと）。絵文字・説明文は無し。空のときも何も書かない。

### 検索

- 右上の虫めがね（`KN.ui.wireSearch`）で、題と本文を絞り込む（かな畳み
  `foldKana`）。段3からノートブックとタグの名前にも当たる。

### 控え（守りの部分。2026年10月1日に利用者が承認）

- 「バックアップを保存」と Dropbox の中身に、記録とは別の一番上の鍵
  `noteBook: {v:1, notes:[…]}` で入れる（最近削除も含める）。
- `store.exportJSON(at, extra)` は、呼ぶ側から余分の鍵を足せるようにしただけ。
  中身は `KN.notes.forExport()`（読めていない日は `{}`——空の noteBook を作って
  「ノートは0件」と言わない）。
- **記録（`emptyState`）に `notes` という鍵を作らない**（作ると、復元で本文が
  localStorage に流れ込み、容量からあふれて全部の保存が止まる）。
- ノートを読み終える前は、書き出しは日記と同じ門で断り（共有シートの前で
  await しない）、Dropbox は待つ（`KN.notes.ready()`）。
- Dropbox の「前と同じなら送らない」には、ノートの変化も数える（ハッシュに
  noteBook を足す）。ノートを直したら `KN.dropbox.soon()` が呼ばれる。
- 入れ物を開けなかった日は noteBook の鍵を付けずに送る（その日の
  `kurashi-latest.json` にはノートが無い。日付の控えは上書きしないので、前の日の
  ものに残る）。
- `importJSON` は今も noteBook を無視する（store はノートに触れない）。合わせるのは
  復元の口（下の「段2」）。

## 段2：復元で合わせる・版の控え（2026年10月1日）

### 前の版

- 置き場は入れ物の meta 棚、鍵 `ver:<id>`、`{k, list:[{at, title, body}]}`（新しい順）。
  **版1の入れ物のまま、棚を足さない**（版を上げない＝移行なし）。ノート1件の中に
  持たせない——一覧の記憶と書き出し・Dropbox が太るので。
- 取るのは「書く回」の最初に直したとき：書く紙を開いた（`begin(id)`）あと、最初に
  中身が変わった拍に、**直す前の中身**を前の版へ。同じ回で何度打っても一つ。隠れて
  （visibilitychange hidden）戻ってから直したら別の回。空の中身・同じ中身は残さない。
  一つのノートに `KEEP_VERS`（30）まで。
- 前の版は**ノートと同じ取引で**書く（`writeNow` が notes と meta を一緒に）。直した
  中身だけ残って前の中身がどこにも無い、という瞬間を作らない。
- 紙の「⋯」→「前の版」→ 並び（日時・題・冒頭）→ 押すと読むだけの一枚 →
  「この版に戻す」。戻すと、いまの中身も前の版に入る（戻したことも戻せる）。
- 書き出し・Dropbox には前の版を入れない（noteBook は `v:1` のまま）。前の版は
  端末の中の守り。ノートを本当に消したとき（30日・空のまま閉じた）は前の版も消す。

### 復元で合わせる

- 設定のファイルの復元で、記録を戻したあとに `KN.notes.merge(noteBook)`。
  **ノートは置き換えない**：こちらに無いノートは足す、同じ id で中身が違えば
  `updatedAt` の新しいほうを本文に、もう片方を前の版へ（どちらの中身も残る）。
  こちらにだけあるノートは消さない。★と消した印はこちらのまま（こちらに無い
  ノートはファイルのまま）。二度合わせても増えない。
- 確認の文に「（ノートは消さずに合わせます）」——「いまのデータはすべて置き換わり
  ます」がノートには当たらないので。ファイルに noteBook が無ければ出さない。
- 入れ物が開けない日は記録だけ戻し、「復元しました（ノートは合わせられません
  でした）」。
- 自動の控え（`backup.js`）にはノートが入っていないので、その復元はノートに触れない。

### 書く紙の見た目（2026年10月1日、iPhone で「書くときが暗い」）

- 書く紙（`.sheet.is-note`）だけ、白い一枚（`--c-surface`）で、はじめから背いっぱい。
  ほかの紙の透ける灰の地は書く面には沈んで見え、半分の高さでは書く場所が狭かった。
- 題のすぐ下に作った日時（「2026年10月1日(木) 9:05」、ローカル時刻）。

## 段3：ノートブック・タグ・絞り込み・ぜんぶをさがす（2026年10月1日、利用者が承認）

理想の見た目は利用者が示した画像（一覧は白いカード・上に絞り込みのチップ・
タグは色の丸）。カード化は段3と一緒に入れた——カードの下の段にノートブックと
タグを載せるので、切り離せない。

### データ（移行なし）

- 欄は段1から一件ずつにある `notebook:""`・`tags:[]` をそのまま使う。入れ物の版も
  形も変えない。書き出し・Dropbox・合わせる（`merge`）はもとから運んでいる。
- 付けるのは `KN.notes.setLabels(id, {notebook?, tags?})`。名前は前後の空白を落とし、
  タグは空と重なりを捨てる（`cleanTags`）。
- **★と同じく、更新日も並びも動かさない・前の版も取らない**（中身を直したのでは
  ないので）。復元で合わせるときも★と同じ＝こちらのまま（こちらに無いノートは
  ファイルのまま）。
- ノートブック・タグの一覧は**入れ物を持たず**、消していないノートからそのつど
  組み立てる（`notebooks()`・`tagNames()`。名前の順＝端末の照合順。漢字は読みの順
  ではない）。だから「中身の無いノートブック」は無い。ノートブックは1ノートに一つまで。
- タグの色は**名前から決まった一色**（`screen-notes.js` の `tagColor`、買うものの
  カテゴリの色から灰を除いた8色）。どこにもしまわないので、どこで描いても同じ色。
  好きな色を選ばせるなら meta に置き場が要る——いまは作らない。

### 一覧：白いカード

- 地（`--c-bg`）の上に白い角丸カード（`--c-surface`・`--r-lg`・`--shadow-1`）を
  間を空けて並べる。中身は題・冒頭2行・下の段（更新日・本の絵とノートブック名・
  色の丸とタグ名）。★は右上。
- カードにするのは一覧だけ（`.note-row.is-card`）。最近削除・前の版の紙の行は今のまま。

### 絞り込みのチップ

- 一覧の上、横へ流れる `.chip-row`：すべて・★（★のノートがあるときだけ）・
  ノートブック（本の絵）・タグ（色の丸）。**一度に一つ**。選んでいるものをもう一度
  押すとすべてへ。選んでいた名前が無くなったら、すべてへ戻る。
- 件数は出さない（daily の席）。「すべて」のほかに選べるものが無ければ列ごと出さない。
- 選んだものは記憶だけ（localStorage に書かない）。組み直しても列の横の位置は保つ。

### 書く紙：日時の下の口（段4で題の上の頭の行へ移した）

- 日時のすぐ下に、ノートブック（あれば）・タグのチップ・「＋ タグ」（タグが一つも
  無いときだけ字を添える）。どれを押しても選ぶ紙が開く。
- タグの紙：使われているタグを押して付け外し（その場で付く）、下の欄で新しいタグ
  （改行で付く）。**欄に打ったまま閉じても付く**——打った字を消えたように見せない。
- ノートブックは「⋯」→「ノートブック」（または口のチップ）。なし・使われている名前・
  新しい名前の欄。押す／改行で決まって閉じる。打ったまま閉じても入る。
- 置く前の新しいノートにも付けられる（手元の一件に持ち、置くときに一緒に入る）。
  何も書かずに閉じたら、付けたタグごと残らない。

### ぜんぶをさがす（R8）にノートを足す

- `search-all.js` の場所に「ノート」（題・本文・ノートブック・タグに当てる）。
  行は題（本文で当たったら前後）と、更新日・ノートブック。ノートの面からは数えない。
- 押すと、daily へ移って紙を下げ（`faceTo(1, "archive")`）、そのノートの書く紙を開く。
- 入れ物を読み終えていない・開けない日はノートを探さない。

### 積み上げとの棲み分け

- 積み上げ＝その日にあったことの一行、ノート＝あとで読み返す中身。ノートを
  積み上げへ移さない。橋は段6。

## 段4：装飾と全画面の書く紙（2026年10月1日、利用者が承認）

段3を iPhone で触った感想（2026年10月1日）：カードの★が高すぎる／「⋯」を押すと
紙がもう一枚下から出て、目が画面の下まで行って戻るのが面倒／ノートブックは「⋯」の
中でなく普通に出してほしい／**記事を書くときはフル画面が絶対使いやすい**（Evernote の
形：左上に戻る ‹、右上に ⋯、その下に左ノートブック・右タグ、大きな題、本文）。

### 書く紙は全画面

- 電話（640px 未満）では `.sheet.is-note` が見えている高さぜんぶ（`--vvh`）を取り、
  底はいつもどおり `--kb`。丸角・掴み手は持たない（払って閉じるのは頭の行のまま）。
  広い画面は真ん中の一枚のまま。
- 頭の行：左の ‹ は紙の閉じる丸（`.js-close`、同じ tryClose）の絵を差し替えたもの。
  右の ⋯（`.js-note-more`）は紙の `menu` を使わずに自分で置く（`menu` を渡すと
  下から出る `actionSheet` になるので）。
- 題の上の頭の行（`.note-meta`）：左にノートブック（無ければ「ノートブック」の字）、
  右にタグのチップと「＋ タグ」。ノートブックは「⋯」から外した。
- 題は `--fs-2xl`。

### 「⋯」はその場の小窓

- `popMenu`（screen-notes.js）：押した ⋯ のすぐ下、右をそろえて `.note-pop`。外を
  押す・項目を選ぶ・Escape で閉じる。重なりは開いている紙の一段上（紙の inline の
  z-index から数える。紙と同じく `--z-sheet` が元）。中身は ★・前の版・削除。
- **前の版は「取り消す」ではない。** 前の版は書く回ごとに端末へ残る守り、取り消す・
  やり直すは道具の帯の ↶ ↷（紙を開いているあいだだけの記憶）。利用者が前の版を
  Undo と読んだので、両方を置いて役目を分けた。

### 読むときは整え、書くときは印（`js/note-format.js`）

- 本文の欄に居ないあいだは、整えた姿（`.note-view`）を出し、書く欄は隠す。押すと
  押した行の終わりにカーソルを入れて書く欄へ（**押した流れの中で同期に focus**）。
  欄から出たら（キーボードを閉じた・題やタグへ移った）整えた姿へ戻る。
- ＋から来たら書く欄と帯。開いたノートは整えた姿（キーボードを出さない）。
- 整える印：`# ` `## ` `### `（見出し）、`- ` `* `（点）、`1. `（番号は書いたまま
  の数）、`- [ ] ` `- [x] `（四角）、`> `（引用）、`---`（区切り）。字下げは空白2つで
  一段。一行の中の装飾は無し。字は textContent で入れる（本文が要素にならない）。
- 整えた姿と書く欄は字の大きさと行の高さが同じ（入れ替わっても字が跳ねない）。
- 四角を押すと、整えた姿のまま付け外し（本文の `[ ]` ⇄ `[x]`）。中身を直したことに
  なるので、更新日も前の版も★とは違って動く。
- 一覧の冒頭と、題を本文から借りるとき（`notes-idb.js` の `headOf`、ぜんぶを
  さがすも同じ）は印を外した字（`plain`）。

### 道具の帯

- 書いているあいだだけ、紙の底（＝キーボードの上端）に：取り消す・やり直す・
  見出し・箇条書き・番号・チェック・引用・区切り・上げる・下げる（左は横へ流れる）、
  右端に「キーボードを閉じる」⌄。
- 押し始め（pointerdown / mousedown）の既定を止めて、本文からカーソルを奪わない。
  それでも外れていたら、最後に居た場所へ戻してから当てる。
- 見出し・箇条書き・番号・チェック・引用は、選んでいる行ぜんぶに付ける。ぜんぶが
  もうその印なら外す。ほかの印なら付け替える。いまの行の印は光る（aria-pressed）。
- 区切りは空の行ならそこに、そうでなければ行の下に。

### 改行の続き

- 箇条書き・番号（一つ進む）・チェック（空の四角で続く）・引用の行で改行したら、
  次の行にも印。中身の無い項目で改行したら印を外して終わる。段のある空の項目は、
  まず一段上がる。印の途中で押したときと、変換中（`isComposing`）は素の改行。
- `beforeinput`（`insertLineBreak` / `insertParagraph`）で見て、差し替えは
  `setRangeText`。取り消すの記憶は自前（打つ字は1秒の切れ目でまとめ、改行・帯・
  チェックは一手ずつ）。

### カードの★

- カードの縦の真ん中（`align-self: center`）。

### ほか

- `ui.js` の紙は、開いて 0.32 秒後に最初の操作へ印を置く（パソコンだけ）。**もう紙の
  中にカーソルがあれば奪わない**ようにした（＋から本文へ入れたカーソルが ⋯ へ
  移っていた）。
- 絵を足した（Phosphor Regular）：redo・heading・numbers・quote・checkbox・indent・
  outdent・chevron-left・chevron-down。
- データは何も変えていない（本文は印のまま。入れ物の版・形・localStorage そのまま）。
