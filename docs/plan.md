計画を見るときは、ここだけ読む（2026年10月17日、roadmap-3.2 の L1・X24 (a)）。

- **道のりの文書はもう増やさない。** 総点検や新しい案は、ここに行を足す。項目の細かいこと（なぜ・何を・試験）は
  docs の該当する文書（todo-timeline・look ほか）へ短く。
- 済んだ行は「開いているもの」から消す（経緯は各 docs と `docs/log/`）。
- 古い道のり（roadmap・2.0・2026-10・unify・3.0・3.1・seamless・3.2）は今の場所のまま——コードのコメントが指している。
  ID（R・V・N・S・K・T・G・H…）はそこの節。
