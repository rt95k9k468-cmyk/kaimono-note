# パソコン・幅の広い画面（desk）

2026年10月30日、利用者「パソコンで見ると iPad のような比率でしか出ない。パソコンにも最適化を。長い道のりでいい」。
それまでは 620px（`--maxw`）の一列を真ん中に置き、左右は灰の地だった。

## 決めごと

- **境目は 840px**（Material の expanded。iPad の縦は電話と同じ、iPad の横とパソコンが desk）。数は CSS の
  `@media (min-width: 840px)`（base.css・screens.css の「幅の広い画面」）と `screen-notes.js` の `WIDE` にある。変えるなら全部。
- **電話の見た目は一画素も変えない。** desk の規則はどれも @media の中。iPhone 幅で撮り比べてから流す。
- **下の帯は左の縦の列**（Apple は iPad・Mac で横の列、Material は広い画面で rail）。同じカプセル・同じ席・同じ滑る印
  （`tab-lens.js` は席の箱を測るだけなので、そのまま縦に滑る）。帯の背は席の数ぶん（`height: auto`）、カプセル・縁の光・
  屈折・押した光の四つは帯の箱に沿う（`inset: 0 var(--sp-2)`）。`--tabbar-space` は 0、＋は右下の角。
- **画面は帯と同じ向きへ流れる**（screens-nav）——desk は縦。一面ぶん滑らせず、32px だけずらして入れ替える（`desk-in-*`・
  `desk-out-*`。Material の shared axis）。名前（`is-in-r` ほか）は電話と同じで、keyframes だけ替える。
- **読む幅は 760px**（`--desk-read`。日本語は一行40字まで＝WCAG 1.4.8）。紙と日の一枚（`.day-slide`）は幅いっぱいのまま、
  **内側の余白で**真ん中へ寄せる——一枚の幅を変えると払う道のりが狂う。
- 1200px から：やることの今日は道（左 480px）と時間割（右）を並べる（`#screen-todo[data-face]`、`render()` が付ける）。
  からだはカードを段組みに（`columns: 3 380px`）。
- 買うものは一列のまま（並べ替えの `onCross` が縦の位置だけで棚を決めるので、棚を横に並べると運べない）。
- ノートの左の木は、左の帯の右・上の帯の下（`--tree-w` 264px）。ノートの画面はそのぶん右へ。
- **書く紙（ノート・日記・積み上げ）は読む幅の大きな一枚**（真ん中・背は窓のほぼいっぱい）。ほかの紙（品物・やること・
  確かめ）は 520px のまま。「画面いっぱい」（ノートの ⋯）はそのまま効く。
- **1280px からノートは三列**（木｜一覧 `--list-w` 380px｜本文）。**ノートの席で開いた**ノートだけ、紙ではなく右の段に据える
  （`screen-notes.js` の `docked`。ほかの席から開いたノートは大きな紙のまま）。覆いは無い（`.sheet-backdrop.is-note-cover` を
  消す）ので一覧も木も押せる。右の段は一枚：一覧のほかのノートを押せば前のを閉じて（保存して）入れ替える。中のノートから
  開いたものだけ重ねる。カードから膨らまない（据える場所が決まっている）。段の場所は何も開いていなくても白い面で取る。
  ＋は一覧の右下。**席を移ると閉じる**（`onLeave`。帯が見えているので、閉じないと紙が次の画面の上に残る）。

- **段3 キーボード（`js/keys.js`）**：`1`〜`5` 席・`←→` 日（日を持たない画面は暦）・`Shift+←→` 週・`t` 今日・`/` さがす・
  `n` ＋・`,` 設定。打っている欄の中・⌘/Ctrl/Alt 付き・変換中・覆いのある紙や小窓が出ているあいだは何もしない
  （右の段のノートは覆いが無いので効く）。鍵のかかった画面でも席は移れる（下の帯と同じ）。
- **トラックパッドの横払い**（wheel の deltaX）：紙の上なら日、暦の上なら週を一つ。一回の払いで一度（220ms 途切れるまでを一続き、
  60px で送る——慣性の続きで二つ送らない）。横に送れる中身（表・チップの列）の上では取らない。取った払いは `preventDefault`、
  広い幅は `overscroll-behavior-x: none`（ブラウザの「戻る・進む」にしない）。

## 罠

- **画面を離れる支度は `onLeave`**（app.js の `show()` が出ていく画面に言う）。電話では紙が帯を覆うので紙を開いたまま
  席を移れないが、広い幅では帯がいつも押せる。
- **帯の箱で「下の端」を測らない。** desk の帯は上に居る（top が小さい）。下の帯の上端を床にしていた所は、帯が面の
  下半分に居るときだけ使う（app.js の `faceDist`、ui.js の小窓は `top > 0` で見ていた）。
