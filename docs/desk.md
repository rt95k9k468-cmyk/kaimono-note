# パソコン・幅の広い画面（desk）

2026年10月30日、利用者「パソコンで見ると iPad のような比率でしか出ない。パソコンにも最適化を。長い道のりでいい」。
それまでは 620px（`--maxw`）の一列を真ん中に置き、左右は灰の地だった。

## 決めごと

- **境目は 840px**（Material の expanded。iPad の縦は電話と同じ、iPad の横とパソコンが desk）。数は CSS の
  `@media (min-width: 840px)`（base.css・screens.css の「幅の広い画面」）と `screen-notes.js`・`keys.js` の `WIDE`・`edge-back.js` の `DESK` にある。変えるなら全部。
- **電話の見た目は一画素も変えない。** desk の規則はどれも @media の中。iPhone 幅で撮り比べてから流す。
- **下の帯は窓の背いっぱいの平らな左の列**（段5。Notion・Things の形。段1〜4 の浮いたカプセルは iPad に見えた）。幅
  `--rail-w` 232px・地は `--c-bg`・右に線一本。席は絵の右に名前の横長の行（36px）、いま居る席は滑る一枚（`tab-lens.js`：
  席が丸薬より背の低い行なら行の箱に敷き、縦に並んでいれば縦に滑る）。ガラス・縁の光・屈折・押した光・押してふくらむは
  指の下のことなので出さない。指したときは薄く塗る。`--tabbar-space` は 0、＋は右下の角。
- 紙の掴み手の棒は指したときだけ見せる（指で引く道具。題を押せば暦、席の二度押しで価格。掴み手の箱と働きはそのまま）。
- **さがすと設定は右上のまま**（「右上は二つ」。左の列は席と、ノートの席の木だけ）。⌘K・Ctrl+K でさがす（打っている欄の中でも）。
- **画面は帯と同じ向きへ流れる**（screens-nav）——desk は縦。一面ぶん滑らせず、32px だけずらして入れ替える（`desk-in-*`・
  `desk-out-*`。Material の shared axis）。名前（`is-in-r` ほか）は電話と同じで、keyframes だけ替える。
- **読む幅は 760px**（`--desk-read`。日本語は一行40字まで＝WCAG 1.4.8）。紙と日の一枚（`.day-slide`）は幅いっぱいのまま、
  **内側の余白で**真ん中へ寄せる——一枚の幅を変えると払う道のりが狂う。
- 1200px から：やることの今日は道（左 480px）と時間割（右）を並べる（`#screen-todo[data-face]`、`render()` が付ける）。
  からだはカードを段組みに（`columns: 3 380px`）。束が短くなるので、からだの紙（`.is-bare`）も広い幅では地を持つ。
- **daily の季節の写真は帯に**（`--season-h` clamp(260px, 40vh, 420px)）。電話の「幅いっぱい」のままだと写真の背が窓を越え、
  紙ぜんぶが写真になった。広い幅は帯を覆う大きさで写真の真ん中を見せる（Notion の表紙）。幕の層は電話と同じ。
- 買うものは一列のまま（並べ替えの `onCross` が縦の位置だけで棚を決めるので、棚を横に並べると運べない）。
- **ノートの左の木は左の列の中**、席の行の下（`--side-nav-h` から窓の底まで。段5。前は帯の右に 264px の段を別に取り、
  1440px で本文が 700px しかなかった）。木の頭の「Notes」は出さない（席の行と印が二重になる）。
- **書く紙（ノート・日記・積み上げ）は読む幅の大きな一枚**（真ん中・背は窓のほぼいっぱい）。ほかの紙（品物・やること・
  確かめ）は 520px のまま。「画面いっぱい」（ノートの ⋯）はそのまま効く。
- **1280px からノートは三列**（木｜一覧 `--list-w` 380px｜本文）。**ノートの席で開いた**ノートだけ、紙ではなく右の段に据える
  （`screen-notes.js` の `docked`。ほかの席から開いたノートは大きな紙のまま）。覆いは無い（`.sheet-backdrop.is-note-cover` を
  消す）ので一覧も木も押せる。右の段は一枚：一覧のほかのノートを押せば前のを閉じて（保存して）入れ替える。中のノートから
  開いたものだけ重ねる。カードから膨らまない（据える場所が決まっている）。段の場所は何も開いていなくても白い面で取る。
  ＋は一覧の右下。**席を移ると閉じる**（`onLeave`。帯が見えているので、閉じないと紙が次の画面の上に残る）。
- **段7：真ん中の一覧は「すべてのノート」「問い」・探すときだけ**（`paintMid` が `html.notes-mid`）。ホームは木｜本文の二列
  （ホームの中身は木と同じで、二つ並ぶと重なった）。★・最近直した・問い は木の上へ、＋は木の右下。虫めがね・⌘K は窓に指を
  入れる前に真ん中を出す（隠れた欄には指が入らない）。畳んだ列（木が無い）ではホームも真ん中を出す。

- **段4 やることの週**（1200px〜）：左に日の行（今週・来週・過ぎた日）、右（`--side-w` 380px）に iPhone の写し・期限・やること・
  これから。`weekSlide` が `.wk-main`・`.wk-side` に分けて組む（電話は分けない＝並びも DOM も今までどおり。試験の
  `.wk > .wk-list` はそのまま）。今週でない週も二段（右は空）——払って週を替えても日の行が動かない。幅をまたいだら組み直す。
- 設定の帯（‹・題）も読む列にそろえる。設定を左右二枚にはしない（目次の一枚に切り替えと値がじかに並ぶので、右が空く時間が長い）。
- **段8 設定は一列のまま、1280px から見出しごとのまとまりを二段に**（`screen-settings.js` の `duo` が `.set-sec` に包む。
  まとまりが一つの頁・押しのけた紙は一列）。包むのは広い幅のときだけ（電話の DOM と CSS の隣り合わせは今までどおり）、
  幅をまたいだら組み直す。「›」と戻るは一面ぶん滑らせず 32px ずらして薄く入れ替える（`edgeBack.push` の `swap`）。
  左端から指で引いたあとは指の続きなので滑らせる。
- **1280px から買うもの｜価格を左右に**（段6。`app.js` の `duo`）。席は前の一枚、後ろの一枚は右半分に出したまま（`.is-duo-r`）。
  席の二度押し・`#prices`・`faceTo` は前の一枚へ（めくらない）。後ろの一枚も store が変わるたびに組む。＋は一枚ずつ、その右下に。
  1280px をまたいだら並べ直す・重ね直す。840〜1279px はめくる形のまま。
- **右クリック**（`KN.ui.rowMenu`）：買うもの・価格の行の払う操作（★・買った・リスト・アーカイブ）を、押した点の小窓（`popMenu` の `at`）で。
  `pointer: fine` だけ（電話の長押しは今までどおり）。字を選んでいればブラウザの小窓。
- **左の列を畳む**（⌘\・Ctrl+\・列の下の ‹。`settings.railFolded`）：`--rail-w` 64px の絵だけの列、席の名前は `title`。ノートの木は出さない。
- **段3 キーボード（`js/keys.js`）**：`1`〜`5` 席・`←→` 日（日を持たない画面は暦）・`Shift+←→` 週・`t` 今日・`/` さがす・
  `n` ＋・`,` 設定。打っている欄の中・⌘/Ctrl/Alt 付き・変換中・覆いのある紙や小窓が出ているあいだは何もしない
  （右の段のノートは覆いが無いので効く）。鍵のかかった画面でも席は移れる（下の帯と同じ）。
  `?` で一覧（段11。設定の中でも一枚を押しのけない `as: "dialog"` の紙）。一文字の近道（矢印も）は 外観 → キーボード で切れる
  （この端末だけ、localStorage `kn-keys-off`。記録に入れない＝控えで iPhone へ渡らない）。⌘K・⌘\ は切らない。行は `any-pointer: fine` の端末だけ。
- **トラックパッドの横払い**（wheel の deltaX）：紙の上なら日、暦の上なら週を一つ。一回の払いで一度（220ms 途切れるまでを一続き、
  60px で送る——慣性の続きで二つ送らない）。横に送れる中身（表・チップの列）の上では取らない。取った払いは `preventDefault`、
  広い幅は `overscroll-behavior-x: none`（ブラウザの「戻る・進む」にしない）。
- **入れたアプリは窓を増やさない**（段12。manifest の `launch_handler` は `focus-existing`、席の近道から来たら app.js の
  `launchQueue` がその # へ移す）。形が切り替わる幅の両側（839｜840・1199｜1200・1279｜1280）・背の低い窓（1024×768・
  1280×720）・1920px は `tests/desk-edges.js` が見る。
- 作らない（今は）：ノートのタブ・分割、買うもののタイル（`onCross`）、からだのカードを増やす。

## 罠

- **画面を離れる支度は `onLeave`**（app.js の `show()` が出ていく画面に言う）。電話では紙が帯を覆うので紙を開いたまま
  席を移れないが、広い幅では帯がいつも押せる。
- **中身の幅を変えたら、変えてから組む。** 暦の輪（`.cal-ring`）は組むときに一度測るだけ（列を畳んだとき前の位置に残った）。
  畳むのは store の subscribe が組む前に `applyRail` する。
- **`.kb-open` は欄に触れただけで付く**（電話でキーボードの印）。広い幅でそれに乗ると、左の列ごと消えていた（電話の幅だけに）。
- **別の窓の書き込みで読み直すときは、ノートの書きかけ（IndexedDB）を書き終えてから**（`KN.notes.flush()` を待つ。上限1.5秒）。
  読み直しは IndexedDB の書き込みを途中で捨てる（tests/README の「閉じた直後に reload しない」と同じ）。`reloadHere` そのものは
  待たせない——復元のあとの読み直しが遅れると、その間に古い記録の保存が割り込む。
- **帯の箱で「下の端」を測らない。** desk の帯は上に居る（top が小さい）。下の帯の上端を床にしていた所は、帯が面の
  下半分に居るときだけ使う（app.js の `faceDist`、ui.js の小窓は `top > 0` で見ていた）。
