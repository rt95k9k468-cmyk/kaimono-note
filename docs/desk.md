## 罠

- **画面を離れる支度は `onLeave`**（app.js の `show()` が出ていく画面に言う）。電話では紙が帯を覆うので紙を開いたまま
  席を移れないが、広い幅では帯がいつも押せる。
- **中身の幅を変えたら、変えてから組む。** 暦の輪（`.cal-ring`）は組むときに一度測るだけ（列を畳んだとき前の位置に残った）。
  畳むのは store の subscribe が組む前に `applyRail` する。
- **`.kb-open` は欄に触れただけで付く**（電話でキーボードの印）。広い幅でそれに乗ると、左の列ごと消えていた（電話の幅だけに）。
- **別の窓の書き込みで読み直すときは、ノートの書きかけ（IndexedDB）を書き終えてから**（`KN.notes.flush()` を待つ。上限1.5秒）。
  読み直しは IndexedDB の書き込みを途中で捨てる（tests/README の「閉じた直後に reload しない」と同じ）。`reloadHere` そのものは
  待たせない——復元のあとの読み直しが遅れると、その間に古い記録の保存が割り込む。
- **帯の箱で「下の端」を測らない。** desk の帯は上に居る（top が小さい）。下の帯の上端を床にしていた所は、帯が面の
  下半分に居るときだけ使う（app.js の `faceDist`、ui.js の小窓は `top > 0` で見ていた）。

## 段15 の設計：読む写し＋足すだけ（10月31日。了承）

- **主の一台**＝控えを送る役（`dropbox.js` の `role` が true）。**写しの端末になるのは設定で入れたときだけ**（役が false の端末に出す）。
  役から自動では決めない——iPhone が役を降ろされた日に、自分の記録が写しに隠れて受け箱も取りこまれなくなる。
  写しの端末では「この端末から控えを送る」を出さない（主を移すのは写しを記録にする作り替え＝別に訊く）。
- **写しの出どころは `kurashi-latest.json`**（今の控え。iPhone は何も増やさない）。版（rev）が変わったときだけ読む
  （開いた・前に出た・見えているあいだ数分おき）。採らない：iPhone が別の写しを書く（主の書く道が増える）・中継所（資格情報）。
- **写しは記録にしない。** 大きな保存場所の新しい棚に置き、記憶の state だけを差し替える（データの欄だけ。`settings` は
  その端末のもの、`noteBook` は使わない＝ノートは今の同期）。写しのあいだは `kaimono-note-v2` に書かず、自動の控え・
  日記の写し（diary-idb）・中継所・鳴らす役も動かさない。**その端末の前からの記録は触れずに残る**（切れば元どおり）。
- **足す道は受け箱 `inbox/<端末>/<時刻>-<乱数>.json` を一件一ファイル、`add` で**（上書きしない＝書き手どうしが食い違わない）。
  採らない：一つのファイルに書き足す（版の取り合い・書き直しで消える）。
  中身 `{ v, id, at, kind, … }`。kind は 足す（やること・買うもの・日記の一件）と 日記の直しの依頼（直す・外す・ノートへ移す）だけ。
  足すものの id は写しの端末が振る。打ったものは先に localStorage の小さな控え（記録の外）に書き、写しに
  取りこまれた印が見えるまで持って、写しの上に重ねて見せる。
- **直しの依頼は元の一件の字を持つ**（`was`＝写しで見た字、`at`＝時刻の行）。iPhone は `diary-posts.js` の `swap`・`take`
  と同じ決まり：同じ字が同じ所にあれば当てる。無ければ 直す→新しい一件として足す、外す→外さない。
  ノートへ移す：ノートは写しの端末で書いて同期で送り、依頼は `note` の id を持つ。iPhone はそのノートが手元に届いてから外す。
- **取り込みは主の一台だけ**：日記の突き合わせが済んでから・書く紙を閉じてから（段10）・記録が見当たらない日はしない。
  先に自動の控え（「受け箱の取り込み前」）→ `at` の順に当てる（日記はその日の時刻の順の位置へ）→ 一度に書く → 済んだ id を
  記録 `inboxSeen`（`reconcile()` で足す。30日で間引く）→ ファイルを `inbox/.done/` へ（30日で消す）。済んだ id は二度当てない
  （書いたあと閉じても、次は移すだけ）。読めない・知らない kind・大きすぎるものは当てず・消さず・動かさない。
  買うもので同じ名の品がリストにあれば足さずに寄せる。取りこんだら控えを早めに送る（写しの端末の重ねが早く外れる）。
- **②で決めたこと**（`js/replica.js`。`tests/desk-replica.js`＝門）：入れる印は localStorage `kn-replica`（記録の外）、
  写しのあいだの設定もそこへ（記録には書かない）。入れる・切るは読み直して始め直す。写しの字は**新しい棚でなく meta の
  "replica"**（棚を足すと全端末で IndexedDB の版が上がる＝開けない日の危うさ）。保存の仕組み（控え・記録の写し・日記の写し・
  過去のやることの棚・中継所・鳴らす役・通知）は中身に触れず、`replica.js` が口を動かないものに差し替える（読み込みは
  bell.js のあと・app.js の前）。store は `writeLive`・`update`（データが変わったら写しへ戻す）・`adoptRaw`・`reload`・
  `writeGone` に門。薄くする操作は済みの丸・★・＋（ノートの＋は除く）、`replica.js` の `ONLY` と screens.css が同じ並び。
- **③で決めたこと**（`js/desk-inbox.js`＝`KN.deskInbox`。`tests/desk-inbox.js`＝門）：入れ物は `inbox/desk-<8桁>/`
  （職場の受け箱は inbox 直下のファイルだけ読むので交わらない。端末の名は localStorage `kn-desk-id`）、済みは
  `inbox/.done/desk-…/`。依頼の `at` は置いた時刻（順に使う）、時刻の行は `was` の頭に入っている（別の欄にしない）、
  `pos` は写しで見た場所——一件として丸ごと同じ字がそこに無ければ、同じ字の一件が一つだけのときその場所（前の一部だけ
  合うのは当てない）。控えは localStorage `kn-desk-held`、`showReplica(text, lay)` が写しに重ねる。やること・買うもの・
  daily の＋は写しで薄くせず一行の紙（やることは `whenParse` で日を読む）、日記の紙は `openPost` が写しなら
  `deskInbox.post` へ（よかったことの欄・一枚で開くは無い）。ノートへ移すは新しいノートだけ。取り込みは控えを送る役と
  決まった端末だけ（`dropbox.status().main`）、紙が一枚でも開いていれば15秒後にもう一度（`KN.ui.sheetsOpen`）。
  控えは同じ中身でも取る（force）。日記の一枚の紙（`openLogSheet`）は写しでは今までどおり戻る。
