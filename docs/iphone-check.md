# iPhone で確かめる一枚（R16）

2026年9月29日に作った。R2〜R29 のうち、試験のブラウザでは通っているが **iPhone では
まだ見ていない**ものを、一度に回すための一枚。15〜20分ほど。
（iPhone で読みやすいように、表ではなく箇条書きにしてある。2026年9月29日）

- 手順は押す順番どおり。**「見えれば良いもの」が見えたら ◯、違ったら × と一言**。
- 分からなかった・前提がそろわない（中継所を置いていない、など）は「—」でよい。
- 何かが動かなかったら、その場で **設定 → 一般 →「困ったときの記録」→「コピー」**（R23）。
  その字も一緒に貼る。
- 結果は、下の「貼るときの形」に番号ごとに書いて、次のセッションにそのまま貼る。
  `docs/improvements.md` の「iPhone で確かめた結果」の形で残す。

## 見た目・手ざわり

**1. R2 季節のひとこと**
- する：daily を開く
- 見えれば良い：「Daily Log」の見出しのすぐ下に、今日の節気・候の一言。見出しとぶつからず、字が切れない

**2. R7 これからの二週間**
- する：上の帯の暦の絵を押す
- 見えれば良い：紙「これからの二週間」。見出しの「今日」「明日」、曜日の色。日を押すと、やることのその日へ

**3. R8 ぜんぶをさがす**
- する：買うものの虫めがね → 日記に書いた字を一つ打つ
- 見えれば良い：窓の下に「ほかの場所に◯件」。押すと紙が出て、daily の行を押すとその日へ

**4. R9 同じ日の年々**
- する：daily で、去年にも記録がある日を開く
- 見えれば良い：年ごとの一行（遠い年から）。行を押すとその日へ。数は言わない

**5. R17 「8:00」が二つ**
- する：やることで、道の段の終わりちょうどで終わる用事を作る（例：5:00 始まりの道なら 7:00〜8:00）
- 見えれば良い：角の「8:00」が一つだけ（上下に二つ並ばない）

**6. R27 daily の「-」**
- する：daily でメモを書かない積み上げを一つ足す
- 見えれば良い：その行の下に「-」が出ない

**7. R27 品名の高さ**
- する：買うものに、メモの無い品物を一つ
- 見えれば良い：品名が、右の値段・丸と同じ高さ（上に寄らない）。メモを足しても行の高さが跳ねない

## 入れる・戻る

**8. R4 行き先の札**
- する：買うものの＋で「明日 19:00 歯医者」と打つ
- 見えれば良い：「やることへ」の札 → 押すと、やることの明日 19:00 に入り、紙が閉じる

**9. R6 済ませてから◯日**
- する：やることの用事を開く → くり返し →「済ませてから」→ 3日 → 保存 → 済ませる
- 見えれば良い：次の回が、済ませた日から3日後に出る

**10. R11 いつもの組**
- する：買うもののリストの終わり「いつもの組にして残す」→ 二品選んで名前「試し」→ ＋で「試し」と打つ
- 見えれば良い：「組：試し（2品）」→ 押すとリストに無いものだけ入る

**11. R3 通知から用事へ**
- する：設定（やること）→「やることの時刻を知らせる」オン → 2分後の時刻の用事を作り、アプリを閉じる
- 見えれば良い：通知が来る → 押すとその用事の紙が開く。「あとで」で15分後へ

**12. R5 Siri の受け箱**
- する：ショートカット（relay/README.md の組み方）で「牛乳」を送る → アプリを開く
- 見えれば良い：買うものに「牛乳」。日付・時刻つきならやることへ

- 見えれば良い：4タブが出て、書いたものが閉じて開いても残る（`tests/offline.js` と同じこと）

## 2.0 の動き（roadmap-2.0、2026年10月4日に足した。V27 の日にまとめて）

**23. V17 買ったものをしまう**
- する：買うものの丸を押す。次に「今日買ったもの」を ＞ で閉じて、もう一つ押す
- 見えれば良い：開いているときは行が消えずに下の束の中へ滑る。閉じているときは行が ＞ へ縮んで入り、数が一つ跳ねる。押したときに一覧ぜんぶが瞬かない

**24. V15 別の日へ**
- する：やることの行を押して紙で日を明日にして閉じる
- 見えれば良い：頭の丸薬が上の暦の明日の丸（暦が出ていなければ頭の日付）へ縮んで飛び、着いた丸がふくらむ

**25. V16 ＋へ帰る**
- する：やることで＋→紙を閉じる。ダイエットで＋→札→紙を閉じる
- 見えれば良い：どちらも紙が縮みながら＋へ帰り、＋が一度受け止める（札のあった所へ消えない）

**26. V10・V21（設定 → 外観 →「試す」→ 2.0 の見た目 をオンにして）**
- する：ノートを書く。daily の日記の抜き出しを見る
- 見えれば良い：ノートの道具の帯がぼけていない白い面。日記の抜き出しが五行。オフに戻すと前のまま

**27. V19 ノートの紙（2.0 の見た目をオンにして）**
- する：ノートのカードを押して開く。左の端から右へ払う。もう一度開き、一番上で中身を下へ引く
- 見えれば良い：紙が四隅の丸いカードで浮き、左右の空きが同じ。払うと払った所からカードへ縮んで帰る。下へ引くと閉じる。キーボードを出しても紙がずれない

**28. V18 元に戻す**
- する：daily の記録を一つ消す。ダイエットの体重を一つ消す。価格の一件を消す
- 見えれば良い：どれも確かめの紙のあと、下に「消しました」と「元に戻す」が5秒ほど出て、押すと元の場所に戻る

**29. V22 期間の書き出し**
- する：daily の歯車 → 書き出し →「期間を選んで書き出す」。始まりと終わりを選んで書き出す
- 見えれば良い：暦の小窓が押した行のそばに出て、画面が上へずれない。ファイルへ保存できる（名前に始まりと終わりの日）

**30. 2.0 の動き全部を、動きを減らす設定で**
- する：iPhone の設定 → アクセシビリティ → 動作 →「視差効果を減らす」をオン。23〜25・27 をもう一度
- 見えれば良い：飛ぶ・縮む・滑るが無く、その場で入れ替わる。行き先（明日・今日買ったもの・＋）には、ちゃんと入っている

**31. 大きな字で**
- する：iPhone の設定 → 画面表示と明るさ → テキストサイズを大きく。やること・daily・ノートを開く
- 見えれば良い：上の帯・下の帯・紙の題が切れずに読める。字が重ならない

**32. ロックと Face ID（daily の歯車 → ロック をオンにして）**
- する：daily のタブを押す。ホームへ戻って、もう一度くらしノートを開く
- 見えれば良い：中身が一瞬も見えずに覆いが出て、Face ID が自分から出る。通れば daily が出る。断ると覆いのまま、ほかのタブへは左上の絵から行ける

**33. V24 からだの三つ（2.0 の見た目をオンにして）**
- する：ダイエットを開き、頭の「今日・記録・推移」を順に押す。「記録」で食事を一つ書く。紙を横に払って昨日へ
- 見えれば良い：今日はからだの輪と体重の数、記録は食事、推移はグラフ。字は三つの区画それぞれの真ん中。書いている欄がキーボードに隠れない。払っても同じ区画のまま日が変わる

**34. V20 ノートの絞り込み**
- する：ノートの一覧の上の「タグ ⌄」を押して一つ選ぶ。書く紙でタグの ＋ を押す
- 見えれば良い：列は四つの札だけで横へ流れない。小窓の名前は折り返して全部見え、選ぶと札にその名前。タグの小窓も折り返す
