## 2. 見立て — 磨きでは届かない所

1. **思想に居場所が無い。**「人生のアーカイブ＋振り返り」は daily のいちばん下の字の行（あの日・どこかの一日・◯月のまとめ）。
   日記が三件ある日は、あの日が一画面より下になる。年も積み重なりも、どこにも見えない。
2. **一日が五つに割れている。** 予定は tasks、書いたことは daily、量った・食べたは health、買ったは shopping。どれも時刻を持つのに、一日を一つの物として見る所が無い。
3. **書く所と読む所が別の物。** 書く口は五つ。書く紙は枠のある欄、書いたあとは吹き出しと左の絵。

良い所（主役へ上げる）：一日の帯と時間割・自然文の「いつ」／72候の写真と名前（電話では 58px）／年々・どこかの一日・年の本／写さず引く／評価しない／紙・墨・朱と明朝。

## 3. 思想と原則（変えない）

- 評価しない・急かさない・数えない。**入れ物は変えず、見せ方を変える**（写さず引く）。
- **厚みで見せ、穴で見せない。** 積み重なりは頁の束と背表紙で。升目の空き・色の濃さ・件数では見せない。書かなかった日を欠けとして扱わない。
- **再会させるが、比べさせない。** 並べる相手は去年の同じ季節。差・矢印・多い少ないを出さない。
- **今日の頁は実用が先。** 時間割が主役のまま。候の写真や大きな飾りを今日の頁に持ちこまない。
- **archive は眺める所。** 写真・縦書きの扉・背表紙・小口の色は、ここでだけ贅沢に。
- **紙に見せるために使いにくくしない。** 電話は片手、パソコンは見渡し。比喩より手つき。

## 6. 今日の頁（絵①⑥⑪⑫）

### 6.1 組み

- 盆そのものが紙。細い朱の縦線（頁ぜんぶ同じ色）の左に時刻、右に中身。**箱を持つのは「これから」だけ。**
- 行は四つ：言葉（日記。明朝 16px・行間 1.85）／事実（ゴシック 13.5px・墨2）／済ませたこと（✓ と題 15.5px）／よかったこと（山吹の淡い面。今の印のまま）。
- 「いま」より下は**今の時間割そのまま**（置き方・長押しで動かす・長さ・畳み・詰める）。過ぎてもまだの用事は、今の置き直しのとおり線の下に居る（赤くしない）。
- 済ませる：丸を押すと、札がほどけてその場の一行になる。過ぎた日には、済ませなかった札を出さない（翌日の「前の日から」へ。今のまま）。
- 帯は今のまま頁の頭に（次は・あと・予定と空き・詰める＝磨4 の形）。足すのは、書いた時刻の細い朱の印だけ。
- 年々のつまみ：同じ月日のほかの年に頁があるときだけ、頁の上の縁に年の札。

### 6.2 時刻の意味と置き場（足す欄は無い。読むだけ）

| 記録 | 持っている時刻 | 意味 | 頁での置き場 |
|---|---|---|---|
| 用事・予定（まだ） | `due`・`time`・`minutes` | これから | 「いま」の線の下。今の時間割の計算のまま |
| 済ませた用事（時刻つき・その日に済ませた） | `time`、`doneAt`＝丸を押した時 | あったこと | **決めた時刻**。始まりより前に押したものだけ `doneAt` |
| 済ませた用事（時刻なし・持ち越し・別の日の予定） | `doneAt` | あったこと | 押した日の頁の、押した時刻 |
| 日記の一件 | 時刻の行＝打ち始めた時 | 書いた時 | その時刻 |
| あとの日に書いた一件 | `10/26 07:10` の行 | あとから書いた | 頁の終わりに、書いた日付つきで（時間の並びに入れない） |
| 時刻の行より前の地の文・一枚の表示 | なし | — | 頁の頭 |
| 買ったもの | `checkedAt`＝丸を押した時 | ほぼ店で | その時刻。30分以内の続きは一行に束ねる |
| 食事 | 枠（朝・昼・夕・間食）と、入れたときだけ `time` | 枠が正 | 時刻があればその時刻。無ければ枠の場所（7・12・15・19時の並び）に、時刻の列は枠の名 |
| 体重 | `time` | 量った時 | その時刻（無ければ足もと） |
| 起床 | `wake`（起きた日に入る） | 起きた時 | その時刻。その朝に終わった眠りの長さを同じ行に |
| 就寝 | `sleep`（**その晩の日**に入る。5時より前は前の日の晩） | 寝た時 | 頁の最後。0〜5時の就寝は 23時台より後ろ（今の `nightRank` の並び） |
| 歩数など日ごとの数 | 日の合計 | — | 足もとに一行 |
| 天気・候・その日の一枚 | 日ごと | — | 頁の頭 |

- 一日＝暦の日（`dayKey`）。記録が入っている日をそのまま使い、日をまたいで付け替えない。
- 同じ時刻は、起床 → 体重 → 食事 → 済ませたこと → 買ったもの → 言葉 → 就寝 の順。時刻の字は一度だけ書く。
- 引くだけなので、あとで時刻を直せば次に描くとき行が動く（写しを持たない）。

| 例 | 頁に出る所 |
|---|---|
| 10:00 の予定を 11:30 に丸 | その日の 10:00 |
| 20:00 の用事を 19:39 に丸 | その日の 19:39 |
| 時刻なしの用事（11/14 から持ち越し）を 11/15 09:05 に丸 | 11/15 の 09:05。11/14 の頁には出ない |
| 11/14 10:00 の予定を 11/15 08:00 に丸 | 11/15 の 08:00 |
| 21:00 に時刻なしの用事を三つ続けて丸 | 21:00 の一行に三つ |
| 就寝 01:10（11/16 の未明）→ 06:30 起床・眠り 5時間20分 | 就寝は 11/15 の頁の最後、起床と眠りは 11/16 の頁の頭 |
| 00:40 に書いた一件（11/16 の日記） | 11/16 の頁のいちばん上 |
| 時刻を入れていない朝食 | 朝の並びに「朝」 |

### 6.3 「いま」の線

- **現在の時刻を示すだけ。** 出すのは時刻の丸薬・線・筆。残り・割合・「あと◯」を線に足さない。予定が無い日は線と筆だけ。
- 動くのは分が替わったときの置き直しだけ（流れ続ける動きは無い。`:root` に毎フレーム書かない）。「動きを減らす」では動かさない。
- 線より上の記録は隠さない・畳まない・薄めない。帯にも過ぎた分の塗りを足さない。
- ひらいたとき、線が見える所まで送る（上に余りがあれば送らない）。席を二度押すと線へ戻る。

### 6.4 長い日の組み方（絵⑪）

1. 時刻の列は 50px・丸い数字 12.5px で通す。同じ時刻は一度だけ。
2. 密度は三段：言葉（上下に 10px）＞ 済ませたこと（28px）＞ 事実（24px）。小さな行どうしは詰める。
3. 続けて三つ以上済ませた用事は、一行に束ねて折り返す。
4. 時間帯の境（空の区切りと同じ：早朝・朝・昼・夕方・夜）で 18px 空ける。見出しの字は置かず、境の最初の時刻だけ太く。
5. 記録に枠・影・区切りの線を付けない（箱は「これから」だけ）。
6. 長い一件は今の畳み（頭三行・終わり三行・「全文を読む」）。
7. 見出しは「時刻なし」の一度だけ。帯・線・つまみも一つずつ。
8. 時刻の無い数（歩数）は足もとに一行。

絵⑪の一日（日記五つ＋あとから一つ・用事十六・食事四つ・体重・買い物二回・起床と就寝）は約1.7画面。

### 6.5 書く（絵②）

- **筆＝いまのことを書く**（今日の頁の「いま」の線。時刻は打ち始めた時）。**＋＝足す**（その席のもの＝今のまま。まん中では新しい用事）。
  過ぎた日は頁の終わりの一行（今の「この日のことを書く」）。筆と＋は同じ紙を開かない。
- 紙は頁と同じ組み。直前の行が薄く見える。道具は よかったこと・戻す・やり直す・書き終える。
- 保存の道は今のまま（`diaryPosts.add`・書きかけを残す・書いているあいだ画面を消さない）。
- 直す・写すは、行を押すと出る小さな道具（左に並ぶ絵は出さない）。

### 6.6 鍵（絵⑫）

鍵は今の一つ（番号と Face ID。年ごとの鍵は無い）。`KN.lock.hides("daily")` が真のあいだ——daily を覆う設定でも、日記だけの設定でも：

| 場所 | 閉じているあいだ |
|---|---|
| 今日の頁（まん中） | **今の tasks と同じ中身だけ**（帯・用事・済ませた用事）。日記・よかったこと・引いた事実・年々のつまみ・その日の一枚・帯の書いた印は**組まない**。頭に「開ける」の一行。筆は効く（今の決め）。書き終えた字は頁に残さない |
| archive（左端） | daily を覆う設定なら今のとおり画面ぜんぶ。日記だけなら扉と棚は出し、いまごろ・ふと開く・升の一行・月の頁の写し・年々は出さない（押すと `KN.lock.ask()`） |
| 過ぎた日の頁 | 開く手前で `ask()`。開けたあと鍵が閉じたら閉じる（今の `diarySheet()` の流儀） |
| となりの頁（iPad・パソコン） | 年々・いまごろを出さない |
| さがす | 今のまま、日記を探さない |

- まん中の席には覆いが無い。**覆って隠すのではなく、字を組まない**（閉じた拍に組み直し、DOM に本文が残らないことを試験する）。
- docs/daily.md「鍵」の漏れ口に足す行：今日の頁・年々のつまみ・いまごろ・ふと開く・一年の升・月の頁・となりの頁。

## 7. 過ぎた日の頁（絵③⑪）

口絵はその日の一枚（あれば。無ければ空の帯）。ぜんぶが字。出すのはその日の事実だけで、daily-rules の言葉（平均・目標・連続…）と前の日との差は出さない。
何も書いていない日は、引いた行と、足もとの季節のひとこと。

## 8. archive（絵④）

- **章の扉**：いまの候の写真を大きく、名は縦書きの明朝（モダンは横組み）。季節のひとことは扉を押すと。
- **棚**：年の背表紙。色は年ごとに決め打ち、**幅と高さで年を比べない**。今年の一冊に栞。
- **ふと開く**：今の「どこかの一日」（名前は今のままでもよい）。
- **いまごろ**：同じ月日の、各年の一日だけを新しい年から縦に（archive の頭は今年の分も一番上）。同じ月日の頁に朱の栞。下に、その候に した・買った を一行ずつ
  （あった順。数えない。からだ・食事は出さない）。**ある頁だけ並べる。** 日記を書かなかった年とは、ここで再会する。
- 年をまたぐ候（雪下出麦）は、候の続き（12/31〜1/4）で引き、年の札は続きが始まる年。

## 9. 一年の一冊・月の頁・小口（絵⑤⑨⑩）

- **一冊は暦年**（1月1日〜12月31日。年の本と同じ）。候は `KN.season.of(日)` のまま。升は、その年の中の候の続き。
  2025年は 73升（頭：雪下出麦 1/1〜1/4 … 終わり：麋角解 12/26〜12/30・雪下出麦 12/31）、2026年は 72升（雪下出麦 1/1〜1/4 … 麋角解 12/27〜12/31）。
- 年をまたぐ候は両方の年の本に出て、**それぞれ自分の年の日だけ**を持つ。一年の記録が欠けない・翌年の記録が混ざらない。
- 月の列は暦の月。その月に始まる候を置く（5〜7枚。2025年は 1月7・6月5・12月7、ほかは6）。
- **升の一行**：その候に書いた日記の最初の一行だけ。無ければ写真と名だけ。鍵のあいだは出さない。まだ来ていない候は名だけ。
- **月の頁**：暦の月どおり。候ごとの見出しと、頁の小さな写しの並び。何も無い日は並べない（今の「—」の行をやめる）。
- **小口**：頁の束の縁に節気の色（今の `SEKKI_C`）。なぞると日へ飛ぶ。

## 10. 端末ごと

- **iPhone**：一頁を親指で。筆と丸は右、＋は今の場所。日は紙を横に払う（今のまま）。小口の当たりは 44px。
  撮りには safe-area が出ないので、上 59・下 34px の見込みで当たりを見て、実機（iphone-check）で確かめる。
- **iPad**：横は見開き（絵⑦）——左は今日、右は相手を選ぶ（年々・いまごろ・あした・ノート）。縦は「頁｜となり」の二段、月の頁は五列（絵⑩）。
- **パソコン**：左の列に棚、まん中に頁、右にとなりの頁、右の縁に小口（絵⑧）。一年は一画面（絵⑨）。鍵盤は今の X2 に J K・N・G・T を足す。

## 11. 絵・写真・色・字（役を一つずつ）

| 素材 | 役 | 出す所 | 守ること |

## 13. 小さくても、ここだけの体験

済ませた札がほどけて記録の一行になる／「いま」の線で書く／候が替わった日に扉がひらく（一度きり）／頁の上の縁から去年の頁が顔を出す／
ふと開く／小口に季節の色が流れる／去年のいまごろの「した」に「今年も」（押した人にだけ用事が一つ。勧めは出さない）／
朝いちばんに昨日の頁がめくれて今日になる（一度きり）／何も書いていない日も足もとに季節のひとこと（促す言葉は置かない）。

## 14. 前の決めごととの関係

**上書きをお願いする行**（拒めば、その行だけ戻す）：daily の頭の三つの書く口（10月12日）→ 筆と notes の＋／時刻ごとの吹き出し（10月13日）→ 頁の行／
候の札を daily の頭に（R6）→ archive の扉／tasks・daily の席の中身（席は増やさない）。

**守る行**：よかったことを集める面は作らない／daily に数字の一覧を作らない（頁はその日の事実だけ）／暦の札は字のまま／英語の席の名／
AI・通知・家計・連続記録・気分の採点／月の満ち欠け／365枚の背景（今ある72枚だけ）／過ぎた用事を赤くしない・遅れと言わない。

## 15. データの守り

- **保存の形は一字も変えない。** 頁は `archive.days[]`（`memo`・`wake`・`sleep`・一枚）・`todos`・`checkedAt`・食事・体重・天気を読んで並べるだけ。
  欄・入れ物・移行は無い（要ると分かったら、作らず先に報告）。
- 並べ方は、DOM に触らない読むだけの関数一つにまとめ、単体で試験する（6.2 の表と例がそのまま試験になる）。
- いまごろ・一年の一冊は、日の鍵から候を引くだけ。索引を持つなら、端末の中の作り直せる写しに限る。
- 設定を足すなら `reconcile()` で後方互換。控え・復元・同期・中継所には触れない。
