## 0. 三つの問いへの答え

1. **どこまで仕上がっているか**：八割。土台（紙・墨・朱、明朝の見出し、札の値）と、このアプリの顔（archive の扉・背表紙・いまごろ、一日一頁）は仕上がっている。
   残る二割は **notes と設定の「データ」**、それと広い幅（iPad 縦・パソコン）の使い切り。操作できない所・重大な読みにくさ（P0）は見つからなかった。
2. **磨くのか、組み直すのか**：磨けばよいのは archive・daily・shopping・health・紙（入力）。**組み直すのは二つだけ**——notes（ホーム・一覧・読む面の器）と、
   設定の「データ・同期」の一枚。アプリ全体の作り直しは要らないし、してはいけない（守りの監査 `shots/audit-2026-11-16.md` の結論と同じ）。
3. **五年・十年もつ向き**：**「蔵書と歳時記」**（8節）。足すのは飾りではなく、利用者自身の言葉と写真と季節がいちばんよく見える器。
   流行の質感（ガラス・挿絵の画風・彩度の高い柄）に寄らず、字・余白・紙の色・一色の朱で立つ。

**毎日開きたくなる場所にするには**：①開いた拍に「今日」と「去年の今日」が在る（いまごろ。もう在る——朱の大きな札をどけて主役に）②自分の言葉がいちばん美しく
組まれる（ノートと日記の行間・口絵）③静けさ（朱は一画面に一つ・数えない・急かさない）④手ざわり（構7 を実機で）⑤預けて平気だと分かる（控えの状態が、穏やかに一行で）。

## 5. 札と部品（`08-tokens.jpg`）

- **揃っているもの**：色（紙・墨・朱と役目の五色）・角（10／14／20／28）・影（三段）・重なり（名前で）・間隔・行の背（44／56／60／64）・太さ（400 と 700）・
  書体の役（明朝＝自分の言葉と題／ゴシック＝事実と押すもの／丸い数字）・ボタン三種・紙の頭。**ここは変えない。**
- **流れているもの**：
  1. 字の大きさ——札は六つ（11・12.5・14・16・19・24）なのに、画面に出ている大きさは二十。半端は `calc(13px * var(--fs-k))` の形で 59 か所。
  2. 冊とタグの色——明るい八色（`TAG_COLORS`）。年の背表紙（深い色）と並ぶ notes だけ彩度が高い。
  3. 食事の枠の色——冷たいパステル（css に「R4 で見直す」のまま）。
  4. 危ない操作の見分け——朱 `#bf4128` と警告の赤 `#b3261e` はほぼ同じ。色では分けられないので、場所（下の別の束）・絵・墨の字・確かめの紙で分ける。
  5. 絵の系統——写真（額）・広重・線の絵・利用者の水彩・設定の挿絵は役が決まっている（構想 11節）。**役が決まっていないのは notes の柄の表紙だけ。**
  6. 紙——ノートの紙だけ幕が無く、四辺に 8px の隙間（ほかの紙は幕つき・幅いっぱい）。
- **明暗**：どちらも読める。暗い面で浮くのは notes の表紙だけ。**地の色**：生成り（手帳）と白（モダン）の二つで足りる。三つめの配色は足さない（磨き切れない＝W9 の教訓）。

## 7. 三つの重点——目標の絵

### A. ホームと、書く・考える口（`05-home.jpg`）

- いま：扉 → 朱の「日記に書く」とコピー → 棚 → いまごろ。思考の口は notes の丸だけ。
- 案：**机を紙の色に。** 一行め＝筆の絵と「いまのことを一行から」（書く紙の最初の行と同じ字。押すと今の書く紙）、右に小さな「写す」。
  二行め＝今日の問い（あるときだけ）と「考える」「別の問い」。問いの無い日・鍵のあいだは一行だけ（出し分けは今の決めのまま）。
- 朱は筆の絵だけになる——扉といまごろが主役に戻る。働き（書く・全文コピー・今日の問い・思考）は一つも減らさない。
- いまごろ：年の札を背表紙の色の印に、生成りの箱をやめて頁の行に（棚とつながり、札が一段軽くなる）。

### B. notes（`01`〜`04`）

- **ホーム**：案A＝**蔵書**。「最近」は読める行（題・抜粋一行・冊と日付。写真のあるノートだけ小さな口絵）。本棚は **archive の年の背表紙と同じ部品**で、
  冊の名を縦に、足もとに冊数。冊が増えても横に送れる。広重は額に入れて、空の画面と見返しに。
  案B＝今の表紙を残し、色を深く・柄を布目に・字は必ず札の上に（広重は敷いたまま）。
  **勧めは A**——archive と一つの棚になり、明暗どちらでも静か。ただし「広重を敷くか」は好みの領域（客観の問題は、字が絵に直に乗る所だけ）。
- **一覧**：どの行も同じ背（約94px）。月の見出しで年月をたどれる。★は付いたものだけ。千件になっても形が変わらない。
- **読む面**：紙は端まで（iPad 縦は頁いっぱい）。一枚目の画像があれば口絵に大きく。空行と見出しの余白を重ねない。
- **パソコン・iPad 横**：ホームを挟まず 木｜一覧｜読む面。右の余白に見出し（今は「⋯」の中にある目次）。＋は左の列の「新しいノート」。
- **挿絵・写真について**：足すのは利用者自身の写真（一枚目が口絵）だけ。ノートごとの飾りの挿絵・自動で付く絵は**足さない**（系統が一つ増え、十年もたない）。
  画像の無いノートは字だけで美しく——それがエディトリアルの芯。磨6（幕と最近のカード。11月14日に選んだ向き）は、この案に含まれる。

### C. 設定（`06`・`07`）

- **根っこ**：席の名を帯と同じに（archive・notes・daily・shopping・health）。「データ・同期」を **記録を守る**＝控え｜同期｜出し入れ｜この端末 の四つの入口に。
  控えの状態は一行（警告の調子にしない）。
- **控えの一枚**：上に状態（この端末の中・Dropbox）と主のボタン一つ。「戻す」は下の別の束——**いまの記録を置きかえる操作**は墨の字と絵で、朱にしない。
- **重なり**：同じ行が二〜三か所にある物は、正の置き場を一つ決め、ほかは入口だけ残す（ノートの書き出し＝出し入れ、中継所＝連携）。
- **広い幅**：左に根っこ、右に選んだ一枚（iPad 横・パソコン）。電話は今の一枚ずつのまま。

## 8. 勧める向き——「蔵書と歳時記」

「一冊の手帳」（11月10日）→「一日一頁、めぐる歳時記」（11月15日）の続きで、新しい様式ではない。**残りの席をその一冊に入れる**だけ。

| 役 | 席 | 形 |
|---|---|---|
| 歳時記（めぐる時） | archive | 写真は額、名は縦書きの明朝、年は背表紙 |
| 頁（今日） | daily | 朱の縦線・時刻・「いま」。実用が先 |
| 蔵書（積もる知） | notes | 背表紙の棚・読める一覧・口絵は自分の写真 |
| 机（書く・考える） | archive の机・＋・筆 | 紙の色。朱は一画面に一つ |
| 帳場（買う・からだ・設定） | shopping・health・settings | 行と数。飾らない |

**利用者の見立て（アーカイブを土台に、エディトリアルの美しさとビジュアルライブラリの豊かさ）への答え**：土台と美しさは賛成。豊かさだけ言い換える——
①豊かさは挿絵を足すことではなく、**自分の写真と季節の写真が額に入って出ること** ②柄の表紙は豊かさではなく雑音になっている ③ワークスペースは様式ではなく
広い幅の割り付け（三面）④「エディトリアル」は本文を明朝にすることではない（書体は設定にもう在る）。行間・余白・見出しの差で作る。

**足さないもの**：三つめの配色・ノートごとの挿絵・表紙を選ぶ仕掛け・一覧の詳しさの設定・数や達成の表示・通知。3月まで新しい働きを足さない（M の決め）に戻る。

## 9. 読みやすさ・使える人の広さ（WCAG 2.2 AA を物差しに）

- **足りているもの**：押すものの名札（名無し 0）・`lang="ja"`・拡大を止めていない・帯は `tablist`／`tab`・`main`／`header`／`nav`・焦点の輪 2px・
  「動きを減らす」「コントラストを上げる」・字の対比（`legibility` 226/226）・字の大きさ（設定と「iPhone に合わせる」）・的は当たりを 44px へ広げてある。
- **足りないもの**：見出しの意味づけ（P3-3）／字でない物の対比（P3-4。1.4.11 は 3:1）／道具の帯の的（P1-3）／日記の一行の的 24px（P3-5）／
  パソコンで左の列が Tab の最後（近道が補う）／危ない操作が色でも場所でも分かれない（P2-5）。

## 10. 壊してはいけないもの（どの段でも）

- **記録**：保存の形・`reconcile()`・控えと復元・ノートの入れ物と同期の欄。色の引き直しは**描くときの読み替え**（`store.catInk` と同じ流儀）で、記録は書き換えない。
  画面の id（`archive`・`todo`・`list`・`diet`・`notes`）・設定の鍵・`sessionStorage` の鍵は変えない——替えるのは見える字だけ。
- **鍵**：日記とノートの鍵のあいだ、本文を組まない。**新しい抜粋・口絵・机の一行・見出しの目次にも同じに掛ける**（`diary-lock`・`lock`）。
- **身ぶり**：日を払う・暦の三段（題を押す）・席の二度押し（「いま」へ）・長押し（運ぶ・☆）・紙を引いて閉じる・戻るの縁・冊と木を運ぶ・鍵盤の近道。
- **書く道**：書きかけを残す・書いているあいだ画面を消さない・主のボタンは鍵盤の上（`--kb`）・「元に戻す」。
- **決めごと**：暦の札は字のまま・席の名は英語・説明文と絵文字を足さない・daily は評価しない・太さ 400 と 700・CSS は置き換えで純増させない・
  装い二つと暗い面・特大・コントラストを上げる、の全部で成り立つこと。
- **試験が掴んでいる名前**（`.nt-cv`・`.nt-bk`・`.js-all`・`.add-fab`・`.fab-sub`・`.arc-desk`・`.js-desk-copy` ほか）は残すか、台本と一緒に替える。

## 11. 実機で確かめること（段ごとに `docs/iphone-check.md` へ一行）

1. ノートの紙を端まで広げたときの safe-area（上の切り欠き・下のホームバー）と、戻るの縁の身ぶり。
2. 道具の帯を横に送るとき、鍵盤の上で指が帯を掴めるか（本文の送りと取り合わないか）。
3. 背表紙の棚：44px 幅の背を親指で押せるか・横に送る棚と日を払う身ぶりがぶつからないか。
4. 机の一行：筆から書く紙へのつながり（紙が開く拍）・鍵盤が出るまでの間。
5. 暗い面・屋外で、深い八色の背表紙と薄れさせた暦の札の字が読めるか。
6. iPad 縦の頁いっぱいの紙：Apple Pencil のなぞり書きと、紙を引いて閉じる身ぶり。
7. 設定の二面（iPad 横）：左の根っこを送ったとき、右の一枚が動かないこと。
