# tools — 一回きりの道具

アプリ本体には入りません。`sw.js` の ASSETS にも `build-standalone.js` にも
載せていないので、PWA が持ち歩くことも、`dist/` に混ざることもありません。

## diary-import.html — 日記の PDF を、暗号化した控えに変える

数年ぶんの日記を他のアプリからくらしノートへ移すための道具です。

### 使い方

1. **パソコンで開きます**（Chrome / Edge / Safari）。GitHub Pages の
   `.../tools/diary-import.html` でも、このフォルダを丸ごと落として
   `diary-import.html` を直接開いても構いません。
   1700ページの PDF は iPhone だと記憶が足りずに落ちることがあるので、
   一回きりの作業はパソコンのほうが確実です。
2. PDF を落とします。何冊でも、書式が違っていても構いません。
3. **取り出せた文字**を目で確かめます。ここが空っぽ・記号だらけなら、
   その PDF は文字ではなく画像で、この道具では扱えません。
4. **日付の書き方**を選びます。候補ごとに「何日ぶん見つかったか」が
   その場で出るので、いちばん多いものを選べば、たいてい合っています。
   どれも合わなければ、自分で正規表現を書けます。
5. **切り分けた結果**の見本（最初・真ん中・最後の3日）を読んで、日付と
   中身がずれていないかを確かめます。**ここが唯一、人にしか判定できない
   ところです。**
6. 合言葉を決めて、控えを作ります。できたファイルを iPhone へ渡し、
   くらしノートの「設定 → 一般 → バックアップ → 日記を取り込む」で
   読ませます。本文の無い日にだけ入り、すでに書いてある日には触れません。

### 約束していること

- **どこにも送りません。** PDF の読み取りも暗号化も、ぜんぶブラウザの中で
  終わります。pdf.js も `vendor/` に置いてあるものを読みます。開いたあと
  機内モードにしても最後まで通ります。
- **鍵の作りはアプリと同じ一枚**（`../js/diary-crypto.js`）を読んでいます。
  ここで作った控えは、同じ合言葉でアプリが必ず開けます。二度書くと、
  いつか片方だけ直して「開かない控え」を作るので。
- **作った直後に、一度開き直して確かめます。** ここを飛ばすと、開けない
  控えを持って引っ越すことになります。

### 合言葉について

忘れると二度と読めません。取り戻す手立ては**作りません**——作れば、それが
他人の抜け道になります。決めたら紙などに控えてください。

## calendar.html — カレンダーに入れる、の受け渡し

一回きりの道具ではなく、**アプリから開かれる小さなページ**です。ホーム画面の
くらしノートは iPhone のカレンダーへ予定を直接渡せないので、「カレンダーに入れる」で
Safari 本体にこのページを開かせます。開いたとたんに「カレンダーに追加」を出します。予定の中身は URL の
`#` の後ろ（サーバーへは送られない）。ここで作ったファイルを Safari に開かせるだけで、
どこにも送りません。詳しくは `docs/todo-items.md` の「カレンダーに入れる」。

## season-art.js — 季節の絵を加工する（3.0 の E1）

`tools/season-src/kNN.jpg`（コミットしない）を、`img/season/kNN.webp`（短い辺 720px・彩度を落とす・少しぼかす・
1枚25KBまで）にし、平均の色を出す。`photo` を付けると写真（`tools/season-photo-src/` → `img/season-photo/`）、`sky` で帯の空（`tools/sky-src/` → `img/sky/`）。
写真と空の大きさ・上限は道具の頭の定数（2026年10月8日に画質を上げた）。Playwright の Chromium の canvas で処理する。手順と対応表は `docs/season-art.md`。

## notes-proto.html — ノートの見本（Notion・Evernote から移るかを決めるため）

階層・検索・見やすさ・表・書き出しを、iPad・パソコン・iPhone で触って確かめるページ。
`.../tools/notes-proto.html`、数を変えるなら `?n=30000`（200〜30000、ふだん3000）。

- 中身は偽物（決まった種から毎回同じ）。直したものは記憶の中だけで、閉じると消える。
- **本物のデータには触れない**：localStorage・IndexedDB・キャッシュを一つも呼ばない（同じ origin
  にアプリの記録がある）。足すときもこの約束を守る。検討の経緯と懸念は `docs/notes-unify.md`。
- 決まったら消す。

## notes-proto2.html — 見本2（ホーム・すべて・ノートブック・道すじ・中のノート）

`docs/notes-unify.md` の段0。今のアプリの見た目（`css/` をそのまま読む）で、最初の面を決めるために触るページ。
`.../tools/notes-proto2.html`、最初の面を今の一覧にするなら `?start=list`。幅900px からは左に木。

- 読むのは保存に触れない部品だけ（`util.js`・`icons.js`・`icons-phosphor.js`・季節の絵。`KN.store` は記憶だけの身代わり）。
  上の見本と同じく、保存の道具は一つも呼ばない。偽のノートは閉じると消える。
- 決まったら消す。

## todo-proto.html — やることの見本（仕事の予定とやること）

`docs/todo-items.md` の「仕事の予定とやること」。今のアプリの見た目（`css/` をそのまま読む）で、週・今日・月の紙・選ぶ紙を触るページ。
`.../tools/todo-proto.html`、今日の面から開くなら `?start=today`。

- 読むのは保存に触れない部品だけ（`util.js`・`icons.js`・`icons-phosphor.js`・季節の絵・空・`when-parse.js`。`KN.store` は記憶だけの身代わり）。
  保存の道具は一つも呼ばない。偽の記録は開いた日から作り、閉じると消える。
- 決まったら消す。

## shots.js — 見比べの画像を撮る（docs/log/design-review.md の柱G）

393×852・2倍で、試しの記録・明暗・時刻・特大・紙を開く・差し替えの style を組み合わせて撮り、差し替えを横に並べて
番号を書いた `compare.png` を作る。使い方は頭のコメント（`--screens`・`--theme`・`--size`・`--clock`・`--sheet`・
`--scroll`・`--css 'B=…'`）。試しの記録は無難な字だけ。
