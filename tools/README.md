# tools — 一回きりの道具

アプリ本体には入りません。`sw.js` の ASSETS にも `build-standalone.js` にも
載せていないので、PWA が持ち歩くことも、`dist/` に混ざることもありません。

## diary-import.html — 日記の PDF を、暗号化した控えに変える

数年ぶんの日記を他のアプリからくらしノートへ移すための道具です。

### 使い方

1. **パソコンで開きます**（Chrome / Edge / Safari）。GitHub Pages の
   `.../tools/diary-import.html` でも、このフォルダを丸ごと落として
   `diary-import.html` を直接開いても構いません。
   1700ページの PDF は iPhone だと記憶が足りずに落ちることがあるので、
   一回きりの作業はパソコンのほうが確実です。
2. PDF を落とします。何冊でも、書式が違っていても構いません。
3. **取り出せた文字**を目で確かめます。ここが空っぽ・記号だらけなら、
   その PDF は文字ではなく画像で、この道具では扱えません。
4. **日付の書き方**を選びます。候補ごとに「何日ぶん見つかったか」が
   その場で出るので、いちばん多いものを選べば、たいてい合っています。
   どれも合わなければ、自分で正規表現を書けます。
5. **切り分けた結果**の見本（最初・真ん中・最後の3日）を読んで、日付と
   中身がずれていないかを確かめます。**ここが唯一、人にしか判定できない
   ところです。**
6. 合言葉を決めて、控えを作ります。できたファイルを iPhone へ渡し、
   くらしノートの「設定 → 日記を取り込む」で読ませます。

### 約束していること

- **どこにも送りません。** PDF の読み取りも暗号化も、ぜんぶブラウザの中で
  終わります。pdf.js も `vendor/` に置いてあるものを読みます。開いたあと
  機内モードにしても最後まで通ります。
- **鍵の作りはアプリと同じ一枚**（`../js/diary-crypto.js`）を読んでいます。
  ここで作った控えは、同じ合言葉でアプリが必ず開けます。二度書くと、
  いつか片方だけ直して「開かない控え」を作るので。
- **作った直後に、一度開き直して確かめます。** ここを飛ばすと、開けない
  控えを持って引っ越すことになります。

### 合言葉について

忘れると二度と読めません。取り戻す手立ては**作りません**——作れば、それが
他人の抜け道になります。決めたら紙などに控えてください。
