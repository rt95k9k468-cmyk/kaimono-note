# 中継所

ショートカットが健康データを置き、くらしノートが受け取る、小さな郵便受けです。

これを立てると、毎朝の手順が

> ショートカットを走らせる → アプリに戻る → 「コピーしたものを取り込む」を押す

から

> （オートメーションが勝手に走る）→ ダイエットタブを開く

になります。押すボタンが無くなります。

---

## なぜ外を一周させるのか

iPhone の中だけでデータを渡す道は、このアプリの形（Webアプリ）では全部ふさがっています。

| 方法 | 使えるか | 理由 |
|---|---|---|
| URLスキーム（`kurashi://…`） | ✕ | ネイティブアプリの仕組み。Webアプリは名乗れません |
| ユニバーサルリンク | ✕ | 同上。受け取るのはネイティブアプリだけです |
| Web Share Target | ✕ | Safari が実装していません（WebKit bug 194593、いまも open） |
| ショートカットから URL を開く（`?health=…`） | △ | **開くのは Safari のほう**です。ホーム画面のアプリと Safari は保存領域が別なので、入れたデータはホーム画面側から見えません |
| クリップボード | △ | いまの方法。ホーム画面のアプリからは `readText()` が断られるので、毎回「ペースト」を押す必要があります |
| **中継所（これ）** | ○ | 端末の外を一周するので、保存領域の分断を越えられます |

つまり「渡す」のではなく「置いておいて、取りに行く」形にします。

## 何を置くのか

置くのは**手入力とまったく同じ文字**です。

```
day=2026-08-17
steps=8432
sleep=7:12
```

くらしノート側は、受け取った文字列を手入力・貼り付けと**同じ読み取り処理**に渡すだけです。増えるのは入口であって、読み方ではありません。だから中継所は中身を一切見ません。

## 建て方（Cloudflare Workers・無料枠）

**この作業だけは、あなたの手でやる必要があります。** Cloudflareのアカウントは
あなたのもので、他人が代わりに作るものではないからです（利用規約への同意も、
無料枠の請求先も、あなたに紐づきます）。かわりに、**一つのコマンドで終わる**
ようにしてあります。

### いちばん短い道

Mac のターミナルで、このリポジトリを持ってきて `relay/` の中で：

```sh
cd relay
./setup.sh
```

これだけです。`setup.sh` が

1. 当てられない道（合言葉）を作り
2. KVの置き場を作って結び
3. 公開し
4. **本当に置けて取れるかを、その場で確かめ**
5. アプリに貼るURLを出します

Cloudflareにログインしていなければ、途中でブラウザが開きます（無料アカウントで
十分。カードの登録は要りません）。二度目からも、そのまま実行して構いません。

最後にこう出ます:

```
════════════════════════════════════════════════════════════
 中継所ができました。

   https://kurashi-relay.あなた.workers.dev/kn-3f9a2c7e1b4d8506

 これを、くらしノートの
   設定 → ダイエット → 中継所
 に貼って「保存」してください。
════════════════════════════════════════════════════════════
```

### 手で建てる場合

`setup.sh` を使わないなら、やることは三つだけです。

1. **道を決める。** `wrangler.toml` の `RELAY_PATH` に、当てられない長い道を書く
   （`/kn-` のあとに英数字を十数文字。`openssl rand -hex 8` でも構いません）。
   ここが唯一の鍵なので、短くしないでください
2. **置き場を作る。** `npx wrangler kv namespace create MAIL` を実行し、返ってきた
   id を `wrangler.toml` の `[[kv_namespaces]]` の `id` に書く
   （ダッシュボードから作るなら **Storage & Databases → KV**、binding名は `MAIL`）
3. **公開する。** `npx wrangler deploy`

### 動くか確かめる

建てたあと（や、あとで「取り込めない」となったとき）は：

```sh
./verify.sh https://あなたの.workers.dev/kn-xxxxxxxx
```

置く・取る・消える・道が合言葉になっている・アプリから読める、を順に確かめます。
**中継所とアプリのどちらが悪いのかを切り分ける**のが、このスクリプトの仕事です。
ここが全部通るのにアプリで取り込めないなら、原因はアプリ側かURLの写し間違いです。

手で確かめるなら：

```sh
curl -X POST https://あなたの.workers.dev/kn-xxxxxxxx --data-binary 'steps=1234'   # → ok
curl      https://あなたの.workers.dev/kn-xxxxxxxx                                # → steps=1234
curl -i   https://あなたの.workers.dev/kn-xxxxxxxx                                # → 204（空）
```

### コードのほうのテスト

中継所のふるまい（置く・取る・消える・道が違えば渡さない・大きすぎるものを断る・
CORS）は、KVの偽物を使って、外に出ずに確かめられます。

```sh
node relay/worker.test.mjs      # → 32 passed
```

建てる前に、コードが正しいことだけは先に分かります。

### くらしノートに教える

アプリの **設定 → ダイエット → 中継所** に、出てきたURL（道まで含めた全体）を
貼って **保存**。その場で **つないでみる** を押すと、繋がったかどうかが出ます。

> この一手だけは、iPhoneの上でやってください。設定はその端末のブラウザの中に
> 保存されるもので、外から書き込む道はありません（そしてホーム画面のアプリと
> Safari は保存領域が別なので、リンクを開かせて設定させることもできません）。

## ショートカットを直す

いまのショートカットの**最後の「クリップボードにコピー」だけ**を差し替えます。前の部分（ヘルスサンプルを検索 → 統計を計算 → テキスト）はそのままです。

1. 「クリップボードにコピー」を削除
2. **「URLの内容を取得」**を追加
3. URL に中継所のURLを入れる
4. その行の **▸（矢印）を開いて**：
   - **方法**：`POST`
   - **本文を要求**：`ファイル`
   - **ファイル**：一つ前の「テキスト」の結果を差し込む

> 「本文を要求」を `JSON` のままにすると、`{"key":"value"}` の形で送られてしまいます。`ファイル` にすると、テキストがそのまま本文になります。

5. 走らせて、**ダイエットタブを開く**。トーストに「中継所：…」と出れば成功です。

### 毎朝、勝手に走らせる

ショートカットアプリの **オートメーション** → **時刻** → 毎朝7時など →
作ったショートカットを選び、**「実行前に尋ねる」をオフ**。

これで、朝のあいだに中継所へ届き、あなたがダイエットタブを開いた時に入ります。

## 気にしておくこと

- **URLが鍵です。** 人に見せるスクリーンショットに写り込ませないでください。漏れたと思ったら、`wrangler.toml` の `RELAY_PATH` を変えて `npx wrangler deploy` し、アプリの設定も入れ直します（それだけで古いURLは死にます）。
- **中身は暗号化されません。** 通信は HTTPS ですが、中継所の中では平文です。置かれるのは歩数・睡眠・体重といった数字で、名前も端末IDも含みません。それでも他人のサーバに置きたくないなら、自分のサーバに同じことをする10行を置いても構いません（POSTで保存、GETで返して削除、CORSを許す、それだけです）。
- **取ったら消えます。** 一度受け取ったあとに端末を替えても、その便はもう届きません。次のショートカットの実行を待ってください。
- **置いた直後は、まだ届いていないことがあります。** KV は結果整合で、置いたことが世界中に伝わるまで最大60秒ほどかかります。ショートカットを走らせた**直後**にタブを開くと空のことがあるので、そのときは一度タブを離れて戻ってください。毎朝のオートメーションで走らせるぶんには、まず起きません。
- **同じ便が二度渡ることが、稀にあります。** 消したことの伝わり方も同じだからです。アプリ側は同じ日の同じ種類を差し替えるので、二度入っても記録は増えません。
- **一週間で捨てます。** 取りに来ないまま溜め続けても意味がないので。
- **無料枠。** 一日一往復なら、Workers（10万リクエスト/日）にも KV（1000書き込み/日）にも遠く届きません。

## 壊れていないもの

中継所は**入口が一つ増えるだけ**です。

- 手入力（取り込みシートの①の欄）— そのまま
- コピーしたものを取り込む — そのまま
- ファイルから取り込む — そのまま

中継所を設定していないアプリは、これまでと完全に同じ動きをします。
