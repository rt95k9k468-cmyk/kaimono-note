# 中継所

ショートカットが健康データを置き、くらしノートが受け取る、小さな郵便受けです。

これを立てると、毎朝の手順が

> ショートカットを走らせる → アプリに戻る → 「コピーしたものを取り込む」を押す

から

> （オートメーションが勝手に走る）→ ダイエットタブを開く

になります。押すボタンが無くなります。

---

## なぜ外を一周させるのか

iPhone の中だけでデータを渡す道は、このアプリの形（Webアプリ）では全部ふさがっています。

| 方法 | 使えるか | 理由 |
|---|---|---|
| URLスキーム（`kurashi://…`） | ✕ | ネイティブアプリの仕組み。Webアプリは名乗れません |
| ユニバーサルリンク | ✕ | 同上。受け取るのはネイティブアプリだけです |
| Web Share Target | ✕ | Safari が実装していません（WebKit bug 194593、いまも open） |
| ショートカットから URL を開く（`?health=…`） | △ | **開くのは Safari のほう**です。ホーム画面のアプリと Safari は保存領域が別なので、入れたデータはホーム画面側から見えません |
| クリップボード | △ | いまの方法。ホーム画面のアプリからは `readText()` が断られるので、毎回「ペースト」を押す必要があります |
| **中継所（これ）** | ○ | 端末の外を一周するので、保存領域の分断を越えられます |

つまり「渡す」のではなく「置いておいて、取りに行く」形にします。

## 何を置くのか

置くのは**手入力とまったく同じ文字**です。

```
day=2026-08-17
steps=8432
sleep=7:12
```

くらしノート側は、受け取った文字列を手入力・貼り付けと**同じ読み取り処理**に渡すだけです。増えるのは入口であって、読み方ではありません。だから中継所は中身を一切見ません。

## 建て方（iPhoneだけ・パソコン不要）

**手順はぜんぶ、アプリの中にあります。** 設定 → ダイエット → **中継所** を開いて
ください。①〜⑥の順に並んでいて、難しいところは全部ボタンになっています。

ここに書くのは、その画面に何が書いてあるかの控えです。作業はアプリの中の
案内を見ながら進めるほうが早いです（手順を読むために別の端末を開かせるのは、
本末転倒なので）。

### なぜアプリの中に置いたか

iPhoneだけで建てるとき、難所は二つでした。

1. **90行のコードをクリップボードに載せる。** GitHubを開いて、rawを出して、
   全部を選んで、コピーして——指ではここで落ちます。
   → アプリの **「中継所のコードをコピー」** の一つボタンにしました。
2. **当てられない合言葉を作る。** iPhoneに `openssl` はありませんし、人が
   思いつく「適当な文字列」は適当ではありません（誕生日や名前が混ざります）。
   → アプリの **「道をつくる」** が、端末の中で 80ビットぶん作ります。

残りは、Cloudflareの画面で**貼るだけ**の作業になります。

### ① Cloudflareに登録して、Workerを作る

1. Safariで <https://dash.cloudflare.com/sign-up> に登録（メールアドレスだけ。
   カードは要りません）
2. 左の **Compute (Workers)**（または **Workers & Pages**）→ **Create**
   → **Start with Hello World** → **Deploy**

名前は何でも構いません（`kurashi-relay` など）。この名前が、あとで出てくる
URLの頭になります。

### ② 中継所のコードを貼る

1. アプリの **「中継所のコードをコピー」** を押す
2. できたWorkerの **Edit code**（＜＞のボタン）を開く
3. コード欄を**長押し → 選択 → すべてを選択**して、**ペースト**
   （元のHello Worldは残さない）
4. 右上の **Deploy**

貼るコードは `relay/worker.js` と同じものです（アプリの中の写しがずれないよう、
ずれたらテストが落ちるようにしてあります）。

### ③ 合言葉になる道をつくる

1. アプリの **「道をつくる」** を押す（`/kn-…` が出て、クリップボードに乗ります）
2. Workerの **Settings** → **Variables and Secrets** → **Add**
3. **Type** は **Secret**、**Variable name** は `RELAY_PATH`、
   **Value** にいまの道を**ペースト**
4. **Deploy**

**この道が合言葉です。** 知られると、その人も同じ郵便受けを開けられます。
だから Type は Secret にしてください（プレーンテキストの変数は、ダッシュボードに
そのまま表示され続けます）。忘れても、アプリが完成したURLを覚えています。

### ④ 置き場（KV）を作って、結ぶ

1. 左の **Storage & Databases** → **KV** → **Create a namespace**
   （名前は何でも。`kurashi-mail` など）
2. Workerに戻って **Settings** → **Bindings** → **Add** → **KV namespace**
3. **Variable name** は **`MAIL`**（コードがこの名前を見ています）。
   **KV namespace** はいま作ったもの
4. **Deploy**

### ⑤ URLをつなげる

Cloudflareの Worker の画面に出ている `…workers.dev` をコピーして、アプリの
**WorkerのURL** の欄に貼り、**「道をつなげる」** を押します。③で作った道が
後ろに付いて、完成したURLができます。**手で打ち継ぐ必要はありません。**

### ⑥ 確かめる

アプリの **「中継所を確かめる」** を押すと、その場で一往復して

```
✓ 置けた
✓ 置いたものがそのまま取れた
✓ 渡したら消えた
✓ 道が違えば渡さない
```

を確かめます。ここが全部通れば、中継所は正しく建っています。**通らなければ、
どこで止まったかと、何を直せばいいか**が出ます（`RELAY_PATH` が無い、KVが
結ばれていない、道が違う…）。

確かめる前に郵便受けを空にするので、もう届いていたデータは**捨てずに取り込みます**。

最後に **保存** を押してください。

---

## パソコンがある場合

`relay/setup.sh` が①〜⑥を一度にやります。

```sh
cd relay
./setup.sh
```

`relay/verify.sh <URL>` は、⑥と同じことをコマンドラインからやります。

## コードのほうのテスト

中継所のふるまい（置く・取る・消える・道が違えば渡さない・大きすぎるものを断る・
CORS）は、KVの偽物を使って、外に出ずに確かめられます。

```sh
node relay/worker.test.mjs      # → 33 passed
```

---

## ショートカットを直す

いまのショートカットの**最後の「クリップボードにコピー」だけ**を差し替えます。前の部分（ヘルスサンプルを検索 → 統計を計算 → テキスト）はそのままです。

1. 「クリップボードにコピー」を削除
2. **「URLの内容を取得」**を追加
3. URL に中継所のURLを入れる
4. その行の **▸（矢印）を開いて**：
   - **方法**：`POST`
   - **本文を要求**：`ファイル`
   - **ファイル**：一つ前の「テキスト」の結果を差し込む

> 「本文を要求」を `JSON` のままにすると、`{"key":"value"}` の形で送られてしまいます。`ファイル` にすると、テキストがそのまま本文になります。

5. 走らせて、**ダイエットタブを開く**。トーストに「中継所：…」と出れば成功です。

### 毎朝、勝手に走らせる

ショートカットアプリの **オートメーション** → **時刻** → 毎朝7時など →
作ったショートカットを選び、**「実行前に尋ねる」をオフ**。

これで、朝のあいだに中継所へ届き、あなたがダイエットタブを開いた時に入ります。

## 気にしておくこと

- **URLが鍵です。** 人に見せるスクリーンショットに写り込ませないでください。漏れたと思ったら、`wrangler.toml` の `RELAY_PATH` を変えて `npx wrangler deploy` し、アプリの設定も入れ直します（それだけで古いURLは死にます）。
- **中身は暗号化されません。** 通信は HTTPS ですが、中継所の中では平文です。置かれるのは歩数・睡眠・体重といった数字で、名前も端末IDも含みません。それでも他人のサーバに置きたくないなら、自分のサーバに同じことをする10行を置いても構いません（POSTで保存、GETで返して削除、CORSを許す、それだけです）。
- **取ったら消えます。** 一度受け取ったあとに端末を替えても、その便はもう届きません。次のショートカットの実行を待ってください。
- **置いた直後は、まだ届いていないことがあります。** KV は結果整合で、置いたことが世界中に伝わるまで最大60秒ほどかかります。ショートカットを走らせた**直後**にタブを開くと空のことがあるので、そのときは一度タブを離れて戻ってください。毎朝のオートメーションで走らせるぶんには、まず起きません。
- **同じ便が二度渡ることが、稀にあります。** 消したことの伝わり方も同じだからです。アプリ側は同じ日の同じ種類を差し替えるので、二度入っても記録は増えません。
- **一週間で捨てます。** 取りに来ないまま溜め続けても意味がないので。
- **無料枠。** 一日一往復なら、Workers（10万リクエスト/日）にも KV（1000書き込み/日）にも遠く届きません。

## 壊れていないもの

中継所は**入口が一つ増えるだけ**です。

- 手入力（取り込みシートの①の欄）— そのまま
- コピーしたものを取り込む — そのまま
- ファイルから取り込む — そのまま

中継所を設定していないアプリは、これまでと完全に同じ動きをします。
